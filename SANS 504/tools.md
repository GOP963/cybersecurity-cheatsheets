![[Screenshot 2025-05-23 003751.png]]

این ابزار هم میتونه برای تست debuging هم استفاده بشه که به این معنی است که چه خطلا های احتمالی در تنظیمات zone وجوئ دارد 
در صورت فعال بودن Zone Transfer (AXFR)، کل Zone رو دانلود کنه و بررسی کنه.

این ابزار برسی میکنه که  آیا رکوردهای NS و MX درست پیکربندی شده‌ان؟
    
- آیا TTLها درست هستند؟
    
- آیا رکوردهای تکراری، ناسازگار یا مفقود وجود داره؟
    
- اگر Zone Transfer باز باشه، همه رکوردها رو می‌خونه و تحلیل می‌کنه.

| سوییچ | توضیح                                                                     |     |
| ----- | ------------------------------------------------------------------------- | --- |
| `-r`  | اجرای recursive بررسی روی همه زیر دامنه‌ها (اگه وجود داشته باشن).         |     |
| `-d`  | نمایش اطلاعات دیباگ (debug output) برای بررسی دقیق‌تر روند اجرا.          |     |
| `-a`  | بررسی همه رکوردها حتی اگر خطا وجود داشته باشه (مثل `-f` در سایر ابزارها). |     |
| `-F`  | جلوگیری از چک کردن رکوردهای "forward"؛ برای صرف‌نظر کردن از تحلیل‌های     |     |

سلام مارتین! 🌟  
بیایید ساده و دقیق بررسی کنیم که فولدرهای `Netlogon` و `SYSVOL` چی هستن و چه کاربردی دارن:

---

### 🟦 1. فولدر **Netlogon** چیه؟

📁 مسیر معمول:

```
C:\Windows\SYSVOL\sysvol\<domain>\scripts
```

🧠 **کاربرد اصلی:**

- این فولدر برای **Login Script**‌هایی استفاده می‌شه که موقع لاگین کاربران دامنه اجرا می‌شن.
    
- کلاینت‌ها موقع لاگین از دامین کنترلر، فایل‌های این پوشه رو می‌خونن.
    

🔒 **مثال:**  
فرض کن یه اسکریپت `.bat` داری که باید موقع ورود کاربر به سیستم، یه درایو شبکه رو مپ کنه. این اسکریپت توی پوشه Netlogon ذخیره می‌شه.

💡 همچنین:

- این فولدر **Replication** می‌شه بین دامین کنترلرها.
    
- می‌تونه شامل فایل‌های اجرایی یا تنظیمات اولیه باشه.
    

---

### 🟨 2. فولدر **SYSVOL** چیه؟

📁 مسیر معمول:

```
C:\Windows\SYSVOL
```

🧠 **کاربرد اصلی:**

- شامل فایل‌های عمومی دامین هست که باید **بین تمام دامین کنترلرها یکسان باشن**.
    
- مخصوصاً شامل:
    
    - Group Policy Objects (GPOs)
        
    - Login Scripts (که در `Netlogon` هم هستن)
        
    - Policy Definitions
        

🔁 **Replication:**  
از طریق **DFS Replication (DFSR)** یا قدیمی‌تر **FRS**، این فولدر بین دامین کنترلرها سینک می‌شه.

📂 ساختار تقریبی:

```
SYSVOL
├── domain
│   ├── Policies        ← تنظیمات Group Policy
│   └── Scripts         ← فولدر Netlogon در اینجاست
```

---

### 📌 خلاصه تفاوت‌ها:

|ویژگی|Netlogon|SYSVOL|
|---|---|---|
|محل استفاده|Login Scripts|Group Policies + Login Scripts|
|نوع محتوا|اسکریپت‌ها، فایل‌های لاگین|اسکریپت‌ها + GPOها|
|مکان ذخیره|زیرمجموعه SYSVOL|پوشه‌ی اصلی اشتراکی|
|Replication|بله|بله|
|اشتراک‌گذاری|از طریق \domain\netlogon|از طریق \domain\sysvol|
