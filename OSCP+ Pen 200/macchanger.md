
یکی از روش های دور زدن هات اسپات یا همون شبکه های Wireless اینه که بیایم با استفاده از ابزار هایی ماننده Macchanger مک سیستم خودمون رو به یک mac دیگر تغییر بدیم 

یعنی توی اون شبکه این امکان وجود دارد که تو تنظیمات اون Router یه سری mac ها به گفته شده باشه که نتونه به اینترنت وصل شه یا اصلا به عنوان gateway سیستم نتونه به سایر شبکه Route داشته باشه که ما میتونیم با استفاده از این روش این محدودیت رو دور بزنیم 


مثلا با استفاده از ابزار هایی ماننده arp بیایم و لیست mac ادرس های اون شبکه رو در بیاریم و mac خودمون رو با mac یک سیستم دیگر تغییر بدیم 


```
arp -a 
```

```
macchanger --random eth0
```

```
macchanger --set OR -m xx.xx.xx.xx.xx eth0
```
