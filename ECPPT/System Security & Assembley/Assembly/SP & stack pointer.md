### ۱. تعریف ساده

**Stack Pointer** یک **رجیستر در CPU** است که همیشه **به بالای (Top) پشته (Stack) اشاره می‌کند**.

- پشته (Stack) یک بخش از حافظه است که برای ذخیره‌سازی موقت داده‌ها استفاده می‌شود، مثل:
    
    - آدرس بازگشت (Return address) هنگام فراخوانی توابع
        
    - مقادیر محلی متغیرهای یک تابع
        
    - مقادیر رجیسترهایی که باید هنگام تغییر تابع ذخیره شوند
        
- Stack Pointer به CPU می‌گوید: "بعدی داده‌ای که می‌خوای روی پشته قرار بدی یا ازش بخونی، کجا هست."
    

---

### ۲. نحوه کار Stack Pointer

1. وقتی یک **عملیات PUSH** انجام می‌شود:
    
    - SP **کم می‌شود** (در سیستم‌هایی که Stack به سمت پایین رشد می‌کند)
        
    - مقدار جدید روی پشته نوشته می‌شود
        
2. وقتی یک **عملیات POP** انجام می‌شود:
    
    - مقدار از بالای پشته خوانده می‌شود
        
    - SP **افزایش پیدا می‌کند** تا به عنصر بالایی بعدی اشاره کند
        

> نکته: رشد پشته در اکثر معماری‌ها (مثل x86) به سمت پایین است، یعنی SP کاهش می‌یابد وقتی داده‌ای به پشته اضافه می‌کنیم.

---

### ۳. تصویر ذهنی ساده

```
|       | <- Stack grows downward
| value |  <- SP points here (top of stack)
| value |
|_______|
```

---

### ۴. چرا Stack Pointer مهم است؟

- برای **فراخوانی توابع** و بازگشت به محل درست
    
- برای **ذخیره متغیرهای محلی و رجیسترها** به صورت موقت
    
- برای **مدیریت حافظه امن** در زمان اجرا
    

---

### ۵. ارتباط با Base Pointer

معمولاً یک رجیستر دیگر به نام **Base Pointer (BP یا EBP/RBP)** داریم که به **پایین‌ترین نقطه‌ی محدوده‌ی یک تابع** اشاره می‌کند، در حالی که SP همیشه **به بالای پشته** اشاره دارد.

---


آها مارتین، الان دقیقاً متوجه شدم منظورت چیه 😎  
میخوای بدونی وقتی می‌بینی مثلاً `ESP-4` یا `ESP+8` یعنی چی و چرا گاهی منفی و گاهی مثبت هست. بیا قدم‌به‌قدم توضیح بدم:

---

### ۱. مبنای Stack Pointer

- **ESP** (Extended Stack Pointer) در معماری x86، همیشه **به بالای پشته اشاره می‌کنه**.
    
- پشته معمولاً **به سمت پایین رشد می‌کنه**؛ یعنی هر بار که داده‌ای به پشته اضافه می‌کنیم، **ESP کاهش پیدا می‌کنه**.
    

---

### ۲. ESP-4 یعنی چی؟

وقتی می‌بینی:

```
mov eax, [esp-4]
```

این یعنی:

- CPU میره **۴ بایت بالاتر از ESP فعلی** و اونجا رو می‌خونه.
    
- چرا منفی؟ چون **آدرس‌های بالاتر در حافظه عدد بزرگتری دارند** و پشته به سمت پایین رشد می‌کنه.
    
- مثال:
    

```
ESP = 0x1000
[esp] = 0x1000
[esp-4] = 0x1004   <- بالای پشته
```

---

### ۳. ESP+8 یعنی چی؟

وقتی می‌بینی:

```
mov eax, [esp+8]
```

این یعنی:

- CPU میره **۸ بایت پایین‌تر از ESP فعلی**.
    
- معمولاً وقتی تابع فراخوانی شده و ESP تغییر کرده (مثلاً PUSH شده)، دسترسی به پارامترهای تابع با ESP+offset انجام می‌شه.
    
- مثال:
    

```
ESP = 0x0FF0   <- بالای پشته فعلی
[esp+4] = پارامتر اول
[esp+8] = پارامتر دوم
```

> خلاصه: **منفی یعنی بالاتر از SP فعلی** (بالاتر در حافظه)، **مثبت یعنی پایین‌تر از SP فعلی** (پایین‌تر در حافظه).

---

### ۴. نکته مهم

- این علامت‌ها **رابطه مستقیم با جهت رشد پشته دارند**.
    
- در x86: پشته به سمت پایین رشد می‌کنه → PUSH کم کردن ESP، POP زیاد کردن ESP.
    
- در معماری‌های دیگه ممکنه جهت رشد پشته متفاوت باشه.
