## ۱. Assemblers (اسمبلرها)

### تعریف:

**Assembler** برنامه‌ای است که **کد اسمبلی (Assembly Code)** رو می‌گیره و اون رو به **کد ماشین (Machine Code)** تبدیل می‌کنه.

- **کد اسمبلی** برای انسان قابل فهم‌تره ولی CPU نمی‌تونه مستقیم اجراش کنه.
    
- **کد ماشین** شامل ۰ و ۱ است و CPU می‌تونه مستقیم اجراش کنه.
    

### ویژگی‌ها:

1. **یک‌به‌یک**: معمولاً هر دستور اسمبلی به **یک دستور ماشین** تبدیل می‌شود.
    
2. **سرعت ترجمه بالا**: چون ساده است و تقریباً مستقیم به کد ماشین می‌رود.
    
3. **معماری وابسته**: کد اسمبلی برای یک معماری خاص (مثل x86 یا ARM) نوشته می‌شود.
    

### مثال:

Assembly:

```asm
MOV AX, 5
ADD AX, 3
```

تبدیل به Machine Code:

```
B8 05 00
03 C0
```

> در واقع، اسمبلر فقط ترجمه‌کننده است، به منطق برنامه کاری ندارد.

## ۲. Compilers (کامپایلرها)

### تعریف:

**Compiler** برنامه‌ای است که **کد منبع سطح بالا (مثل C, C++, Java)** را می‌گیرد و آن را به **کد ماشین یا اسمبلی** تبدیل می‌کند.

- وظیفه اصلی: **ترجمه یک برنامه کامل از سطح بالا به سطح پایین**.
    
- علاوه بر ترجمه، **چک کردن خطاها و بهینه‌سازی کد** هم بر عهده کامپایلر است.
    

### ویژگی‌ها:

1. **یک به چند دستور ماشین**: معمولاً یک دستور زبان سطح بالا به چند دستور اسمبلی یا ماشین تبدیل می‌شود.
    
2. **بهینه‌سازی**: کامپایلر می‌تواند کد خروجی را برای سرعت یا حجم بهینه کند.
    
3. **معماری وابسته**: خروجی کامپایلر هم معمولاً برای یک CPU مشخص است، مگر اینکه Intermediate Code تولید کند (مثل Java Bytecode).
    

### مثال:

C Code:

```c
int a = 5;
int b = 3;
int c = a + b;
```

می‌تواند به چند دستور اسمبلی تبدیل شود:

```asm
MOV AX, 5
MOV BX, 3
ADD AX, BX
MOV [c], AX
```

## ۳. تفاوت اصلی Assembler و Compiler

|ویژگی|Assembler|Compiler|
|---|---|---|
|ورودی|Assembly Code|زبان سطح بالا (C, C++, ...)|
|خروجی|Machine Code|Machine Code یا Assembly|
|ترجمه|تقریباً یک‌به‌یک|یک به چند|
|چک خطا|کم|کامل (syntax, semantic)|
|بهینه‌سازی|ندارد/کم|دارد|

---

### جمع‌بندی

- **Assembler**: ترجمه دستور به دستور، خیلی نزدیک به سخت‌افزار.
    
- **Compiler**: ترجمه برنامه کامل، شامل چک خطا و بهینه‌سازی، معمولاً به زبان ماشین یا اسمبلی تبدیل می‌کند.

## ۱. تعریف اسمبلی

**Assembly Language** یک زبان سطح پایین است که خیلی نزدیک به **کد ماشین (Machine Code)** است، ولی برای انسان قابل فهم‌تر.

- به هر دستور اسمبلی، معمولاً **یک دستور ماشین** متناظر وجود دارد.
    
- معماری CPU مشخص می‌کند که چه دستوراتی داریم (مثل x86, x64, ARM).
    

---

## ۲. ساختار یک برنامه اسمبلی

یک برنامه اسمبلی معمولاً شامل این‌هاست:

1. **دستورات (Instructions)**
    
    - مثل `MOV`, `ADD`, `SUB`, `JMP`
        
    - این‌ها عملیاتی هستند که CPU انجام می‌دهد.
        
2. **رجیسترها (Registers)**
    
    - محل نگه‌داری داده‌ها در CPU، مثل `EAX`, `EBX`, `ESP`, `EBP`
        
    - دسترسی سریع به داده‌ها بدون رفتن به RAM
        
3. **برچسب‌ها (Labels)**
    
    - مثل نام یک خط برای دستور `JMP` یا تابع
        
    - مسیر اجرای برنامه را مشخص می‌کند
        
4. **داده‌ها (Data Section)**
    
    - جایی که متغیرها یا ثابت‌ها نگه‌داری می‌شوند
        

---

## ۳. نحوه کار برنامه اسمبلی

1. برنامه‌نویس دستورات اسمبلی را می‌نویسد.
    
2. **Assembler** آن را به **کد ماشین (Machine Code)** تبدیل می‌کند.
    
3. CPU آن کد ماشین را اجرا می‌کند.
    

> مثال ساده x86:

```asm
MOV AX, 5     ; مقدار 5 را در رجیستر AX قرار بده
ADD AX, 3     ; 3 را به AX اضافه کن
```

- هر دستور اسمبلی به **یک یا چند دستور ماشین** تبدیل می‌شود.
    
- CPU این دستورات ماشین را اجرا می‌کند و نتیجه در رجیسترها ذخیره می‌شود.

## ۴. نکات مهم

- **هر دستور اسمبلی مستقیم به CPU می‌گوید چه کاری انجام بده**
    
- **Assembly زبان انسان‌پسند نیست، اما کنترل کامل روی سخت‌افزار می‌دهد**
    
- معمولاً برای:
    
    - نوشتن **درایورها**

```
Program (Assembly) --> Assembler --> Machine Code --> CPU اجرا
```

> یعنی اسمبلی فقط **زبان واسطه بین انسان و CPU** است.
