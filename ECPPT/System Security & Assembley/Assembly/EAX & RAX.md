## 🔹 EAX چیست؟

- **EAX** مخفف **Extended Accumulator Register** هست.
    
- یه رجیستر **۳۲ بیتی** (توی معماری x86) و در خانوادهٔ رجیسترهای عمومی (**General Purpose Registers**) قرار داره.
    
- نقش اصلیش: انجام عملیات‌های حسابی و منطقی.
    

📌 به زبون ساده:  
EAX مثل یه **ماشین‌حساب مرکزی** برای CPU عمل می‌کنه. خیلی از دستورالعمل‌ها نتیجه نهایی رو توی EAX ذخیره می‌کنن.

---

## 🔹 تاریخچه کوتاه

- توی CPUهای قدیمی (۸ بیتی)، یه رجیستر بود به اسم **AX (Accumulator)**.
    
- بعد که معماری ۳۲ بیتی شد، **EAX** ساخته شد (E = Extended).
    
- توی ۶۴ بیتی هم نسخه بزرگ‌ترش میشه **RAX**.

## 🔹 کاربردهای اصلی EAX

### 1. عملیات حسابی و منطقی

بیشتر دستورها نتیجه رو توی EAX می‌ذارن.  
مثال:

```asm
mov eax, 5
add eax, 3   ; حالا EAX = 8
```

### 2. برگشت مقدار تابع

در زبان‌های سطح بالا مثل C یا C++، وقتی تابع چیزی return می‌کنه → مقدار برگشتی توی **EAX** ذخیره میشه.  
مثلاً:

```c
int add(int a, int b) {
    return a + b;
}
```

اسمبلی معادل:

```asm
mov eax, [ebp+8]   ; آرگومان a
add eax, [ebp+12]  ; a + b
ret                ; نتیجه در EAX هست
```

### 3. عملیات‌های خاص CPU

- توی دستورهای ضرب و تقسیم، EAX همیشه رجیستر پیش‌فرضه.
    
    ```asm
    mov eax, 6
    mul ebx       ; eax = eax * ebx
    ```
    
- توی بعضی سیستم‌کال‌ها (مثل لینوکس) شمارهٔ syscall باید توی EAX قرار بگیره.
    

### 4. بخش‌بندی به رجیسترهای کوچیک‌تر

EAX رو میشه به قسمت‌های کوچیک‌تر استفاده کرد:

- `AX` (16-bit) → نصف پایینی EAX
    
- `AH` (High 8-bit) → ۸ بیت بالایی AX
    
- `AL` (Low 8-bit) → ۸ بیت پایینی AX
    

مثلاً:

```asm
mov eax, 0x12345678
```

- `EAX = 12345678h`
    
- `AX = 5678h`
    
- `AH = 56h`
    
- `AL = 78h`

## 🔹 جمع‌بندی

- **EAX = رجیستر اصلی محاسبات در CPU**
    
- برای عملیات‌های حسابی، منطقی، ضرب و تقسیم استفاده میشه
    
- خروجی توابع و syscallها معمولاً توی EAX قرار می‌گیره
    
- می‌تونی به صورت ۸ بیت، ۱۶ بیت یا ۳۲ بیت ازش استفاده کنی
