### ۱. تعریف Stack

**Stack** یک **بخش از حافظه** است که برای **ذخیره‌سازی موقت داده‌ها به صورت LIFO** (Last In, First Out) استفاده می‌شود.

- **LIFO** یعنی آخرین چیزی که گذاشته می‌شود، **اولین چیزی است که برداشته می‌شود**.
    
- داده‌هایی که معمولاً روی Stack ذخیره می‌شوند:
    
    - آدرس بازگشت (Return Address) هنگام فراخوانی تابع
        
    - مقادیر متغیرهای محلی
        
    - پارامترهای تابع
        
    - مقادیر رجیسترهایی که قبل از فراخوانی تابع باید ذخیره شوند
        

---

### ۲. ویژگی‌های مهم Stack

1. **رشد Stack:**
    
    - در معماری x86، Stack به سمت پایین رشد می‌کند (یعنی PUSH باعث کاهش ESP می‌شود).
        
2. **دسترسی سریع:**
    
    - CPU به Stack بسیار سریع دسترسی دارد، چون عملیات آن ساده است: PUSH و POP.
        
3. **ساختار موقت:**
    
    - وقتی تابع تمام شد، داده‌های مرتبط با آن تابع از Stack پاک می‌شوند.
        

---

### ۳. تصویر ذهنی ساده

فرض کن Stack مثل یه لیوان کاغذی است:

```
Top (ESP ->)  | Data 3  <- آخرین چیزی که اضافه شد
              | Data 2
              | Data 1  <- اولین چیزی که اضافه شد
Bottom        |
```

- وقتی داده‌ای جدید PUSH می‌کنیم، روی Top گذاشته می‌شود.
    
- وقتی POP می‌کنیم، از Top برداشته می‌شود.
    

---

### ۴. ارتباط با Stack Pointer

- **Stack Pointer (ESP)** همیشه به **بالای Stack** اشاره دارد.
    
- با PUSH، ESP کم می‌شود، با POP، ESP زیاد می‌شود.
    

---

---

### ۱. تعریف ساده

**Stack Frame** یا **Activation Record**، یک **بخش از پشته** است که **برای هر بار فراخوانی یک تابع ساخته می‌شود**.

- وقتی یک تابع در حال اجراست، همه چیزهایی که آن تابع نیاز داره توی **Stack Frame خودش** نگه‌داری میشه.
    

---

### ۲. چه چیزهایی داخل Stack Frame هست؟

یک Stack Frame معمولاً شامل موارد زیر است:

1. **Return Address**
    
    - آدرسی که CPU بعد از پایان تابع باید برگرده به اونجا.
        
    - وقتی تابع با دستور `CALL` فراخوانی میشه، این آدرس به پشته **PUSH** میشه.
        
2. **Saved Base Pointer (EBP/RBP)**
    
    - رجیستری که به پایین‌ترین نقطه Stack Frame اشاره می‌کنه.
        
    - برای دسترسی به متغیرهای محلی و پارامترهای تابع به کار میره.
        
3. **Local Variables**
    
    - متغیرهایی که فقط داخل این تابع استفاده می‌شوند.
        
    - معمولاً با **ESP-Offset** (مثل `ESP-4`) بهشون دسترسی پیدا می‌کنیم.
        
4. **Function Parameters**
    
    - پارامترهای تابع که توسط تابع فراخوانی‌کننده (Caller) ارسال شده.
        
    - معمولاً با **EBP+Offset** (مثل `EBP+8`) بهشون دسترسی داریم.
        

---

### ۳. ساختار تصویری ساده

فرض کن پشته به سمت پایین رشد می‌کنه:

```
| پارامتر 2           |  <- EBP + 12
| پارامتر 1           |  <- EBP + 8
| Return Address      |  <- EBP + 4
| Saved EBP           |  <- EBP (پایین‌ترین نقطه)
| Local Variable 1    |  <- EBP - 4
| Local Variable 2    |  <- EBP - 8
| ...                 |  
| ESP -> بالای پشته فعلی
```

> نکته:
> 
> - پارامترها با EBP+Offset دسترسی دارند.
>     
> - متغیرهای محلی با EBP-Offset دسترسی دارند.
>     
> - ESP همیشه به **بالای پشته** اشاره می‌کنه و با PUSH و POP تغییر می‌کنه.
>     

---

### ۴. چرا Stack Frame مهمه؟

- برای **مدیریت صحیح حافظه** تابع
    
- برای **دسترسی سریع به پارامترها و متغیرهای محلی**
    
- برای **بازگشت صحیح بعد از CALL**
    

---


---

### ۱. Stack Frame چیست؟

**Stack Frame** (یا Activation Record) همون **بخشی از Stack است که مخصوص یک تابع ساخته می‌شود** و شامل همه چیزهایی است که اون تابع برای اجرا نیاز داره.

---

### ۲. چه چیزهایی داخل یک Stack Frame هست؟

هر Stack Frame معمولاً شامل این‌هاست:

1. **Return Address**
    
    - آدرسی که بعد از پایان تابع باید CPU برگرده به اونجا.
        
2. **Saved Base Pointer (EBP/RBP)**
    
    - مقدار EBP قبلی که برای بازگشت به تابع قبلی ذخیره شده.
        
3. **Local Variables**
    
    - متغیرهای محلی تابع که فقط داخل همون تابع معتبر هستند.
        
4. **Function Parameters**
    
    - پارامترهایی که به تابع فرستاده شده.
        

---

### ۳. نکته مهم

- **Stack Frame خودش اجرا نمی‌شود.**
    
    - فقط محل ذخیره‌سازی **اطلاعات مورد نیاز تابع** است.
        
    - وقتی CPU دستورالعمل‌های تابع را اجرا می‌کند، از مقادیر داخل Stack Frame استفاده می‌کند (مثلاً برای خواندن متغیرها یا برگشت به آدرس درست).
        

---

### ۴. تصویر ذهنی

```
| پارامتر 2           |  <- EBP + 12
| پارامتر 1           |  <- EBP + 8
| Return Address      |  <- EBP + 4
| Saved EBP           |  <- EBP
| Local Variable 1    |  <- EBP - 4
| Local Variable 2    |  <- EBP - 8
| ...                 |
| ESP -> بالای پشته فعلی
```

> هر بار که یک تابع CALL می‌شود، یک Stack Frame جدید روی Stack ساخته می‌شود، و بعد از RET از بین می‌رود.
