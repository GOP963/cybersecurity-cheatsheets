## 🔹 ECX چیست؟
- **ECX** مخفف **Extended Counter Register** هست.  
- رجیستر **۳۲ بیتی** توی معماری x86 (در x64 بهش می‌گن **RCX**).  
- جزو رجیسترهای عمومی (General Purpose) هست.  

📌 نقش اصلی: همونطور که اسمش میگه، بیشتر به عنوان **شمارنده (Counter)** استفاده میشه.  

---

## 🔹 کاربردهای اصلی ECX
### 1. شمارنده در حلقه‌ها
خیلی از دستورها مثل `loop` از ECX به عنوان شمارنده استفاده می‌کنن.  
مثال:
```asm
mov ecx, 5     ; شمارنده = 5
L1:
    ; یکسری دستور
loop L1         ; هر بار ECX-- میشه تا برسه به 0
```

---

### 2. شمارنده در عملیات تکراری (REP Instructions)
توی دستورهایی مثل `rep movsb` یا `rep stosd`، مقدار **ECX** نشون میده که دستور چند بار تکرار بشه.  
مثال:  
```asm
mov ecx, 100
rep movsb    ; 100 بایت از [ESI] به [EDI] کپی کن
```

---

### 3. قراردادهای فراخوانی (Calling Conventions)
- توی **fastcall** (روی ویندوز)، آرگومان دوم تابع معمولاً توی **ECX** قرار می‌گیره.  
- توی **x86-64 System V ABI** (روی لینوکس/یونیکس)، رجیستر **RCX** برای یکی از آرگومان‌های تابع استفاده میشه.  

---

### 4. استفاده عمومی (General Purpose)
مثل بقیه رجیسترها میشه از ECX برای ذخیره مقادیر موقت یا محاسباتی استفاده کرد:  
```asm
mov ecx, 10
add ecx, 20   ; ECX = 30
```

---

### 5. بخش‌بندی به رجیسترهای کوچیک‌تر
مثل بقیه:  
- `CX` (16-bit) → نصف پایینی ECX  
- `CH` (High 8-bit) → ۸ بیت بالایی CX  
- `CL` (Low 8-bit) → ۸ بیت پایینی CX  

مثال:
```asm
mov ecx, 0x12345678
```
- `ECX = 12345678h`  
- `CX  = 5678h`  
- `CH  = 56h`  
- `CL  = 78h`  

---

## 🔹 تفاوت ECX با EAX و EBX
- **EAX** → رجیستر اصلی محاسبات و ذخیرهٔ نتایج.  
- **EBX** → معمولاً برای آدرس‌دهی و داده‌هایی که باید ثابت بمونن.  
- **ECX** → بیشتر برای شمارش و تکرار (Counter Register).  

---

✅ جمع‌بندی:  
**ECX = Extended Counter Register**  
- رجیستر ۳۲ بیتی برای شمارش  
- استفاده در حلقه‌ها (`loop`) و دستورهای تکراری (`rep`)  
- در بعضی قراردادهای فراخوانی برای آرگومان‌ها استفاده میشه  
- میشه بخش‌بندی‌ش کرد (CX, CH, CL)
