## 🔹 EBX چیست؟

- **EBX** مخفف **Extended Base Register** هست.
    
- یک رجیستر **۳۲ بیتی** در معماری x86 (توی ۶۴ بیتی بهش می‌گن **RBX**).
    
- جزو **General Purpose Registers** حساب میشه.
    

📌 نقش اصلیش: بیشتر برای **آدرس‌دهی حافظه (Base Addressing)** و نگهداری داده‌های عمومی استفاده میشه.

---

## 🔹 تاریخچه کوتاه

- توی پردازنده‌های 16 بیتی، رجیستر **BX** به اسم "Base Register" معروف بود چون معمولاً به عنوان پایه (Base) در محاسبات آدرس استفاده میشد.
    
- وقتی ۳۲ بیتی شد، شد **EBX**.
    

---

## 🔹 کاربردهای اصلی EBX

### 1. آدرس‌دهی در حافظه (Base Register)

EBX خیلی وقت‌ها برای ساختن آدرس استفاده میشه.  
مثلاً:

```asm
mov ebx, array   ; آدرس یک آرایه در EBX
mov eax, [ebx+4] ; مقدار عنصر دوم آرایه
```

اینجا EBX نقش **پایه (base)** رو داره.

---

### 2. نگهداری داده‌های عمومی

مثل بقیه رجیسترهای عمومی، می‌تونی از EBX برای ذخیره مقادیر موقت استفاده کنی:

```asm
mov ebx, 10
add ebx, 20   ; EBX = 30
```

---

### 3. قراردادهای فراخوانی (Calling Conventions)

در بعضی قراردادهای فراخوانی (Calling Convention) مثل **fastcall** یا **system V**:

- EBX می‌تونه برای نگه داشتن بعضی آرگومان‌ها یا مقادیر خاص استفاده بشه.
    
- در خیلی از ABIها (Application Binary Interface)، EBX جزو رجیسترهایی هست که باید مقدارش در طول یک تابع ثابت بمونه (Callee-saved). یعنی اگه تابعی خواست از EBX استفاده کنه، باید قبلش مقدارشو push کنه و بعداً دوباره pop کنه.
    

---

### 4. بخش‌بندی به رجیسترهای کوچیک‌تر

مثل EAX، رجیستر EBX هم می‌تونه شکسته بشه به بخش‌های کوچیک‌تر:

- `BX` (16-bit) → نصف پایینی EBX
    
- `BH` (High 8-bit) → ۸ بیت بالایی BX
    
- `BL` (Low 8-bit) → ۸ بیت پایینی BX
    

مثال:

```asm
mov ebx, 0x12345678
```

- `EBX = 12345678h`
    
- `BX = 5678h`
    
- `BH = 56h`
    
- `BL = 78h`
    

---

## 🔹 تفاوت EBX با EAX

- **EAX** معمولاً برای محاسبات و ذخیرهٔ خروجی استفاده میشه.
    
- **EBX** بیشتر نقش **پایه برای آدرس‌دهی** و نگه داشتن داده‌هایی که نباید توی تابع تغییر کنن رو بازی می‌کنه.
    

---

✅ جمع‌بندی:  
**EBX = Extended Base Register**

- رجیستر ۳۲ بیتی عمومی
    
- معمولاً برای آدرس‌دهی حافظه (Base Addressing) استفاده میشه
    
- جزو رجیسترهایی که باید توابع مقدارش رو حفظ کنن (callee-saved)
    
- میشه به قسمت‌های کوچیک‌تر (BX, BH, BL) تقسیمش کرد
