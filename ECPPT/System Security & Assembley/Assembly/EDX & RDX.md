## 🔹 EDX چیست؟

- **EDX** مخفف **Extended Data Register** هست.
    
- یک رجیستر **۳۲ بیتی** در معماری x86 (توی x64 بهش می‌گن **RDX**).
    
- مثل بقیه، جزو **General Purpose Registers** هست.
    

📌 نقش اصلیش: ذخیره داده‌های اضافی، مخصوصاً در عملیات‌های **ضرب و تقسیم** که خروجی بزرگ‌تر از EAX میشه.

---

## 🔹 کاربردهای اصلی EDX

### 1. عملیات ضرب (MUL/IMUL)

وقتی دو عدد بزرگ ضرب میشن، حاصل ممکنه بیشتر از ۳۲ بیت بشه.

- بخش پایینی نتیجه توی **EAX** ذخیره میشه.
    
- بخش بالایی نتیجه توی **EDX** ذخیره میشه.
    

مثال:

```asm
mov eax, 0xFFFFFFFF ; بزرگترین عدد 32 بیتی
mov ebx, 2
mul ebx             ; EDX:EAX = EAX * EBX
```

📌 اینجا جواب 0x1FFFFFFFE میشه، یعنی:

- `EAX = FFFFFFFE` (بخش پایین)
    
- `EDX = 1` (بخش بالا)
    

---

### 2. عملیات تقسیم (DIV/IDIV)

توی تقسیم هم ترکیب **EDX:EAX** به عنوان مقسوم (Dividend) استفاده میشه.

- یعنی اول EDX رو صفر می‌کنن (یا Sign-Extend می‌کنن).
    
- بعد EDX:EAX رو تقسیم می‌کنن.
    

مثال:

```asm
mov eax, 20   ; عددی که می‌خوای تقسیم کنی
xor edx, edx  ; EDX = 0
mov ebx, 3
div ebx       ; EAX = خارج‌قسمت (6), EDX = باقیمانده (2)
```

---

### 3. ذخیره داده‌های عمومی

مثل بقیه رجیسترها میشه از EDX هم به عنوان رجیستر عمومی استفاده کرد:

```asm
mov edx, 100
sub edx, 40   ; EDX = 60
```

---

### 4. قراردادهای فراخوانی (Calling Conventions)

- توی بعضی قراردادهای فراخوانی (مثل fastcall در ویندوز)، یکی از آرگومان‌های تابع داخل EDX قرار می‌گیره.
    
- توی معماری ۶۴ بیتی (System V ABI)، رجیستر **RDX** معمولاً برای آرگومان سوم تابع استفاده میشه.
    

---

### 5. بخش‌بندی به رجیسترهای کوچیک‌تر

مثل بقیه رجیسترها:

- `DX` (16-bit) → نصف پایینی EDX
    
- `DH` (High 8-bit) → ۸ بیت بالایی DX
    
- `DL` (Low 8-bit) → ۸ بیت پایینی DX
    

مثال:

```asm
mov edx, 0x12345678
```

- `EDX = 12345678h`
    
- `DX = 5678h`
    
- `DH = 56h`
    
- `DL = 78h`
    

---

## 🔹 تفاوت EDX با بقیه

- **EAX** → محاسبات و نتایج
    
- **EBX** → آدرس‌دهی و داده‌های ثابت
    
- **ECX** → شمارنده و تکرار
    
- **EDX** → داده‌های اضافی (به‌ویژه ضرب و تقسیم)
    

---

✅ جمع‌بندی:  
**EDX = Extended Data Register**

- رجیستر ۳۲ بیتی
    
- ذخیره بخش بالای حاصل ضرب و باقیمانده تقسیم
    
- استفاده در برخی قراردادهای فراخوانی
    
- میشه به DX, DH, DL تقسیمش کرد
