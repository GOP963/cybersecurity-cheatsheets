## 🎯 Port Scanning چیست؟

Port Scanning یعنی ارسال بسته‌های خاص به پورت‌های یک سیستم برای فهمیدن این‌که:

- پورت **باز** (Open) است → سرویس در حال اجراست و پاسخ می‌دهد.
    
- پورت **بسته** (Closed) است → سرویس در حال اجرا نیست ولی سیستم پاسخ می‌دهد.
    
- پورت **فیلتر شده** (Filtered) است → فایروال یا دستگاه امنیتی مانع پاسخ شده.
    

---

## ⚙️ مراحل کلی از دید Attacker

1. **Host Discovery** (پیدا کردن سیستم‌های فعال)
    
2. **Port Scan** (پیدا کردن سرویس‌های باز)
    
3. **Service Enumeration** (دریافت اطلاعات دقیق سرویس)
    
4. **Exploit** یا استفاده در فاز بعدی حمله
    

---

## 🛠 تکنیک‌های Port Scanning با Nmap

---

### 1️⃣ **TCP Connect Scan** (`-sT`)

- از سیستم‌عامل می‌خواهد که اتصال TCP کامل (3-way handshake) برقرار کند.
    
- اگر اتصال موفق شد → پورت باز.
    

```bash
nmap -sT 192.168.1.10
```

- **مزیت:** نیاز به دسترسی خاص ندارد.
    
- **عیب:** قابل شناسایی راحت چون اتصال کامل انجام می‌شود.
    

---

### 2️⃣ **TCP SYN Scan (Half-Open)** (`-sS`)

- ارسال SYN → اگر SYN/ACK برگشت، فوراً RST می‌فرستد (اتصال کامل نمی‌شود).
    

```bash
nmap -sS 192.168.1.10
```

- **مزیت:** سریع و نسبتاً مخفی.
    
- **عیب:** نیاز به دسترسی Root/Administrator.
    

---

### 3️⃣ **UDP Scan** (`-sU`)

- ارسال بسته UDP → اگر پاسخ سرویس یا ICMP Port Unreachable بیاید، وضعیت مشخص می‌شود.
    

```bash
nmap -sU 192.168.1.10
```

- **مزیت:** کشف سرویس‌های UDP مثل DNS، SNMP.
    
- **عیب:** کند و پر از False Positive.
    

---

### 4️⃣ **TCP FIN / Xmas / Null Scans** (`-sF`, `-sX`, `-sN`)

- ارسال بسته‌های غیرعادی برای دور زدن فایروال و تشخیص سیستم‌عامل.
    

```bash
nmap -sF 192.168.1.10
nmap -sX 192.168.1.10
nmap -sN 192.168.1.10
```

- **مزیت:** عبور از بعضی فایروال‌ها و IDS قدیمی.
    
- **عیب:** روی سیستم‌های Windows معمولاً جواب نمی‌دهد (چون RFC متفاوت).
    

---

### 5️⃣ **Version Detection** (`-sV`)

- بعد از شناسایی پورت‌ها، تلاش برای کشف نسخه دقیق سرویس.
    

```bash
nmap -sV 192.168.1.10
```

---

### 6️⃣ **Aggressive Scan** (`-A`)

- ترکیب Port Scan + Version Detection + OS Detection + Script Scan.
    

```bash
nmap -A 192.168.1.10
```

- **مزیت:** اطلاعات کامل.
    
- **عیب:** خیلی پر سروصدا و سریع لو می‌روی.
    

---

### 7️⃣ **Fast Scan** (`-F`)

- فقط 100 پورت پرکاربرد را اسکن می‌کند.
    

```bash
nmap -F 192.168.1.10
```

---

### 8️⃣ **Custom Port Range**

- اسکن پورت‌های خاص:
    

```bash
nmap -p 21,22,80,443 192.168.1.10
```

- یا همه پورت‌ها:
    

```bash
nmap -p- 192.168.1.10
```

---

## 📌 نکات Red Team برای مخفی‌کاری

- اسکن آهسته:
    

```bash
nmap -sS --scan-delay 1s 192.168.1.10
```

- تغییر ترتیب پورت‌ها:
    

```bash
nmap -sS --randomize-hosts --top-ports 50 192.168.1.0/24
```

- ذخیره خروجی برای تحلیل:
    

```bash
nmap -sS 192.168.1.10 -oN scan_result.txt
```

## 📌 معنی `-Pn`

- **به Nmap میگه Host Discovery رو رد کنه** و فرض کنه همه هدف‌ها زنده هستند.
    
- یعنی قبل از Port Scanning، دیگه ICMP Ping یا TCP/ARP Ping انجام نمی‌ده.
    

---

## 🎯 کاربرد اصلی

1. وقتی ICMP یا روش‌های host discovery توسط فایروال بلاک شده.
    
2. وقتی می‌خوای مستقیم پورت‌ها رو اسکن کنی حتی اگه سیستم‌ها به پینگ جواب ندن.
    
3. در شبکه‌هایی که stealth مهمه و نمی‌خوای بسته‌های ping شناسایی‌ت کنن.
    

---

## ⚙️ مثال

```bash
nmap -Pn 192.168.1.10
```

این یعنی بدون تست Alive بودن، مستقیم میره سراغ اسکن پورت‌ها.

یا برای کل شبکه:

```bash
nmap -Pn 192.168.1.0/24
```

---

## ⚠️ نکته از دید Attacker

- مزیت: می‌تونه سرویس‌ها رو حتی روی سیستم‌هایی که پینگ نمی‌دن کشف کنه.
    
- عیب: زمان اسکن زیاد میشه چون Nmap همه IPها رو اسکن می‌کنه، حتی اگه خاموش باشن.
    
- گاهی باعث ترافیک اضافه و لو رفتن بیشتر میشه.

## SCTP ----> Simple Control Transmission Protocol

پروتکل ==انتقال کنترل جریان (SCTP) یک پروتکل لایه انتقال است که در شبکه‌های کامپیوتری برای انتقال داده‌ها استفاده می‌شود==. این پروتکل ویژگی‌های هر دو پروتکل TCP و UDP را ارائه می‌دهد و برای انتقال داده‌های قابل اعتماد و متوالی با کنترل ازدحام و همچنین پشتیبانی از چندین جریان داده‌ای در یک اتصال واحد طراحی شده است

پروتکل SCTP یک پروتکل لایه انتقال (transport layer) در مدل TCP/IP است. به عبارت دیگر، SCTP یک پروتکل لایه چهارم است و وظیفه انتقال داده‌ها بین برنامه‌های کاربردی در شبکه‌های کامپیوتری را بر عهده دارد.

ویژگی‌های اصلی SCTP:

- **اتصال‌گرا:**
    
    SCTP یک پروتکل اتصال‌گرا است، به این معنی که قبل از انتقال داده، یک اتصال بین دو نقطه پایانی برقرار می‌شود. 
    
- **پیام‌گرا:**
    
    برخلاف TCP که مبتنی بر جریان بایت است، SCTP یک پروتکل پیام‌گرا است و داده‌ها را در پیام‌های مجزا ارسال می‌کند. 
    
- **قابلیت اطمینان و توالی:**
    
    SCTP انتقال داده‌ها را به صورت متوالی و با قابلیت اطمینان تضمین می‌کند و از از دست رفتن یا تکرار پیام‌ها جلوگیری می‌کند. 
    
- **کنترل ازدحام:**
    
    SCTP از مکانیسم‌های کنترل ازدحام برای جلوگیری از اشباع شبکه استفاده می‌کند. 
    
- **Multi-homing:**
    
    SCTP به یک هاست اجازه می‌دهد تا چندین آدرس IP داشته باشد و با استفاده از این قابلیت، انعطاف‌پذیری و قابلیت اطمینان بیشتری را فراهم می‌کند. 
    
- **Multi-streaming:**
    
    SCTP می‌تواند چندین جریان داده‌ای را به طور همزمان در یک اتصال واحد پشتیبانی کند. 
    

کاربردهای SCTP:

- **شبکه‌های مخابراتی:**
    
    SCTP در ابتدا برای انتقال پیام‌های سیگنالینگ در شبکه‌های تلفن همراه (SS7) استفاده می‌شد. 
    
- **برنامه‌های چندرسانه‌ای:**
    
    به دلیل قابلیت چندجریانی (multi-streaming)، SCTP برای انتقال داده‌های چندرسانه‌ای مانند صدا و تصویر که نیاز به انتقال همزمان چند جریان داده‌ای دارند، مناسب است. 
    
- **برنامه‌های توزیع‌شده:**
    
    SCTP به دلیل قابلیت اطمینان و پشتیبانی از multi-homing، برای برنامه‌های توزیع‌شده که نیاز به ارتباط پایدار و قابل اعتماد بین گره‌های مختلف دارند، کاربرد دارد
