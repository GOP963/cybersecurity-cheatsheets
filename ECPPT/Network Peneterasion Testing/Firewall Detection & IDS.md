## 1️⃣ Firewall Detection (تشخیص فایروال)

فایروال‌ها معمولاً یا **پورت‌ها رو بلاک می‌کنن** یا **ترافیک رو فیلتر می‌کنن**. با چند روش میشه تشخیص داد:

### 🔹 روش‌ها

#### **1. Nmap Firewalking**

- تست کردن پورت‌ها برای پیدا کردن جایی که بسته‌ها Drop میشن.
    

```bash
nmap -Pn --traceroute <target>
```

- وقتی مسیر ردیابی میشه، اگه در یک hop بسته‌ها قطع شن → احتمال وجود فایروال هست.
    

#### **2. TCP ACK Scan**

- با سوییچ `-sA` در Nmap.
    
- هدف: تشخیص پورت‌هایی که توسط فایروال فیلتر شدن.
    

```bash
nmap -sA <target>
```

- پورت‌های **unfiltered** با RST جواب میدن، فیلترشده‌ها جواب نمیدن.
    

#### **3. بسته‌های عجیب (Malformed Packets)**

- ارسال بسته‌های ناقص یا غیرعادی و بررسی واکنش.
    
- بعضی فایروال‌ها بسته‌های غیر استاندارد رو Drop می‌کنن.
    

#### **4. TTL Expiry Trick**

- تغییر TTL برای دیدن اینکه بسته‌ها از چه hop رد میشن و کجا Drop میشن.

## 2️⃣ IDS / IPS Detection (تشخیص سیستم‌های تشخیص نفوذ)

IDS (Intrusion Detection System) و IPS (Intrusion Prevention System) معمولاً به دنبال **الگوهای ترافیکی مشکوک** هستن.

### 🔹 روش‌ها

#### **1. Nmap Idle Scan (`-sI`)**

- استفاده از یک Host زامبی برای اسکن → کمترین احتمال شناسایی.
    

```bash
nmap -sI zombie_host target
```

#### **2. تغییر سرعت و زمان‌بندی**

- با `-T0` یا `-T1` خیلی آهسته اسکن کردن، چون IDS روی burstهای سریع حساسه.
    

```bash
nmap -sS -T1 <target>
```

#### **3. Fragmentation (`-f`)**

- شکستن بسته‌ها به تکه‌های کوچک‌تر برای سخت‌تر کردن تشخیص.
    

```bash
nmap -f <target>
```

#### **4. Bypass با تغییر MTU**

- تغییر اندازه بسته:
    

```bash
nmap --mtu 24 <target>
```

#### **5. ارسال Probeهای تصادفی**

- اضافه کردن داده‌های الکی به بسته‌ها (`--data-length`):
    

```bash
nmap --data-length 25 <target>
```

## 💡 نشانه‌های وجود IDS/IPS

- قطع شدن موقتی اتصال هنگام اسکن.
    
- دریافت **بسته‌های Reset** ناگهانی بعد از چند probe.
    
- وجود تاخیر یا drop شدن بسته‌ها وقتی الگوهای خاص ارسال میشن.
    
- افزایش پاسخ‌های ICMP type 3 (destination unreachable).
    

---

📍 **ترفند Attacker:**

- اول با یک **اسکن آرام و غیرتهاجمی** (`-sS -T2`) شروع کن.
    
- بعد تست تکنیک‌های **evade** (`-f`, `--mtu`, `--data-length`) رو اضافه کن.
    
- خروجی رو با اسکن عادی مقایسه کن → هر تفاوتی می‌تونه نشانه وجود فایروال یا IDS باشه.
