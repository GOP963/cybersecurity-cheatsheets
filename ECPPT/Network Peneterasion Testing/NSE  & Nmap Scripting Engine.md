## 📌 NSE چیست؟

**NSE** مخفف **Nmap Scripting Engine** هست.  
این قابلیت به Nmap اجازه میده با استفاده از **اسکریپت‌های Lua** کارهایی فراتر از یک اسکن ساده انجام بده، مثل:

- شناسایی دقیق‌تر سرویس‌ها
    
- پیدا کردن آسیب‌پذیری‌ها
    
- تست امنیتی سرویس‌ها
    
- حتی اجرای اکسپلویت‌های ساده
    



زبان Lua ==یک زبان برنامه‌نویسی اسکریپتی سبک و قدرتمند است که به طور گسترده در توسعه بازی‌ها==، برنامه‌های کاربردی و ابزارهای مختلف استفاده می‌شود. این زبان به دلیل سادگی، انعطاف‌پذیری و سرعت بالا، به عنوان یک زبان محبوب برای جاسازی در برنامه‌های نوشته شده به زبان‌های دیگر شناخته می‌شود

## 🎯 کاربردهای NSE

اسکریپت‌های NSE در دسته‌های زیر تقسیم میشن:

1. **Discovery**  
    پیدا کردن سرویس‌ها و منابع در شبکه  
    مثال: کشف مسیرهای HTTP
    
    ```bash
    nmap --script=http-enum 192.168.1.10
    ```
    
2. **Vulnerability**  
    تست وجود باگ‌های شناخته‌شده (CVE ها)  
    مثال: تست MS17-010 (EternalBlue)
    
    ```bash
    nmap --script=smb-vuln-ms17-010 192.168.1.10
    ```
    
3. **Auth**  
    تست احراز هویت ضعیف یا پیش‌فرض  
    مثال: تست لاگین FTP با پسوردهای پیش‌فرض
    
    ```bash
    nmap --script=ftp-anon 192.168.1.10
    ```
    
4. **Brute**  
    حملات Brute Force روی سرویس‌ها  
    مثال: SSH Brute Force
    
    ```bash
    nmap --script=ssh-brute 192.168.1.10
    ```
    
5. **Safe**  
    اسکریپت‌های غیرتهاجمی که بدون خرابکاری فقط اطلاعات جمع‌آوری می‌کنن.

## ⚙️ ساختار کلی اجرای NSE

```bash
nmap --script=<script-name> <target>
```

یا اجرای چند اسکریپت:

```bash
nmap --script=smb-enum-users,smb-enum-shares 192.168.1.10
```

یا اجرای یک دسته کامل:

```bash
nmap --script=vuln 192.168.1.10
```

## 🔍 نکته مهم از دید Attacker

- NSE در واقع **یک mini-exploit framework** داخل Nmapه.
    
- می‌تونی بدون نیاز به ابزار اضافی، هم اسکن و هم تست آسیب‌پذیری رو یک‌جا انجام بدی.
    
- اسکریپت‌ها تو مسیر `/usr/share/nmap/scripts/` ذخیره شدن و قابل ویرایش یا ساخت اسکریپت جدید هستن.
