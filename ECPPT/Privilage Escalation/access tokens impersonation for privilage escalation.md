## **۱. Windows Access Token چیست؟**

- **Access Token** یک **ساختار داده‌ای در ویندوز** است که وقتی کاربری وارد سیستم می‌شود ایجاد می‌شود.
    
- این توکن شامل اطلاعات مهم امنیتی است، مثل:
    
    - **User SID** (شناسه کاربر)
        
    - **Group SIDs** (گروه‌های کاربر)
        
    - **Privilegeها** (مثل SeDebugPrivilege، SeImpersonatePrivilege و …)
        
    - **Ownership و Session ID**
        
- ویندوز برای هر **فرایند و thread** از این توکن استفاده می‌کند تا مشخص کند چه عملیاتی مجاز است انجام شود.
    
- به طور ساده: **Access Token مثل کارت شناسایی دیجیتال است که به سیستم می‌گوید این کاربر چه کارهایی می‌تواند انجام دهد.**
    

---

## **۲. Access Token Impersonation چیست؟**

- **Impersonation** یعنی اینکه یک فرایند یا thread از **توکن یک کاربر دیگر (معمولاً با دسترسی بالاتر)** استفاده کند تا عملیات را با سطح دسترسی آن کاربر انجام دهد.
    
- در تست نفوذ و privilege escalation:
    
    - شما ممکن است دسترسی محدود داشته باشید، اما یک فرایند دیگر با دسترسی بالا (مثل SYSTEM) در سیستم اجرا شود.
        
    - با **دزدیدن یا استفاده از توکن آن فرایند** می‌توانید **سطح دسترسی خود را ارتقا دهید**.
        

---

## **۳. Privilege Escalation via Access Token Impersonation**

- ایده اصلی:
    
    1. شناسایی فرایندهایی که توکن با دسترسی بالاتر دارند (مثلاً SYSTEM یا Administrator).
        
    2. گرفتن توکن آن‌ها (با دسترسی‌های لازم، معمولاً SeImpersonatePrivilege).
        
    3. ایجاد یک فرایند جدید یا اجرای دستور با **سطح دسترسی بالاتر** از طریق آن توکن.
        
- مثال رایج در Meterpreter:
    
    ```bash
    getsystem
    ```
    
    - این دستور تلاش می‌کند با استفاده از **token impersonation** به SYSTEM دسترسی پیدا کند.
        
- ابزارهای دیگر:
    
    - `incognito` در Meterpreter برای لیست و استفاده از توکن‌های موجود در سیستم.
        

---

### **خلاصه ساده:**

|مفهوم|توضیح|
|---|---|
|Access Token|کارت شناسایی دیجیتال کاربر در ویندوز که مشخص می‌کند چه عملیاتی مجاز است.|
|Impersonation|استفاده از توکن کاربر دیگر برای اجرای عملیات با سطح دسترسی او.|
|Privilege Escalation via Token|گرفتن توکن یک کاربر با دسترسی بالاتر و اجرای دستور با سطح دسترسی او.|
