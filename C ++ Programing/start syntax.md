## **ساختار برنامه C++**

ساختار پایه یک برنامه C++ **روش استاندارد نوشتن هر برنامه را تعریف می‌کند**؛ در غیر این صورت، خطای کامپایل ایجاد می‌شود. این ساختار شامل موارد زیر است:

- **فایل هدر (Header File):**  
    `#include <iostream>`
    اشیای ورودی/خروجی مثل `cin` و `cout` را از طریق پیش‌پردازنده اضافه می‌کند.  
    هدرهای رایج:  
    `fstream`
     (کار با فایل‌ها)، `string` (رشته‌ها)، `vector` (STL)، `bits/stdc++.h` (همه‌چیز در یکجا)
    
- **اعلان فضای نام (Namespace Declaration):**  
    `using namespace std;`
     امکان استفاده مستقیم از نام‌های استاندارد مانند `cout` بدون نیاز به `std::` را فراهم می‌کند.
    
- **تابع اصلی (Main Function):**  
    `int main()`
     نقطه شروع برنامه است؛ اجرا از اینجا شروع می‌شود و عدد صحیحی برمی‌گرداند، که ۰ نشان‌دهنده اجرای موفق برنامه است.
    
- **کامنت‌ها (Comments):**  
    `//` برای یک خط، `/* ... */` برای چند خط  
    این خطوط توسط کامپایلر نادیده گرفته می‌شوند و فقط برای مستندسازی کد استفاده می‌شوند.
    
- **دستور (Statement):**  
    شامل کد قابل اجراست.  
    مثال: `cout << "Hello World!";` متن را روی صفحه با استفاده از عملگر درج (`<<`) چاپ می‌کند.
    
- **بازگشت (Return):**  
    دستور `return 0;` تابع `main()` را پایان می‌دهد و نشان می‌دهد برنامه با موفقیت اجرا شده است.
