


در زبان++ C داده ها به وسیله Streams ها یا همان جریان ها خوانده و نوشته میشوند Sreams یعنی دنباله یی از بایت ها 

- **Input Stream (جریان ورودی):** 
- داده از یک دستگاه (مثل کیبورد) وارد حافظهٔ کامپیوتر می‌شود.
    
- **Output Stream (جریان خروجی):**
- داده از حافظه به یک دستگاه خروجی (مثل صفحه‌نمایش)

این جریان‌ها در هدر **<iostream** تعریف شده‌اند.  
رایج‌ترین اشیای استریم در ++C عبارت‌اند از:

- `cin` → برای دریافت ورودی
    
- `cout` → برای نمایش خروجی
---
## **جریان ورودی استاندارد – cin**

`cin`
یک نمونه از کلاس **istream** است و برای گرفتن ورودی از کیبورد استفاده می‌شود.  
برای دریافت داده و قرار دادن آن در یک متغیر از **عملگر استخراج (Extraction Operator)** یعنی `>>` استفاده می‌کنیم.

```c++
#include <iostream>
using namespace std;

int main()
{
    int age;

    // Taking input from user and store it in variable
    cin >> age;

    // Output the entered age
    cout << "Age entered: " << age;
    
    return 0;
}
```


در این برنامه کاربر کا باید یه مقدار از نوع int وارد کنه اگر مقداری که میده datatype به غیر از int باشه برنامه یک خطایی رو تولید میکنه 
ما به دو صورت میتونیم ورودی مون رو کنترول کنیم و متوجه این موضو بشیم که کاربر چه دیتایی رو وارد میکنه 

معمولا اگر خروجی که ما به غیر از int بدیم و برگردونه 0 باشه یعنی مقداری که دادیم اشتباه 


ما یه سری از فانکشن هایی دیگری رو هم داریم که به اسم clog,cerr 

این فانکشن ها برای نمایش خطا ها، لاگ ها استفاده میشوند و هر دو در اصل یه کاری میکنن با این تفاوت که 

فانکشن clog برای لاگ کردن اطلاعات لاگ برنامه در بروز خطا را نمایش میدهد که این اطلاعات در قدم بعدی برای debug کردن هم استفاده بشود

# 🔥 **مرور حرفه‌ای روی Input/Output Streams در C++**

در C++ همهٔ ورودی/خروجی‌ها بر پایهٔ یک سیستم به نام **streams** کار می‌کنند.  
مهم‌ترین خروجی‌ها:

- `std::cout` → خروجی عادی برنامه (Normal Output)
    
- `std::cerr` → خروجی خطاها (Unbuffered Error Output)
    
- `std::clog` → خروجی خطاهای عادی (Buffered Log Output)
    

حالا دقیق و با مثال توضیح می‌دم 👇

---

# 🟥 **1. std::cerr — برای پیام‌های خطا (بدون بافر)**

`std::cerr` برای چاپ پیام‌های خطا استفاده می‌شود.

ویژگی مهمش:

### 🚨 **Unbuffered** = فوراً روی خروجی چاپ می‌شود.

یعنی حتی اگر برنامه crash کند یا هنوز flush نشده باشد،  
پیام خطا **قطعاً** چاپ شده است.

این برای ابزارهای امنیتی، سیستم‌های real-time، logging‌های مهم و… حیاتی است.

### مثال:

```cpp
#include <iostream>

int main() {
    std::cerr << "Error: Something went wrong!" << std::endl;
}
```

حتی اگر برنامه بعد از این خط crash کند،  
پیام خطا دیگر در بافر نیست — چاپ شده.

---

# 🟦 **2. std::clog — برای لاگ‌ها و دیباگ (بافر دارد)**

`std::clog` نوعی خروجی برای **لاگ نوشتن** است.

ویژگی مهم:

### 📝 **Buffered** = پیام‌ها ابتدا در بافر می‌مانند و بعد چاپ می‌شوند.

مزیت؟

- سرعت بالاتر
    
- مناسب برای حجم زیاد لاگ
    

عیب؟

- اگر برنامه ناگهان crash کند،  
    ممکن است آخرین لاگ‌ها هنوز flush نشده باشند.
    

مثال:

```cpp
#include <iostream>

int main() {
    std::clog << "Program started..." << std::endl;
    std::clog << "Loading configuration..." << std::endl;
}
```

---

# 🟩 **3. تفاوت std::cout با std::cerr و std::clog**

|Stream|نوع خروجی|بافر؟|کاربرد|
|---|---|---|---|
|`std::cout`|خروجی معمولی|**بافر دارد**|نتایج عادی برنامه|
|`std::cerr`|پیام خطا|**بدون بافر**|خطاهایی که باید فوری چاپ شوند|
|`std::clog`|پیام لاگ/دیباگ|**بافر دارد**|گزارش‌های برنامه|

---

# 🎯 **چرا std::cerr و std::clog مهم‌اند؟**

در برنامه‌های حرفه‌ای:

- خروجی معمولی → `std::cout`
    
- اطلاعات دیباگ/لاگ → `std::clog`
    
- پیام خطا → `std::cerr`
    

حتی ابزارهای لینوکسی مثل:

- grep
    
- cut
    
- python
    
- curl  
    همگی خطاها را روی stderr می‌فرستند.
    

این باعث می‌شود بتوانیم خروجی را redirect کنیم بدون اینکه خطاها هم قاطی شوند.

# 🧪 **4. مثال عملی با Redirect در لینوکس/ویندوز**

### مثلا:

```bash
./app > output.txt
```

- `std::cout` → در `output.txt`
    
- `std::cerr` → همچنان روی صفحه
    

اگر بخواهیم خطاها هم بروند داخل فایل:

```bash
./app 2> errors.txt
```

یا:

```bash
./app > out.txt 2> err.txt
```

خروجی‌ها جدا می‌شوند.

# 🚀 **5. مثال کامل که cout و cerr و clog را کنار هم نشان می‌دهد**

```cpp
#include <iostream>

int main() {
    std::cout << "This is normal output.\n";
    std::clog << "This is a log message.\n";
    std::cerr << "This is an error message!\n";
    return 0;
}
```

---



```
<< ---> insertion operator 
>> ---> Extraction Opereator
```

**Extraction operator**
زمانی استفاده میشود که بخواهیم یک دیتایی رو از کیبورد بگیریم و در نهایت در حافظه برنامه ذخیره کنیم و روش عملایت انجام بدیم 

**insertion operator**
این معکوس Extraction Opereator هست یعنی یک دیتایی که از قبل توسط برنامه نویس نوشته شده پردازش و در نهایت از به کاربر یعنی صفحه نمایش نشان داده میشود
