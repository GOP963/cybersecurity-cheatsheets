## دستورات کنترل جریان (Control Flow) در برنامه‌نویسی

**آخرین به‌روزرسانی: 23 جولای 2025**

کنترل جریان (Control Flow) به **ترتیبی** اشاره دارد که دستورات داخل یک برنامه اجرا می‌شوند.  
در حالت عادی، برنامه‌ها دستورات را **به‌صورت ترتیبی از بالا به پایین** اجرا می‌کنند، اما در بسیاری از مواقع به **انعطاف‌پذیری بیشتری** نیاز داریم.

این مقاله به‌صورت شفاف، تمام چیزهایی که باید درباره‌ی **دستورات کنترل جریان** بدانید را توضیح می‌دهد.

## دستورات کنترل جریان در برنامه‌نویسی چیست؟

دستورات کنترل جریان اجزای **اساسی و بنیادین** زبان‌های برنامه‌نویسی هستند که به برنامه‌نویس اجازه می‌دهند **ترتیب اجرای دستورات** را کنترل کند.

این دستورات امکان انجام کارهای زیر را فراهم می‌کنند:

- اجرای چندباره‌ی یک بلوک کد
    
- اجرای کد بر اساس یک شرط
    
- متوقف کردن یا رد کردن اجرای بعضی خطوط کد
    
- خروج از توابع یا حلقه‌ها
    

---

## انواع دستورات کنترل جریان در برنامه‌نویسی

### 1️⃣ دستورات شرطی (Conditional Statements)

|دستور|توضیح|
|---|---|
|`if-else`|اگر شرط برقرار باشد یک بلوک اجرا می‌شود، در غیر این صورت بلوک دیگری اجرا می‌شود|
|`switch-case`|مقدار یک متغیر یا عبارت را بررسی کرده و بر اساس caseهای مختلف کد مناسب را اجرا می‌کند|

---

### 2️⃣ دستورات حلقه‌ای (Looping Statements)

|دستور|توضیح|
|---|---|
|`for`|یک بلوک کد را تعداد مشخصی بار اجرا می‌کند|
|`while`|تا زمانی که شرط برقرار باشد کد را اجرا می‌کند|
|`do-while`|حداقل یک‌بار کد را اجرا می‌کند و سپس شرط را بررسی می‌کند|

---

### 3️⃣ دستورات پرش (Jump Statements)

| دستور      | توضیح                                                                    |
| ---------- | ------------------------------------------------------------------------ |
| `break`    | حلقه یا switch را متوقف کرده و از آن خارج می‌شود                         |
| `continue` | اجرای iteration فعلی را رد کرده و به iteration بعدی می‌رود               |
| `return`   | از تابع خارج شده و مقدار (در صورت وجود) برمی‌گرداند                      |
| `goto`     | کنترل برنامه را به یک برچسب مشخص منتقل می‌کند (⚠️ معمولاً توصیه نمی‌شود) |

## دستورات شرطی در برنامه‌نویسی

دستورات شرطی برای **تصمیم‌گیری در برنامه** استفاده می‌شوند و مشخص می‌کنند که کدام بخش از کد اجرا شود.

---

### 1️⃣ دستور if

اگر شرط درست باشد، کد داخل if اجرا می‌شود.

```cpp
int a = 5;
if (a == 5) {
    cout << "a is equal to 5";
}
```

**خروجی:**

```
a is equal to 5
```

---

### 2️⃣ دستور if-else

اگر شرط برقرار باشد یک بلوک اجرا می‌شود، وگرنه بلوک دیگر.

```cpp
int a = 10;
if (a == 5) {
    cout << "a is equal to 5";
} else {
    cout << "a is not equal to 5";
}
```

**خروجی:**

```
a is not equal to 5
```

---

### 3️⃣ دستور if-else-if

چند شرط به‌ترتیب بررسی می‌شوند و اگر هیچ‌کدام برقرار نباشد، بلوک else اجرا می‌شود.

```cpp
int a = 15;
if (a == 5) {
    cout << "a is equal to 5";
}
else if (a == 10) {
    cout << "a is equal to 10";
}
else {
    cout << "a is not equal to 5 or 10";
}
```

**خروجی:**

```
a is not equal to 5 or 10
```

---

### 4️⃣ عملگر سه‌تایی (Ternary Operator)

برای مقداردهی یا انتخاب مقدار بر اساس شرط استفاده می‌شود.

```cpp
int a = 10;
cout << (a == 5 ? "a is equal to 5"
                : "a is not equal to 5");
```

**خروجی:**

```
a is not equal to 5
```

---

### 5️⃣ دستور switch

برای انتخاب بین چند حالت مختلف بر اساس مقدار یک متغیر استفاده می‌شود.

```cpp
int a = 15;
switch (a) {
case 5:
    cout << "a is equal to 5";
    break;
case 10:
    cout << "a is equal to 10";
    break;
default:
    cout << "a is not equal to 5 or 10";
}
```

**خروجی:**

```
a is not equal to 5 or 10
```

## دستورات حلقه‌ای در برنامه‌نویسی

حلقه‌ها برای **اجرای تکراری یک بلوک کد** استفاده می‌شوند.

---

### 1️⃣ حلقه for

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

**خروجی:**

```
0
1
2
3
4
```

---

### 2️⃣ حلقه while

تا زمانی که شرط برقرار باشد اجرا می‌شود.

```java
int count = 0;
while (count < 5) {
    System.out.println(count);
    count++;
}
```

---

### 3️⃣ حلقه do-while

حداقل یک‌بار اجرا می‌شود، سپس شرط بررسی می‌شود.

```java
int count = 0;
do {
    System.out.println(count);
    count++;
} while (count < 5);
```

---

### 4️⃣ حلقه‌های تو در تو (Nested Loops)

```java
for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 2; j++) {
        System.out.println("i=" + i + " j=" + j);
    }
}
```

**خروجی:**

```
i=0 j=0
i=0 j=1
i=1 j=0
i=1 j=1
```

## دستورات پرش در برنامه‌نویسی

این دستورات مسیر اجرای برنامه را تغییر می‌دهند.

---

### 1️⃣ دستور break

برای خروج فوری از حلقه استفاده می‌شود.

```java
for (int i = 0; i < 10; i++) {
    if (i == 5)
        break;
    System.out.print(i + " ");
}
```

**خروجی:**

```
0 1 2 3 4
```

---

### 2️⃣ دستور continue

iteration فعلی را رد کرده و به iteration بعدی می‌رود.

```java
for (int i = 0; i < 10; i++) {
    if (i % 2 == 1)
        continue;
    System.out.print(i + " ");
}
```

**خروجی:**

```
0 2 4 6 8
```

---

### 3️⃣ دستور return

از تابع خارج می‌شود و مقدار برمی‌گرداند.

```java
static boolean isEven(int N) {
    return N % 2 == 0;
}
```

---

### 4️⃣ دستور goto

کنترل برنامه را به یک برچسب خاص منتقل می‌کند (⚠️ معمولاً توصیه نمی‌شود).

```cpp
int i = 0;
loopStart:
if (i < 5) {
    cout << i << " ";
    i++;
    goto loopStart;
}
```

**خروجی:**

```
0 1 2 3 4
```
