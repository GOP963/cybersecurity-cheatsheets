# 🔷 **Vector در C++ چیست؟**

`vector` یک **Dynamic Array** یا **آرایه پویا** در C++ است که داخل کتابخانهٔ استاندارد STL قرار دارد:

```cpp
#include <vector>
```

ویژگی اصلی vector این است که:

### ✅ اندازه‌اش **پویا** است — یعنی می‌تواند در زمان اجرا بزرگ و کوچک شود

### ✅ مدیریت حافظه را خودش انجام می‌دهد

### ✅ توابع آماده برای کارهای مختلف دارد (مثل اضافه‌کردن، حذف‌کردن و …)

مثال ساده:

```cpp
#include <vector>
using namespace std;

int main() {
    vector<int> nums;
    nums.push_back(10);
    nums.push_back(20);
    nums.push_back(30);
}
```

# 🔥 تفاوت vector و array در C++

این قسمت را **خیلی شفاف** به‌صورت جدول برات نوشتم:

---

## 🆚 **Vector vs Array**

|ویژگی|`array[]` سنتی|`vector`|
|---|---|---|
|**نوع حافظه**|Static (ثابت)|Dynamic (پویا)|
|**تغییر اندازه**|❌ امکان تغییر اندازه ندارد|✔️ اندازه در runtime تغییر می‌کند|
|**مدیریت حافظه**|روی stack (اگر static باشد)|روی heap (مدیریت خودکار)|
|**امنیت حافظه**|ضعیف (احتمال out-of-bounds بالا)|بهتر (چک کردن مرزها با `at()`)|
|**توابع کمکی**|ندارد|دارد: push_back، pop_back، size، clear و …|
|**سرعت**|کمی سریع‌تر چون ساده‌تر است|کمی کندتر بخاطر عملیات داخلی|
|**استفاده**|برای داده‌های کوچک و ثابت|برای داده‌های متغیر و بزرگ|
|**کپی کردن**|دستی و سخت|راحت و با overloadهای استاندارد|
|**پشتیبانی STL**|❌ ندارد|✔️ کامل پشتیبانی می‌شود|

---

# 🔷 مثال تفاوت

## **Array: اندازه ثابت**

```cpp
int arr[3] = {1, 2, 3};
// arr[3] = 4;  // خطا! چون جا ندارد
```

---

## **Vector: قابل گسترش**

```cpp
vector<int> v = {1, 2, 3};
v.push_back(4);   // اضافه می‌شود
```

---

# 🔥 چرا vector بهتر است؟

چون:

- با بزرگ و کوچک شدن خودش **حافظه را مدیریت می‌کند**
    
- تابع‌های مفید دارد
    
- امن‌تر است
    
- با الگوریتم‌های STL کاملاً سازگار است
    

---

# ⭐ چه زمانی array بهتر از vector است؟

وقتی:

- اندازه از قبل ثابت و کوچک است
    
- نیاز به سرعت بالاتر دارید
    
- حافظه محدود است (مثلاً در embedded systems)
    

---

# 🔥 خلاصهٔ خیلی کوتاه

**Array = اندازه ثابت**  
**Vector = اندازه پویا + امکانات زیاد**
