در زبان c/c++ ما موقعی داریم یک pointer میسازیم ممکن است که این pointer به یک آدرسی اشاره کند که این آدرس یا آزاد شده باشد یا مقدارش غلط باشد که در این حالت اتفاقی می افتد به اسم **Dangling Pointer** 
یعنی اشاره گری مقدار دارد ولی ادرسش غلط یا آزاد شده 

مثلا 

```c++
int *test(){
	int *x = new int{10};
	delete x;
	printf("%d",&x);
	return x;
}
```

ما الان میخواهیم ادرس یک حافظه یی رو چاپ کنیم که اصلا وجود ندارد این یعنی **Dangling Pointer**
