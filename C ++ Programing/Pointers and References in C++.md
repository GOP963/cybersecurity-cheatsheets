

در زبان ++C، هم **اشاره‌گرها (Pointers)** و هم **ارجاع‌ها (References)** مکانیزم‌هایی برای کار با حافظه، آدرس حافظه و داده‌ها در یک برنامه هستند.  
اشاره‌گرها برای ذخیره‌ی **آدرس حافظه‌ی یک متغیر دیگر** استفاده می‌شوند، در حالی که رفرنس‌ها برای ایجاد یک **نام مستعار (alias)** برای یک متغیر از قبل موجود به کار می‌روند.

---

## اشاره‌گرها در ++C

اشاره‌گرها در ++C نمایش نمادین آدرس‌ها هستند. آن‌ها به برنامه‌ها این امکان را می‌دهند که **Call-by-Reference** را شبیه‌سازی کنند و ساختارهای داده‌ی پویا (Dynamic Data Structures) را ایجاد و مدیریت کنند.  
اشاره‌گرها آدرس متغیرها یا یک محل از حافظه را ذخیره می‌کنند.

### سینتکس

```cpp
datatype *var_name;
```

مثال:

```cpp
int *ptr; // ptr به آدرسی اشاره می‌کند که داده‌ای از نوع int در آن قرار دارد
```

---

## مثال اشاره‌گرها در ++C

برنامه‌ی زیر نحوه‌ی استفاده از اشاره‌گرها در ++C را نشان می‌دهد:

```cpp
#include <iostream>
using namespace std;

int main()
{
    int x = 10;   // تعریف متغیر
    int* myptr;  // تعریف اشاره‌گر

    // ذخیره آدرس x در اشاره‌گر myptr
    myptr = &x;

    cout << "Value of x is: ";
    cout << x << endl;

    // چاپ آدرسی که در اشاره‌گر myptr ذخیره شده است
    cout << "Address stored in myptr is: ";
    cout << myptr << endl;

    // چاپ مقدار x با استفاده از اشاره‌گر
    cout << "Value of x using *myptr is: ";
    cout << *myptr << endl;

    return 0;
}
```

### خروجی

```
Value of x is: 10
Address stored in myptr is: 0x7ffd2b32c7f4
Value of x using *myptr is: 10
```

### توضیح

در این برنامه یک متغیر عدد صحیح به نام `x` با مقدار اولیه‌ی ۱۰ تعریف شده و یک اشاره‌گر به نام `myptr` ایجاد می‌شود.  
آدرس حافظه‌ی `x` در `myptr` ذخیره می‌شود. سپس مقدار `x`، آدرس ذخیره‌شده در `myptr` و مقدار `x` با Dereference کردن اشاره‌گر (`*myptr`) چاپ می‌شود.

## کاربردهای اشاره‌گرها در ++C

کاربردهای مهم اشاره‌گرها عبارت‌اند از:

- **ارسال آرگومان‌ها به‌صورت Reference**
    
- **دسترسی به عناصر آرایه** (کامپایلر در سطح داخلی از اشاره‌گرها استفاده می‌کند)
    
- **برگرداندن چند مقدار از یک تابع** (مثل مربع و ریشه‌ی مربع یک عدد)
    
- **مدیریت حافظه‌ی پویا (Dynamic Memory Allocation)**  
    حافظه‌ی پویا تا زمانی که به‌صورت صریح آزاد نشود، حذف نمی‌شود
    
- **پیاده‌سازی ساختمان داده‌ها**
    
- **برنامه‌نویسی سطح سیستم** که در آن کار با آدرس حافظه اهمیت دارد

## ویژگی‌ها و استفاده‌های اشاره‌گرها در ++C

اشاره‌گرها ویژگی‌ها و کاربردهای مهمی دارند؛ مانند:

- صرفه‌جویی در فضای حافظه
    
- تخصیص پویا‌ی حافظه
    
- استفاده در مدیریت فایل‌ها
    

اشاره‌گرها آدرس متغیرها یا یک محل از حافظه را ذخیره می‌کنند.

مثال:

```cpp
int *ptr;
```

در اینجا اشاره‌گر `ptr` آدرس یک متغیر عدد صحیح یا آدرس حافظه‌ای را نگه می‌دارد که مقدار آن می‌تواند به‌صورت عدد صحیح تفسیر شود.

## اشاره‌گر `this` در ++C

اشاره‌گر `this` به‌صورت یک آرگومان مخفی به تمام توابع عضو **غیر ایستا (non-static)** ارسال می‌شود و در بدنه‌ی این توابع به‌عنوان یک متغیر محلی در دسترس است.  
اشاره‌گر `this` در توابع عضو **static** وجود ندارد، چون توابع static بدون نیاز به یک شیء (و فقط با نام کلاس) قابل فراخوانی هستند.

حتی اگر فقط یک نسخه از هر تابع عضو وجود داشته باشد که توسط چندین شیء استفاده می‌شود، کامپایلر یک اشاره‌گر ضمنی به نام `this` را همراه با فراخوانی تابع ارسال می‌کند.

مثال:

```cpp
this->x = x;
```

## رفرنس‌ها (References) در ++C

وقتی یک متغیر به‌صورت Reference تعریف می‌شود، به یک **نام جایگزین برای یک متغیر موجود** تبدیل می‌شود.  
برای تعریف Reference از علامت `&` در اعلان استفاده می‌شود.

سه روش برای ارسال آرگومان‌ها به توابع در ++C وجود دارد:

1. ارسال به‌صورت مقدار (call-by-value)
    
2. ارسال به‌صورت Reference با استفاده از اشاره‌گر
    
3. ارسال به‌صورت Reference با استفاده از رفرنس
    

---

## مثال رفرنس‌ها در ++C

برنامه‌ی زیر نحوه‌ی استفاده از رفرنس‌ها را نشان می‌دهد:

```cpp
#include <iostream>
using namespace std;

int main()
{
    int y = 10;

    // myref یک رفرنس به y است
    int& myref = y;

    // تغییر مقدار y
    y = 30;

    cout << "value of y is " << y << endl;
    cout << "value of myref after change in value of y is: "
         << myref << '\n';

    return 0;
}
```

### خروجی

```
value of y is 30
value of myref after change in value of y is: 30
```

### توضیح

در این برنامه یک متغیر `y` تعریف شده و سپس یک رفرنس به نام `myref` ایجاد شده که نام مستعار `y` است.  
با تغییر مقدار `y`، مقدار `myref` نیز تغییر می‌کند، چون هر دو به یک مکان حافظه اشاره می‌کنند.

## تفاوت اشاره‌گرها و رفرنس‌ها

هر دو (اشاره‌گر و رفرنس) می‌توانند:

- متغیرهای محلی یک تابع را در تابع دیگر تغییر دهند
    
- از کپی شدن اشیای بزرگ هنگام ارسال به توابع جلوگیری کنند و کارایی را افزایش دهند
    

با این حال تفاوت‌های مهمی دارند:

- یک اشاره‌گر می‌تواند از نوع `void` باشد، اما رفرنس هرگز نمی‌تواند `void` باشد  
    مثال:
    
    ```cpp
    int a = 10;
    
    void* aa = &a; // معتبر
    void& ar = a;  // نامعتبر
    ```
    
- رفرنس‌ها قدرت کمتری نسبت به اشاره‌گرها دارند
    
- پس از ایجاد یک رفرنس، نمی‌توان آن را به شیء دیگری متصل کرد (reseat نمی‌شود)
    
- رفرنس نمی‌تواند `NULL` باشد، اما اشاره‌گر می‌تواند `NULL` شود
    
- رفرنس باید حتماً هنگام تعریف مقداردهی اولیه شود، اما اشاره‌گر چنین محدودیتی ندارد

## ارسال با اشاره‌گر (Passing by Pointer)

در این روش، **آدرس حافظه‌ی متغیرها** به‌عنوان پارامتر به تابع ارسال می‌شود و عملیات روی آن آدرس انجام می‌گیرد.  
به این روش **Call by Pointer** نیز گفته می‌شود.

### مثال: جابه‌جایی دو عدد با استفاده از اشاره‌گر

```cpp
#include <iostream>
using namespace std;

void swap(int *x, int *y)
{
    int z = *x;
    *x = *y;
    *y = z;
}

int main()
{
    int a = 45, b = 35;
    cout << "Before Swap\n";
    cout << "a = " << a << " b = " << b << "\n";

    swap(&a, &b);

    cout << "After Swap with pass by pointer\n";
    cout << "a = " << a << " b = " << b << "\n";
}
```

### خروجی
```
Before Swap
a = 45 b = 35
After Swap with pass by pointer
a = 35 b = 45
```

## ارسال با رفرنس (Passing by Reference)

این روش به تابع اجازه می‌دهد **بدون ایجاد کپی از متغیر**، مقدار آن را تغییر دهد.  
در این حالت باید متغیرهای رفرنس تعریف شوند. آدرس حافظه‌ی متغیر ارسال‌شده و پارامتر تابع **کاملاً یکسان** است؛ بنابراین هر تغییری روی پارامتر، روی متغیر اصلی هم اعمال می‌شود.

به این روش **Call by Reference** گفته می‌شود.

### مثال: جابه‌جایی دو عدد با استفاده از رفرنس

```cpp
#include <iostream>
using namespace std;

void swap(int& x, int& y)
{
    int z = x;
    x = y;
    y = z;
}

int main()
{
    int a = 45, b = 35;
    cout << "Before Swap\n";
    cout << "a = " << a << " b = " << b << "\n";

    swap(a, b);

    cout << "After Swap with pass by reference\n";
    cout << "a = " << a << " b = " << b << "\n";
}
```

### خروجی
```
Before Swap
a = 45 b = 35
After Swap with pass by reference
a = 35 b = 45
```

## مقایسه‌ی ارسال با اشاره‌گر و ارسال با رفرنس

دانستن تفاوت این دو روش برای طراحی صحیح توابع بسیار مهم است. جدول زیر تفاوت‌های اصلی این دو را نشان می‌دهد:

### تفاوت‌های کلیدی

### نحوه‌ی ارسال آرگومان‌ها
- **اشاره‌گر:** آدرس متغیرها به تابع ارسال می‌شود  
- **رفرنس:** خود متغیر به تابع ارسال می‌شود (به‌صورت ضمنی)

### نحوه‌ی دسترسی به مقدار
- **اشاره‌گر:** با استفاده از عملگر Dereference (`*`)
- **رفرنس:** مستقیماً با نام رفرنس

### امکان تغییر آدرس (Reassignment)
- **اشاره‌گر:** می‌تواند به آدرس حافظه‌ی دیگری اشاره کند
- **رفرنس:** نمی‌تواند به آدرس دیگری متصل شود

### مقادیر مجاز
- **اشاره‌گر:** می‌تواند مقدار `NULL` یا حتی مقدار نامعتبر داشته باشد
- **رفرنس:** هرگز `NULL` نیست و همیشه به یک مقدار معتبر اشاره می‌کند

---

## تفاوت متغیر Reference و متغیر Pointer

- رفرنس در واقع **همان شیء است با یک نام دیگر** و حتماً باید به یک شیء اشاره کند
- چون رفرنس نمی‌تواند `NULL` باشد، **ایمن‌تر** از اشاره‌گر است
- اشاره‌گر می‌تواند دوباره مقداردهی شود، اما رفرنس فقط یک‌بار و هنگام تعریف مقداردهی می‌شود
- اشاره‌گر می‌تواند `NULL` باشد، اما رفرنس نمی‌تواند
- اشاره‌گر می‌تواند روی آرایه حرکت کند (با `++` و `--`)
- اشاره‌گر یک متغیر است که آدرس حافظه را نگه می‌دارد، اما رفرنس **همان آدرس حافظه‌ی شیء اصلی** را دارد
- برای دسترسی به اعضای کلاس یا ساختار:
  - اشاره‌گر از `->`
  - رفرنس از `.` استفاده می‌کند
- اشاره‌گر نیاز به Dereference (`*`) دارد، اما رفرنس مستقیماً استفاده می‌شود

## مثال عملی: تفاوت اشاره‌گر و رفرنس

برنامه‌ی زیر تفاوت‌ها را به‌صورت عملی نشان می‌دهد:

```cpp
#include <iostream>
using namespace std;

struct demo {
    int a;
};

int main()
{
    int x = 5;
    int y = 6;
    demo d;

    int* p;
    p = &x;
    p = &y; // 1. اشاره‌گر می‌تواند دوباره مقداردهی شود

    int& r = x;
    // &r = y; // 1. خطای کامپایل

    r = y; // مقدار x برابر 6 می‌شود

    p = NULL;
    // &r = NULL; // 2. خطای کامپایل

    p++; // 3. حرکت به آدرس حافظه‌ی بعدی

    r++; // 3. مقدار x برابر 7 می‌شود

    cout << &p << " " << &x << '\n'; // 4. آدرس‌ها متفاوت‌اند
    cout << &r << " " << &x << '\n'; // 4. آدرس‌ها یکسان‌اند

    demo* q = &d;
    demo& qq = d;

    q->a = 8;
    qq.a = 8;

    cout << p << '\n'; // 6. چاپ آدرس
    cout << r << '\n'; // 6. چاپ مقدار x

    return 0;
}
```

### خروجی
```
0x7ffdfc7bead8 0x7ffdfc7bead4
0x7ffdfc7bead4 0x7ffdfc7bead4
0x4
7
```

## کدام روش بهتر است؟ Passing by Pointer یا Passing by Reference؟

- زمانی که **نیازی به تغییر مرجع (reseating)** نداریم، معمولاً **رفرنس‌ها گزینه‌ی بهتری هستند**
- اگر لازم است مقدار `NULL` داشته باشیم یا نبودن مقدار معنا دارد، از **اشاره‌گر** استفاده می‌کنیم
- قانون کلی:
  
> **هر وقت می‌توانی از Reference استفاده کن، و فقط وقتی مجبور شدی سراغ Pointer برو**
