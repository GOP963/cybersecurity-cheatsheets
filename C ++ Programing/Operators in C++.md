# ⭐ **ترجمه کامل: Operators in C++ — عملگرها در C++**

عملگرها در C++ نمادهایی هستند که روی مقادیر عمل کرده و محاسبات ریاضی یا منطقی انجام می‌دهند. آن‌ها پایه‌ی اصلی هر زبان برنامه‌نویسی هستند.

---

# 🔵 مثال ساده:

```cpp
int a = 10 + 20;
cout << a;
```

**خروجی:**  
```
30
```

علامت `+` یک عملگر جمع است و 10 و 20 را با هم جمع می‌کند.

---

# ⭐ انواع عملگرها در C++

عملگرهای C++ به ۶ دسته اصلی تقسیم می‌شوند:

---

# 1️⃣ Arithmetic Operators — عملگرهای حسابی

برای انجام عملیات ریاضی استفاده می‌شوند:

| عملگر | توضیح |
|------|-------|
| `+` | جمع |
| `-` | تفریق |
| `*` | ضرب |
| `/` | تقسیم |
| `%` | باقیمانده تقسیم (فقط برای int) |
| `++` | افزایش یک واحد |
| `--` | کاهش یک واحد |

**نکته مهم:**  
`++a` اول مقدار را زیاد می‌کند بعد استفاده می‌شود.  
`a++` اول مقدار استفاده می‌شود بعد زیاد می‌شود.

---

# 2️⃣ Relational Operators — عملگرهای مقایسه‌ای

برای مقایسه‌ی دو مقدار:

| عملگر | توضیح |
|-------|-------|
| `==` | برابر است با |
| `>` | بزرگ‌تر از |
| `>=` | بزرگ‌تر یا مساوی |
| `<` | کوچک‌تر |
| `<=` | کوچک‌تر یا مساوی |
| `!=` | نابرابر |

خروجی این عملگرها **0 (false)** یا **1 (true)** است.

---

# 3️⃣ Logical Operators — عملگرهای منطقی

برای ترکیب شرط‌ها استفاده می‌شوند:

| عملگر | توضیح |
|-------|-------|
| `&&` | و منطقی — فقط وقتی هر دو درست باشند → true |
| `||` | یا منطقی — اگر یکی درست باشد → true |
| `!` | نقیض، برعکس کردن مقدار |

---

# 4️⃣ Bitwise Operators — عملگرهای بیتی

عملیات روی سطح بیت انجام می‌شود:

| عملگر | توضیح |
|-------|-------|
| `&` | AND بیتی |
| `|` | OR بیتی |
| `^` | XOR بیتی |
| `<<` | شیفت چپ |
| `>>` | شیفت راست |
| `~` | مکمل (0 → 1 و 1 → 0) |

فقط روی `char` و `int` قابل استفاده هستند.

---

# 5️⃣ Assignment Operators — عملگرهای انتساب

برای مقداردهی به متغیرها:

| عملگر | توضیح |
|-------|-------|
| `=` | انتساب معمولی |
| `+=` | جمع و انتساب |
| `-=` | تفریق و انتساب |
| `*=` | ضرب و انتساب |
| `/=` | تقسیم و انتساب |

---

# 6️⃣ Ternary Operator (شرطی سه‌تایی)

تنها عملگر سه‌تایی C++:

```
condition ? value_if_true : value_if_false
```

مثال:

```cpp
int result = (a < b) ? b : a;
```

اگر `a < b` درست باشد، مقدار b برمی‌گردد، اگر نه مقدار a.

---

# 🔶 عملگرهای متفرقه (Miscellaneous Operators)

### 1. `sizeof`
اندازه یک متغیر یا نوع را بر حسب بایت برمی‌گرداند.

### 2. Comma Operator (`,`)
چند عبارت را با کاما از هم جدا کرده و **آخرین مقدار را برمی‌گرداند**.

### 3. عملگر آدرس (`&`)
آدرس حافظه یک متغیر را برمی‌گرداند.

### 4. Dot (`.`)
برای دسترسی به اعضای یک کلاس یا ساختار.

### 5. Arrow (`->`)
برای دسترسی به اعضای یک کلاس از طریق pointer.

### 6. Casting Operators  
برای تبدیل نوع داده:

```
(float)x
static_cast<float>(x)
```

---

# 🔥 Precedence و Associativity — تقدم و جهت ارزیابی

### 🔹 Precedence (تقدم)
مشخص می‌کند کدام عملگر اول اجرا شود.

مثال:

```
3 * 2 + 8
```

چون `*` اولویت بالاتری دارد:

→ `(3 * 2) + 8 = 14`

---

### 🔹 Associativity (جهت اجرای عملگرها)
وقتی عملگرها **هم‌رده** باشند:

- بعضی از **چپ به راست** حل می‌شوند  
- بعضی **راست به چپ**

مثال:

```
50 / 25 * 2
```

چون / و * هم‌تقدم‌اند و از چپ به راست اجرا می‌شوند:

→ `(50 / 25) * 2 = 4`
