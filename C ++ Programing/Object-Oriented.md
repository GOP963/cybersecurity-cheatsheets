

# 🎯 **شیءگرایی چیه؟**

**شیءگرایی یعنی نگاه کردن به برنامه مثل دنیای واقعی.**

در دنیای واقعی همه‌چیز **شیء** هست:

- یک ماشین
    
- یک انسان
    
- یک گوشی
    
- یک کتاب
    

هر شیء دو چیز داره:

1. **ویژگی‌ها (Attributes / Properties)**  
    چیزهایی که شیء _هست_.  
    مثال: ماشین → رنگ، سرعت، مدل
    
2. **رفتارها (Methods / Functions)**  
    کارهایی که شیء _انجام می‌دهد_.  
    مثال: ماشین → حرکت کن، ترمز بزن
    

برنامه‌نویسی شیءگرا همین ایده را وارد کدنویسی می‌کنه.

---

# 🧩 **مفاهیم اصلی شیءگرایی**

## **1) کلاس (Class)**

کلاس مثل **یک نقشه یا قالب** است.  
خودش شیء نیست، فقط **الگو** است.

مثال:

```c
class Car {
    string color;
    int speed;

    void move();
    void stop();
}
```

این فقط **طرح** ماشین است، نه خود ماشین.

---

## **2) شیء (Object)**

شیء یک **نمونه واقعی ساخته‌شده از کلاس** است.

مثل ساخت یک ماشین واقعی از نقشه:

```c
Car myCar;
```

---

## **3) خصوصیت‌ها (Attributes)**

چیزهایی که یک شیء _دربارهٔ خودش نگه می‌داره_.

```c
myCar.color = "Red";
myCar.speed = 120;
```

---

## **4) متد/رفتارها (Methods)**

چیزهایی که یک شیء _می‌تواند انجام دهد_.

```c
myCar.move();
myCar.stop();
```

---

# 🔑 چهار ستون شیءگرایی (خیلی مهم)

## ✔ 1. **Encapsulation (کپسوله‌سازی)**

یعنی **اطلاعات داخل شیء را مخفی کنیم** و فقط از راه خاصی به آن دسترسی بدهیم.

چرا؟  
چون امنیت بیشتر می‌شود و برنامه شخصی‌تر و قابل‌اعتمادتر می‌شود.

---

## ✔ 2. **Inheritance (وراثت)**

یعنی یک کلاس می‌تواند از کلاس دیگری خصوصیت‌ها را **به ارث ببرد**.

مثال:

کلاس Animal  
→ کلاس Dog  
→ کلاس Cat

Dog همه ویژگی‌های Animal را دارد + ویژگی‌های اضافهٔ خودش.

---

## ✔ 3. **Polymorphism (چندریختی)**

یک اسم، رفتارهای مختلف.

مثلاً متد `speak()`:

- سگ: پارس می‌کند
    
- گربه: میومیو می‌کند
    
- گاو: مااا می‌کند
    

اسم متد یکی است اما رفتار متفاوت.

---

## ✔ 4. **Abstraction (انتزاع)**

یعنی چیزهای غیرضروری را پنهان کنیم و فقط چیزهای مهم را نشان بدهیم.

مثل رانندگی با ماشین:  
راننده لازم نیست موتور چطور کار می‌کند؛ فقط فرمان، پدال، دنده را می‌بیند.

---

# 🎯 **چرا شیءگرایی مهمه؟**

چون برنامه را:

- قابل‌فهم‌تر
    
- قابل‌توسعه‌تر
    
- قابل‌نگهداری‌تر
    
- امن‌تر
    
- و شبیه دنیای واقعی می‌کند
    

---

# 🧠 **اگر بخوام خیلی خلاصه بگم:**

**OOP = کلاس + شیء + ویژگی‌ها + رفتارها**

و چهار اصل مهم:

- کپسوله‌سازی
    
- وراثت
    
- چندریختی
    
- انتزاع
