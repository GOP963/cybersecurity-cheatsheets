### استفاده مجدد از رمز عبور Local Administrator

- **Internal Password Spraying** فقط محدود به حساب‌های کاربری دامنه نیست.
    
- اگر دسترسی **مدیریتی (Administrative Access)** و **NTLM hash یا رمز عبور واضح (cleartext)** حساب **Local Administrator** یا دیگر حساب‌های محلی با سطح دسترسی بالا را داشته باشیم، می‌توانیم این حمله را **روی چندین میزبان در شبکه** امتحان کنیم.
    
- استفاده مجدد از رمز عبور Local Administrator بسیار رایج است، زیرا:
    
    - از **Gold Images** در پیاده‌سازی‌های خودکار استفاده می‌شود.
        
    - مدیریت آسان به نظر می‌رسد وقتی همان رمز عبور روی چندین میزبان اعمال می‌شود.



### نکات مهم هنگام کار با Local Administrator

- **استفاده مجدد از رمز عبور یا فرمت‌های رایج** بین حساب‌ها یک نکته مهم است.
    
    - مثال: اگر روی یک Desktop رمز Local Administrator برابر `$desktop%@admin123` باشد، ممکن است ارزش امتحان کردن `$server%@admin123` روی سرورها را داشته باشد.
        
    - اگر حساب‌های غیر استاندارد محلی مانند `bsmith` پیدا کنیم، ممکن است همان رمز در **حساب دامنه با نام مشابه** استفاده شده باشد.
        
- همین اصل برای حساب‌های دامنه هم صادق است:
    
    - اگر رمز کاربری مثل `ajones` را داشته باشیم، می‌توانیم همان رمز را روی حساب مدیریتی او (`ajones_adm`) امتحان کنیم.
        
    - این موضوع در **Domain Trust** نیز رایج است: ممکن است اعتبارنامه یک کاربر در دامنه A برای کاربر با همان یا نام مشابه در دامنه B هم معتبر باشد.

### استفاده از NTLM Hash

- گاهی فقط **NTLM hash** حساب Local Administrator از **SAM محلی** به دست می‌آید.
    
- در این موارد، می‌توان **NT hash را روی یک subnet یا چندین subnet اسپری کرد** تا حساب‌های Local Administrator با همان رمز عبور پیدا شوند.
    
- مثال: تلاش برای **احراز هویت روی تمام میزبان‌های یک شبکه /23** با استفاده از **NT hash حساب Local Administrator** که از یک دستگاه دیگر به دست آمده است.
    
- **گزینه `--local-auth`** در CrackMapExec:
    
    - تضمین می‌کند که **فقط یک بار ورود روی هر ماشین انجام شود** و خطر قفل شدن حساب را کاهش دهد.
        
    - اگر این گزینه فعال نباشد، ابزار از **دامنه جاری** برای احراز هویت استفاده می‌کند که می‌تواند به سرعت باعث **قفل شدن حساب‌ها** شود.
