## Windows Management Instrumentation (WMI)

**Windows Management Instrumentation (WMI)** 
یک موتور اسکریپتینگ است که در محیط‌های سازمانی
ویندوز بسیار استفاده می‌شود تا اطلاعات جمع‌آوری کند و وظایف مدیریتی را روی میزبان‌های محلی و راه‌دور اجرا کند. برای استفادهٔ ما، گزارش‌های WMI در مورد کاربران دامنه، گروه‌ها، پردازه‌ها و اطلاعات دیگر را از میزبان خود و سایر میزبان‌های دامنه تولید خواهیم کرد.

---

## چک‌های سریع WMI (Quick WMI checks)

(ستون اول: فرمان — ستون دوم: توضیح)

- `wmic qfe get Caption,Description,HotFixID,InstalledOn`  
    — سطح پَچی (hotfix) نصب‌شده و توضیحات مربوطه را چاپ می‌کند.
    
- `wmic computersystem get Name,Domain,Manufacturer,Model,Username,Roles /format:List`  
    — اطلاعات پایهٔ میزبان را نمایش می‌دهد (نام، دامنه، سازنده، مدل، کاربر فعلی، نقش‌ها و هر ویژگیِ دیگر داخل لیست).
    
- `wmic process list /format:list`  
    — فهرستی از تمام پردازه‌های در حال اجرا روی میزبان.
    
- `wmic ntdomain list /format:list`  
    — اطلاعاتی دربارهٔ دامنه و کنترلرهای دامنه را نمایش می‌دهد.
    
- `wmic useraccount list /format:list`  
    — اطلاعات همهٔ حساب‌های محلی و هر حساب دامنه‌ای که به این دستگاه لاگین کرده را نمایش می‌دهد.
    
- `wmic group list /format:list`  
    — اطلاعات همهٔ گروه‌های محلی.
    
- `wmic sysaccount list /format:list`  
    — اطلاعات مربوط به حساب‌های سیستمی که به‌عنوان service account استفاده می‌شوند را استخراج می‌کند.
    

> در پایینِ متنِ اصلی نمونه‌ای از اطلاعات دامنه، دامنهٔ فرزند و forest خارجی‌ای که دامنهٔ فعلی با آن اعتماد (trust) دارد، نشان داده شده است. این cheatsheet فرمان‌های مفیدی برای پرس‌وجو (query) اطلاعات میزبان و دامنه با `wmic` ارائه می‌دهد.

> توجه: WMI موضوع گسترده‌ای است و در این‌جا همهٔ قابلیت‌هایش قابل پوشش نیست. برای جزئیات بیشتر به مستندات رسمی WMI مراجعه کنید.

## Net Commands

دستورات `net` (مثل `net user`, `net localgroup` و غیره) نیز می‌توانند برای فهرست‌برداری اطلاعات از دامنه مفید باشند. این دستورات مشابه قابلیت‌های WMI اطلاعاتی مانند موارد زیر را نمایش می‌دهند:

- کاربران محلی و دامنه
    
- گروه‌ها
    
- میزبان‌ها
    
- اعضای خاص در گروه‌ها
    
- کنترلرهای دامنه
    
- الزامات رمزعبور (password requirements)
    

نمونه خروجی WMI برای `wmic ntdomain get Caption,Description,DnsForestName,DomainName,DomainControllerAddress` در متن نشان می‌دهد که دامنه‌ها و کنترلرها چه آدرس‌هایی دارند و چه forestهایی مرتبط‌اند.

## هشدار پایانی دربارهٔ مانیتورینگ

- دقت کنید که اجرای دستورات `net.exe` یا برخی کوئری‌های WMI **اغلب توسط راهکارهای EDR/مانیتورینگ رهگیری می‌شود** و می‌تواند محل یا فعالیت ما را سریعاً افشا کند، به‌ویژه وقتی حساب کاربری‌ای غیرمرتبط (مثلاً یک کاربرِ بخش مارکتینگ) این دستورات مدیریتی را اجرا کند.
    
- بعضی سازمان‌ها برای اجرای دستوراتی مثل `whoami` یا `net localgroup administrators` توسط حساب‌هایی در اُستانداردهای خاص، آلارم تنظیم می‌کنند — این رفتار می‌تواند علامت قرمز واضحی برای تیم‌های امنیتی باشد.

## دستورات Net (Net Commands)

دستورات `net` هم برای فهرست‌برداری اطلاعات از دامنه مفیدند و عملکردی مشابه WMI دارند؛ می‌توانند اطلاعاتی مانند کاربران محلی و دامنه، گروه‌ها، میزبان‌ها، اعضای گروه‌ها، کنترلرهای دامنه و الزامات رمزعبور را نشان دهند.

> هشدار: اجرای برخی دستورات `net.exe` معمولاً توسط راهکارهای EDR مانیتور می‌شود و در محیط‌های حساس می‌تواند هشدار ایجاد کند (مثلاً اجرای `whoami` یا `net localgroup administrators` توسط حساب‌هایی که معمولاً نباید چنین دستورات مدیریتی اجرا کنند).

### جدول دستورات مفید `net`

(فرمان — توضیح)

- `net accounts`  
    → اطلاعات دربارهٔ الزامات رمزعبور (password requirements).
    
- `net accounts /domain`  
    → سیاست‌های رمزعبور و قفل شدن (password & lockout policy) برای دامنه.
    
- `net group /domain`  
    → اطلاعات دربارهٔ گروه‌های دامنه.
    
- `net group "Domain Admins" /domain`  
    → فهرست کاربران دارای امتیازات Domain Admin.
    
- `net group "domain computers" /domain`  
    → فهرست کامپیوترهای متصل به دامنه.
    
- `net group "Domain Controllers" /domain`  
    → فهرست حساب‌های کامپیوتری کنترل‌کنندهٔ دامنه.
    
- `net group <domain_group_name> /domain`  
    → کاربران عضو یک گروه مشخص دامنه.
    
- `net groups /domain`  
    → فهرست گروه‌های دامنه.
    
- `net localgroup`  
    → تمام گروه‌های محلی دستگاه را نشان می‌دهد.
    
- `net localgroup administrators /domain`  
    → فهرست کاربرانی که در گروه administrators دامنه هستند (شامل Domain Admins به‌صورت پیش‌فرض).
    
- `net localgroup Administrators`  
    → اطلاعات دربارهٔ گروه محلی Administrators (روی دستگاه محلی).
    
- `net localgroup administrators [username] /add`  
    → اضافه کردن یک کاربر به گروه administrators محلی.
    
- `net share`  
    → نمایش اشتراک‌های فعلی (shares) روی دستگاه.
    
- `net user <ACCOUNT_NAME> /domain`  
    → اطلاعات دربارهٔ یک کاربر مشخص در دامنه.
    
- `net user /domain`  
    → فهرست تمام کاربران دامنه.
    
- `net user %username%`  
    → اطلاعات دربارهٔ کاربر فعلی.
    
- `net use x: \\computer\share`  
    → مانت (نصب) یک share به‌عنوان درایو محلی X:.
    
- `net view`  
    → فهرست کامپیوترها (در شبکه/دامنه).
    
- `net view /all` یا `net view /domain[:domainname]`  
    → نمایش shareها روی دامنه‌ها.
    
- `net view \\computer /ALL`  
    → فهرست اشتراک‌های یک کامپیوتر مشخص.
    
- `net view /domain`  
    → فهرست کامپیوترهای دامنه.

### جمع‌بندی کوتاه

- **WMI**: 
- بسیار قدرتمند برای جمع‌آوری اطلاعات میزبان/دامنه و اجرای کارهای مدیریتی (قابل اجرا محلی یا راه‌دور).
    
- **Net commands**:
- ساده، سریع و مفید برای فهرست‌برداری کاربران، گروه‌ها، shareها و سیاست‌ها، اما اجرای آن‌ها ممکن است مانیتور شود.
    
- هر دو مجموعهٔ دستورات ابزارهای مهمی برای مرحلهٔ کشف (recon) در تست نفوذ و ارزیابی امنیت دامنه هستند.

## مهم : 

اگر فکر می‌کنی مدافعان شبکه فعالانه هر دستوری که غیرعادی به‌نظر می‌رسد را لاگ یا پایش می‌کنند، می‌تونی از این راه‌حل برای استفاده از دستورات `net` استفاده کنی. تایپ کردن `net1` به‌جای `net` همان عملکردها را اجرا می‌کند اما احتمال راه‌اندازی هشدار مبتنی بر رشتهٔ `net` را کاهش می‌دهد.

مثال 

```
net user charon ❌
```

اینکارو باعث ایجاد لاگ میشه 
راه حل 

```
net1 user charon ✅
```

استفاده از این دستور میتواند رشته حساس بودن EDR نسبت به ابزار net را کاهش دهد



run as Administrator 

```
runas /netonly /user:INLANEFREIGHT\adunn powershell
```
