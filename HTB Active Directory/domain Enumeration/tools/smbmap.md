
**SMBMap**  
SMBMap برای فهرست‌برداری از اشتراک‌های SMB از یک میزبان حمله‌کننده لینوکسی بسیار مفید است. می‌توان از آن برای گرفتن فهرست اشتراک‌ها، بررسی دسترسی‌ها و محتوای اشتراک‌ها (در صورتی که قابل‌دسترسی باشند) استفاده کرد. وقتی دسترسی به اشتراکی به‌دست آمد، می‌توان فایل‌ها را دانلود یا آپلود کرد و دستورات راه‌دور اجرا نمود.

مثل **CrackMapExec (CME)**، می‌توانیم با استفاده از SMBMap و مجموعه‌ای از اعتبارنامه‌های کاربران دامنه، بررسی کنیم کدام اشتراک‌ها روی سیستم‌های راه دور قابل‌دسترسی‌اند. همانند سایر ابزارها، با اجرای `smbmap -h` می‌توان منوی راهنمای استفاده را دید. علاوه بر فهرست‌کردن اشتراک‌ها، SMBMap توانایی فهرست‌برداری بازگشتی از پوشه‌ها، نمایش محتوای یک دایرکتوری، جستجوی محتوای فایل‌ها و موارد دیگر را دارد. این قابلیت‌ها به‌ویژه هنگام جستجو در اشتراک‌ها برای یافتن اطلاعات مفید بسیار کاربردی هستند.


how to scan with smbmap
```
smbmap -u forend -p Klmcargo2 -d INLANEFREIGHT.LOCAL -H 172.16.5.5
```

متن بالا به ما می‌گوید که کاربر ما چه چیزهایی را می‌تواند دسترسی داشته باشد و سطح دسترسی‌اش چیست. مانند نتایج‌مان از CME، می‌بینیم که کاربر `forend` به اشتراک‌های `ADMIN$` یا `C$` روی DC دسترسی ندارد (این برای یک حساب کاربری عادی قابل‌انتظار است)، اما دسترسی خواندن به `IPC$`، `NETLOGON` و `SYSVOL` دارد که در هر دامنه به‌صورت پیش‌فرض وجود دارد.  
اشتراک‌های غیرِاستانداردِ دیگر، مانند «اشتراک‌های دپارتمان» و اشتراک‌های `user` و `archive`، جالب‌تر هستند. بیایید فهرست‌برداری بازگشتی (recursive) از دایرکتوری‌های موجود در اشتراک `Department Shares` انجام دهیم. همان‌طور که انتظار می‌رود، زیردایرکتوری‌هایی برای هر دپارتمان در شرکت را می‌بینیم.


```
smbmap -u forend -p Klmcargo2 -d INLANEFREIGHT.LOCAL -H 172.16.5.5 -R
'Department Shares' --dir-only
```
