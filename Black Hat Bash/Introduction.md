

صدر درصد ما موقعی که یک فایل bash رو باز میکنیم تا سورسش رو ببینیم به نوعی میشه گفت که همیشه در خط اول کدی رو میبینیم که با علامت #! شروع میشه  که در اصطلاح به این میگن خط Shebang


## خط Shebang

هر اسکریپت باید با **خط shebang** آغاز شود، یک رشته کاراکتری که با `#!` شروع می‌شود و پس از آن مسیر کامل **تفسیرگر اسکریپت** نوشته می‌شود.

مثال یک خط shebang معمولی برای یک اسکریپت bash:

```
#!/bin/bash
```

- تفسیرگر bash معمولاً در مسیر `/bin/bash` قرار دارد.
    
- اگر اسکریپت‌هایتان را با Python یا Ruby نوشته باشید، مسیر کامل تفسیرگر Python یا Ruby را در خط shebang می‌نویسید.
    

گاهی ممکن است با اسکریپت‌هایی روبرو شوید که از این نوع shebang استفاده می‌کنند:


به طور کلی shebang میشه تفسیرگر کد ما 


### آرگومان‌های اختیاری در Shebang

خط shebang می‌تواند آرگومان‌های اختیاری برای تغییر رفتار اجرای اسکریپت داشته باشد:

مثال با آرگومان `-x`:


```
#!/bin/bash -x
```

- این گزینه باعث می‌شود **همه دستورات و آرگومان‌های آن‌ها هنگام اجرا در ترمینال چاپ شوند**.
    
- برای **اشکال‌زدایی (debugging)** اسکریپت در حین توسعه بسیار مفید است.


```
#!/bin/bash -r
```

- این گزینه یک **پوسته bash محدود (restricted)** ایجاد می‌کند.
    
- برخی دستورات بالقوه خطرناک محدود می‌شوند، مانند:
    
    - رفتن به دایرکتوری‌های خاص
        
    - تغییر متغیرهای محیطی حساس
        
    - تلاش برای غیر فعال کردن پوسته محدود از داخل اسکریپت


---

### ارسال آرگومان به تفسیرگر از خارج از اسکریپت

می‌توانید بدون تغییر اسکریپت، آرگومان‌ها را هنگام فراخوانی bash هم ارسال کنید:

```
bash -r myscript.sh
```


    فرقی نمی‌کند آرگومان‌ها را در خط shebang بنویسید یا در خط فرمان ارسال کنید.

    استفاده از خط فرمان روش راحت‌تری برای فعال کردن حالت‌های مختلف است.


---

### نحوه نوشتن کامنت در Bash

کامنت‌ها با یک علامت **هش (#)** شروع می‌شوند، مانند مثال زیر:

```
#!/bin/bash

# This is my first script.

echo "hello world"
```


---


## اشکال‌زدایی (Debugging)

یک روش آسان برای پیدا کردن خطاها **در مراحل اولیه** استفاده از پارامتر `-n` هنگام اجرای اسکریپت است:

```
$ bash -n script.sh
```



---



### اختصاص خروجی یک دستور به متغیر

می‌توانیم **خروجی یک دستور را به متغیر اختصاص دهیم** با استفاده از **command substitution** با سینتکس `$()`:

- دستور مورد نظر را داخل پرانتز قرار می‌دهیم.
    
- این سینتکس در برنامه‌نویسی bash بسیار کاربرد دارد.

```
$ root_directory=$(ls -ld /)
$ echo "${root_directory}"
drwxr-xr-x 1 user user 0 Feb 13 20:12 /
```
