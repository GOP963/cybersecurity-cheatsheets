


در debug کردن kernel ما چیزی به اسم breakpoint نداریم منطقی هم هست چون سیستم کلا فریز میشه 

به دوحالت میتونیم kernel debug کنیم 

- Local kernel debug
- remote kernel debug


برای اینکه بتونیم به صورت remote دیباگ بکنیم احتیاج به دوتا فایل داریم knet.exe  و یک فایل xml که مربوط به debugger هست رو میبریم رو سیستم تارگت 

 سیستم تارگت  رو هم با استفاده از ابزار  bcdedit میبریم رو مود debug

```
bcdedit -debug on
```
