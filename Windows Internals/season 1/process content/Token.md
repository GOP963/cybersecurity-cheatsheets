

پروسه همیشه یه object داره که این Object میاد Attach میشه به پروسه ما و مجوز های اون پروسه مشخص میکنه 
اما Token از کجا میادش از پروسه یی که این پروسه رو ایجاد کرده است یعنی هر برنامه یی که ما میایم و run میکنیم از طریق explorer میاد Token Explorer رو میگیره 

پس Token همیشه از پرنت ارث بری میکند

اما اجزای این Token شامل چیا هستش 

	کی این Token رو ایجاد کرده 
	اون user که اومده ایجادش کرده چه دسترسی هایی داره تو چه گروهی هستش
	به چه Resource های میتونه دسترسی بگیره
