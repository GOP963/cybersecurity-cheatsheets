## 🧩 فایل PDB چیه؟

**PDB = Program DataBase**

فایل **PDB** یک فایل **اطلاعات دیباگ (Debug Symbols)** هست که کامپایلر و لینکِر مایکروسافت (MSVC) موقع Build برنامه تولیدش می‌کنن.

به زبان ساده:

> PDB نقشهٔ دقیق ارتباط بین کد سورس و فایل اجرایی (EXE/DLL) است.

---

## 📦 داخل PDB چی ذخیره می‌شه؟

PDB شامل اطلاعاتی مثل:

### 🧠 اطلاعات سطح بالا

- نام توابع
    
- نام کلاس‌ها
    
- نام متغیرها
    
- ساختارها (struct / class layout)
    
- Namespaceها
    

### 🔬 اطلاعات سطح پایین

- آدرس دقیق توابع در حافظه
    
- Offset متغیرها
    
- Line numberهای سورس
    
- Mapping بین assembly ↔ سورس C/C++
    

### 🧵 اطلاعات Thread / Stack

- Stack frame layout
    
- Call stack information
    

---

## 🎯 PDB به چه دردی می‌خوره؟

### 1️⃣ Debugging (مهم‌ترین کاربرد)

وقتی تو Visual Studio یا WinDbg:

- Breakpoint می‌ذاری
    
- Step Into می‌کنی
    
- Variable می‌بینی
    

👉 همهٔ اینا با کمک **PDB** ممکنه.

بدون PDB:

```
0x40123A
0x401240
```

با PDB:

```
main()
GetRealOSVersion()
MessageBoxW()
```

---

### 2️⃣ Reverse Engineering (خیلی مهم)

اگر PDB در دسترس باشه:

- اسم واقعی توابع معلوم می‌شه
    
- کلاس‌ها بازسازی می‌شن
    
- Reverse خیلی راحت می‌شه
    

به همین دلیل:

> لو رفتن PDB = لو رفتن معماری برنامه

---

### 3️⃣ Crash Analysis

وقتی برنامه Crash می‌کنه:

- Windows یک minidump می‌سازه
    
- بدون PDB → بی‌معنی
    
- با PDB → دقیق می‌فهمی کجا کرش شده
    

---

## 🏗️ چرا کنار EXE ساخته می‌شه؟

در حالت Debug:

- Visual Studio همیشه PDB می‌سازه
    

در حالت Release:

- اگر `/DEBUG` فعال باشه → باز هم ساخته می‌شه
    

این فایل:

- جزو برنامه نیست
    
- سیستم‌عامل بهش نیازی نداره
    
- فقط برای **توسعه‌دهنده** است
    

---

## ❌ آیا PDB باید همراه EXE منتشر بشه؟

تقریباً همیشه:

> ❌ نه

چون:

- اسم توابع لو می‌ره
    
- منطق برنامه لو می‌ره
    
- Reverse خیلی راحت می‌شه
    

📌 استثناء:

- بعضی شرکت‌ها PDB رو روی **Symbol Server** خصوصی نگه می‌دارن
    
- یا برای Debug نسخه‌های خاص منتشر می‌کنن
    

---

## 🔐 مثال امنیتی (خیلی مهم)

فرض کن این EXE رو داری:

```text
malware.exe
malware.pdb
```

Reverse Engineer چی کار می‌کنه؟

- PDB رو لود می‌کنه
    
- تو IDA / WinDbg
    
- مستقیم اسم توابع رو می‌بینه 😐
    

برای همین:

> بدافزارها PDB ندارن  
> ابزارهای حرفه‌ای Release PDB رو حذف می‌کنن

---

## 🧪 یه نکته خیلی خفن

داخل فایل EXE یک مسیر به PDB ذخیره می‌شه:

```text
C:\Users\Dev\Desktop\Project\x64\Debug\project.pdb
```

Reverse Engineer از همین:

- اسم پروژه
    
- اسم کاربر
    
- ساختار سورس  
    رو حدس می‌زنه 😈
