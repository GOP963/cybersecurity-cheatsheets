# 📘 درس 1 — SCADA چیست؟

## ⭐ تعریف

**SCADA = Supervisory Control And Data Acquisition**  
(سامانهٔ نظارت و جمع‌آوری داده)

SCADA یک **سیستم نرم‌افزاری + سخت‌افزاری** است که برای:

- **نظارت** بر تجهیزات صنعتی
    
- **کنترل** تجهیزات صنعتی
    
- **جمع‌آوری داده**
    
- **هشداردهی**
    
- **نمایش وضعیت کارخانه / نیروگاه**
    

استفاده می‌شود.

---

# ⭐ SCADA در چه جاهایی کاربرد دارد؟

- نیروگاه برق
    
- سیستم توزیع گاز
    
- تصفیه‌خانه آب
    
- پالایشگاه
    
- خطوط تولید کارخانه
    
- سیستم‌های حمل‌ونقل
    
- خودروسازی
    
- نفت و گاز
    

هرجا تجهیزات بزرگ اتوماتیک وجود دارد، SCADA آنجاست.

---

# ⭐ هدف SCADA چیست؟

SCADA هدفش این است که از یک محل مرکزی (Control Room):

- وضعیت تجهیزات دیده شود
    
- فرمان روشن/خاموش داده شود
    
- هشدارها نمایش داده شود
    
- داده‌ها ذخیره شوند
    

---

# 📌 SCADA چطور کار می‌کند؟

سه کار اصلی را انجام می‌دهد:

### 1) **Data Acquisition – جمع‌آوری داده**

اطلاعات را از:

- PLC
    
- RTU
    
- سنسورها  
    دریافت می‌کند.
    

### 2) **Supervision – نظارت**

روی HMI / مانیتور اطلاعات را نمایش می‌دهد.

### 3) **Control – کنترل از راه دور**

اپراتور می‌تواند:

- یک پمپ را روشن کند
    
- یک شیر صنعتی را باز کند
    
- سرعت موتور را کم/زیاد کند
    

---

# ⭐ اجزای SCADA

برای نوت‌برداری بسیار مهم:

```
Level 0 = Sensors + Actuators
Level 1 = PLC / RTU
Level 2 = SCADA Server + HMI
Level 3 = Operations Network
Level 4 = IT Network
```

این ساختار به نام **Purdue Model** شناخته می‌شود.

# 📘 درس 2 — تفاوت SCADA با شبکه سازمانی

|ویژگی|شبکه IT|شبکه SCADA|
|---|---|---|
|هدف|کاربران + دیتا|کنترل تجهیزات فیزیکی|
|پروتکل‌ها|TCP/IP, HTTP,...|Modbus, DNP3, Profinet|
|امنیت مهم|Confidentiality|Availability|
|ترافیک|معمولی|Real-Time|
|آپدیت|قابل انجام|بسیار محدود|

# 📘 درس 4 — پروتکل‌های SCADA

قبل از اینکه وارد جزئیات مثل "Modbus RTU vs Modbus TCP" بشویم،  
اول باید دسته‌بندی پروتکل‌ها را بدانی:

### 🟣 1) پروتکل‌های سطح پایین (Fieldbus / Serial)

- **Modbus RTU**
    
- **Profibus**
    
- **HART**
    
- **CANBus**
    

روی کابل‌های سریال کار می‌کنند:

- RS-232
    
- RS-485
    

---

### 🔵 2) پروتکل‌های شبکه‌ای (Ethernet-based)

- **Modbus TCP**
    
- **DNP3**
    
- **EtherNet/IP**
    
- **Profinet**
    
- **S7Comm (زیمنس)**
    

این‌ها روی **TCP/IP واقعی** اجرا می‌شوند.

---

### 🟢 3) پروتکل‌های سطح مدیریت و داده

- **OPC Classic**
    
- **OPC UA**
    
- **MQTT (در سیستم‌های جدید)**

# 📘 درس 5 — Modbus RTU vs Modbus TCP

(برای آماده شدن قبل از درس پروتکل‌ها)

## ⭐ Modbus RTU:

- روی **Serial Line** کار می‌کند
    
- بدون TCP/IP
    
- قاب کوچک‌تر
    
- آدرس‌دهی ساده
    
- سرعت کم
    
- کابل: RS-485 / RS-232
    

---

## ⭐ Modbus TCP:

- روی **TCP/IP** اجرا می‌شود
    
- پورت 502
    
- سریع‌تر
    
- multi-client
    
- Packetها داخل TCP قرار می‌گیرند
    

مثل این:

```
TCP/IP Packet
    |
Modbus Function Code
    |
Registers
```

---

## ⭐ مهم‌ترین تفاوت:

|Modbus RTU|Modbus TCP|
|---|---|
|Serial|Ethernet|
|بدون IP|دارای IP|
|بدون TCP|داخل TCP/IP حمل می‌شود|
|فقط point-to-point|قابلیت شبکه گسترده|


### 🔸 درس 6 — Modbus از صفر تا پیشرفته

- ساختار Frame
    
- Registerها
    
- Function Code
    
- Master/Slave
    
- Attack Surface
    
- Wireshark Analysis

# 📌 **RTU چیست؟ (Remote Terminal Unit)**

**RTU = Remote Terminal Unit  
واحد ترمینال راه‌دور**

RTU یکی از مهم‌ترین اجزای سیستم‌های **SCADA** است.

RTU یک دستگاه سخت‌افزاری است که:

### ✔ داده‌های سنسورها را جمع می‌کند

(دما، فشار، ولتاژ، جریان و… مثل PLC)

### ✔ داده‌ها را تبدیل می‌کند به سیگنال دیجیتال

چون سنسورها معمولاً داده آنالوگ می‌دهند (مثلاً 4–20 mA)

### ✔ با SCADA Server ارتباط برقرار می‌کند

از طریق پروتکل‌هایی مثل:

- Modbus RTU
    
- Modbus TCP
    
- DNP3
    
- IEC 60870-5-101/104
    

### ✔ از راه دور قابل مدیریت است

در ایستگاه‌های برق، مخازن آب، خطوط لوله نفت و گاز  
RTUها معمولاً چند کیلومتر با مرکز کنترل فاصله دارند.

### ✔ برق خیلی کمی مصرف می‌کند

برای محل‌هایی که برق یا اینترنت کم است.

### ✔ معمولاً روی لینک‌های Slow یا Wireless کار می‌کند

و برای همین پروتکل‌های ساده مثل Modbus RTU (سریال) دارند.

---

# 🎯 تفاوت RTU با PLC

|ویژگی|PLC|RTU|
|---|---|---|
|محل استفاده|کارخانه‌ها و محیط‌های صنعتی|محیط‌های دورافتاده، پست برق، لوله‌ها|
|برنامه‌پذیری|بسیار قوی و پیچیده|ساده‌تر|
|پردازش منطقی|زیاد|کم|
|ارتباط|معمولاً سریع (Ethernet/IP, Profinet)|لینک‌های کند (Serial, RF)|
|مصرف انرژی|نرمال|بسیار کم|
|قیمت|معمولاً پایین‌تر|گران‌تر|

به طور ساده:

🔸 **PLC** برای کنترل سریع و لحظه‌ای  
🔸 **RTU** برای جمع‌آوری داده از راه دور و ارسال به SCADA

---

# 🧩 یک مثال واقعی RTU

فرض کن یک ایستگاه پمپاژ آب ۵۰ کیلومتر دورتر از شهر است.

در آن ایستگاه:

- سنسور فشار
    
- سنسور سطح آب
    
- سنسور دما
    
- پمپ‌ها
    
- شیرها
    

وجود دارد.

هیچ اپراتوری آنجا نیست.  
اینجا **RTU نصب می‌شود**:

RTU:

- داده را جمع می‌کند
    
- به مرکز کنترل (SCADA) ارسال می‌کند
    
- اگر لازم باشد از راه دور دستور اجرا می‌کند (مثلاً روشن کردن پمپ)
    

---

# 📡 پروتکل‌هایی که RTU استفاده می‌کند:

- **Modbus RTU** ← سریال (RS-485 / RS-232)
    
- **DNP3** ← مخصوص شبکه برق
    
- **IEC 60870-5-101/104** ← اروپا/آسیا
    
- **Modbus TCP** ← اگر شبکه IP داشته باشد
    

---

# 📝 برای نوت‌برداری: تعریف کوتاه RTU

```
RTU (Remote Terminal Unit):
یک دستگاه صنعتی برای جمع‌آوری داده از سنسورها در مکان‌های دور،
تبدیل داده به دیجیتال، و ارسال آن به SCADA از طریق پروتکل‌هایی
مثل Modbus RTU یا DNP3. مصرف انرژی کم، مناسب ارتباطات با سرعت پایین،
و کاربرد در پست‌های برق، خطوط لوله و تأسیسات دورافتاده.
```

# 🔵 اول: RTU چیست؟

RTU مخفف **Remote Terminal Unit** است.

📌 **تعریف ساده:**  
**RTU یک دستگاه سخت‌افزاری است که در مکان‌های دور (Remote Sites) قرار می‌گیرد و داده‌های سنسورها و تجهیزات را جمع می‌کند و به مرکز (SCADA/Control Center) می‌فرستد.**

---

## 🔹 RTU چه کاری انجام می‌دهد؟

RTU معمولاً این قابلیت‌ها را دارد:

- خواندن ورودی‌ها (Analog Input و Digital Input)
    
- کنترل خروجی‌ها (Relay Output، Valves، Pumps)
    
- ارتباط با SCADA از طریق پروتکل‌های شبکه
    
- مقاومت بالا در برابر شرایط سخت (رطوبت، گرما، سرما، لرزش)
    
- با باتری کار می‌کند یا مصرف کم دارد
    
- معمولاً در **ایستگاه‌های دور از مرکز** استفاده می‌شود:
    
    - ایستگاه پمپاژ آب
        
    - ایستگاه گاز
        
    - خطوط انتقال برق
        
    - چاه‌های نفت
        
    - سدها و تأسیسات آبی
        

---

## 🔹 RTU مثل "Agent" هست؟


RTU یک **دستگاه سخت‌افزاری مستقل** است (نه برنامه).  
در واقع خودش یک دستگاه فیزیکی است که ورودی/خروجی دارد.

🔸 می‌توان گفت:  
RTU یک **دستگاه Remote** است که داده‌ها را از محیط بومی می‌گیرد و به مرکز ارسال می‌کند.

اما واژه Agent دقیق نیست چون:

- RTU سیستم‌عامل‌های خیلی ساده دارد
    
- برنامه‌ریزی پیچیده PLC را ندارد
    
- منطق کنترلش محدودتر است
    

---

# 🔵 حالا PLC چیست؟

PLC مخفف **Programmable Logic Controller** است.

📌 **تعریف ساده:**  
**PLC مغز سیستم کنترل صنعتی است — برنامه‌پذیر، سریع، قابل اعتماد و برای کارهای منطقی طراحی شده.**

---

## 🔹 PLC چه می‌کند؟

- اجرای منطق کنترل (Control Logic)
    
- خواندن ورودی‌های سنسور
    
- کنترل موتور، پمپ، شیر
    
- اجرای برنامه Ladder یا Structured Text
    
- پاسخ‌دهی در زمان واقعی (Real-time)
    
- برقراری ارتباط با SCADA یا HMI
    

📌 PLC دقیقاً برای **اتوماتیک‌سازی فرایندها** ساخته شده.

---

# 🔴 تفاوت اصلی PLC و RTU

|ویژگی|PLC|RTU|
|---|---|---|
|هدف|کنترل فرایند صنعتی|جمع‌آوری داده از مناطق دور|
|برنامه‌ریزی|بسیار پیشرفته|محدود|
|سرعت|سریع (Real-time)|کندتر|
|ارتباط|Modbus, Profinet, EtherNet/IP|DNP3, Modbus RTU/TCP|
|مکان|داخل کارخانه|در نقاط دور از کارخانه|
|منطق کنترل|پیچیده|ساده|
|مقاومت محیطی|متوسط|بسیار مقاوم|

---

# 🔵 رابطه‌ی RTU و PLC با SCADA و HMI

معماری استاندارد اینطوری است:

```
   سنسور / موتور / پمپ
         │
         ▼
   ┌──────────┐
   │   PLC    │ ← کنترل محلی
   └──────────┘
         │
         ▼
   ┌──────────┐
   │   SCADA   │ ← سرور مدیریت + Logging
   └──────────┘
         │
         ▼
   ┌──────────┐
   │   HMI     │ ← اپراتور وضعیت را می‌بیند و کنترل می‌کند
   └──────────┘
```

---

# 🔵 نقش RTU کجاست؟

RTU معمولاً **به جای PLC استفاده نمی‌شود**.

معمولاً در **فاصله‌های دور از کارخانه** این معماری دیده می‌شود:

```
سنسور ─→ RTU ────→ SCADA (از طریق لینک رادیویی یا ماهواره)
```

در حالی که PLC بیشتر داخل محیط کارخانه است:

```
سنسور ─→ PLC ─→ SCADA ─→ HMI
```

---

# 🔴 پاسخ به سوالت:

## ❌ «RTU مثل Agent هست که وضعیت را به PLC می‌فرستد؟»

نه، معمولاً اینطور نیست.

### ✔ درستش این است:

- **RTU مستقیماً با SCADA صحبت می‌کند**
    
- **PLC هم با SCADA صحبت می‌کند**
    
- ولی **معمولاً PLC با RTU ارتباط ندارد**
    

پس:

> ❗ RTU داده‌ها را به **SCADA** می‌فرستد، نه به **PLC**  
> ❗ PLC داده‌ها را به **SCADA/HMI** می‌فرستد  
> ❗ HMI فقط رابط گرافیکی برای اپراتور است، کنترل ندارد
