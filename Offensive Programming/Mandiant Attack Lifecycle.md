

**چرخه حیات حمله Mandiant (Mandiant Attack Lifecycle)** یکی از مدل‌های استاندارد و معتبر برای توصیف مراحل یک حمله سایبری هدفمند (مانند حملات APT) است. حملات و تکنیک‌هایی که در هر فاز از این مدل اتفاق می‌افتند، به صورت ساختاریافته و به ترتیب فازها در ادامه لیست شده‌اند:

### ۱. فاز نفوذ اولیه (Initial Compromise)
در این مرحله، مهاجمان سعی می‌کنند اولین راه ورود به شبکه سازمان را پیدا کنند.
*   **فیشینگ هدفمند (Spear Phishing):** ارسال ایمیل‌های حاوی لینک‌های مخرب یا فایل‌های پیوست آلوده (مثل فایل‌های آفیس حاوی ماکرو).
*   **سوءاستفاده از آسیب‌پذیری‌ها (Exploitation):** استفاده از اکسپلویت‌ها برای نفوذ از طریق نرم‌افزارهای پچ‌نشده، تجهیزات لبه شبکه (Firewall, VPN) یا آسیب‌پذیری‌های روز صفر (Zero-day).
*   **حملات Watering Hole:** آلوده کردن وب‌سایت‌های معتبری که کارمندان سازمانِ هدف معمولاً به آن‌ها سر می‌زنند.
*   **استفاده از اعتبارنامه‌های لو رفته (Credential Stuffing):** استفاده از نام کاربری و رمزهای عبوری که قبلاً در نشت‌های اطلاعاتی دیگر فاش شده‌اند.

### ۲. فاز تثبیت موقعیت (Establish Foothold)
پس از ورود موفق، مهاجمان ابزارهایی را مستقر می‌کنند تا دسترسی خود را حتی در صورت راه‌اندازی مجدد سیستم یا تغییر رمز عبور اولیه حفظ کنند.
*   **نصب درپشتی (Backdoor) و Web Shell:** قرار دادن فایل‌های مخرب روی سرورها برای دسترسی از راه دور.
*   **ایجاد کانال فرمان و کنترل (C2 - Command and Control):** برقراری ارتباط مخفیانه بین سیستم آلوده و سرورهای تحت کنترل مهاجم جهت دریافت دستورات.
*   **ایجاد وظایف زمان‌بندی شده (Scheduled Tasks):** تنظیم سیستم برای اجرای خودکار بدافزارها در زمان‌های مشخص.
*   **تغییرات در رجیستری (Registry Run Keys):** اضافه کردن بدافزار به لیست برنامه‌هایی که هنگام روشن شدن ویندوز اجرا می‌شوند.

### ۳. فاز ارتقاء سطح دسترسی (Escalate Privileges)
مهاجم معمولاً در ابتدا دسترسی یک کاربر عادی را دارد و برای کنترل بیشتر شبکه، نیاز به دسترسی مدیر (Administrator یا SYSTEM) دارد.
*   **استخراج اعتبارنامه‌ها (Credential Dumping):** استفاده از ابزارهایی مانند Mimikatz برای استخراج رمزهای عبور یا هش‌ها از حافظه سیستم (مثل LSASS).
*   **سوءاستفاده از آسیب‌پذیری‌های ارتقاء دسترسی محلی (LPE):** اجرای اکسپلویت‌های روی سیستم‌عامل برای گرفتن دسترسی SYSTEM.
*   **دور زدن کنترل حساب کاربری (UAC Bypass):** تکنیک‌هایی برای دور زدن هشدارهای امنیتی ویندوز جهت اجرای برنامه‌ها با سطح دسترسی بالا.
*   **حملات Kerberoasting:** استخراج و کرک کردن بلیت‌های سرویس در Active Directory (TGS) برای به دست آوردن رمز عبور حساب‌های کاربری خدماتی.

### ۴. فاز شناسایی داخلی (Internal Reconnaissance)
مهاجم محیط اطراف خود را بررسی می‌کند تا بفهمد کجا قرار دارد، سیستم‌های مهم کجا هستند و ساختار شبکه چگونه است.
*   **اسکن پورت‌ها و شبکه (Port/Network Scanning):** جستجو برای یافتن سرورها، دیتابیس‌ها و سرویس‌های فعال در شبکه داخلی.
*   **بررسی ساختار اکتیو دایرکتوری (Active Directory Enumeration):** استفاده از ابزارهایی مانند BloodHound یا درخواست‌های LDAP برای ترسیم گراف دسترسی‌ها و یافتن مسیر رسیدن به Domain Admin.
*   **جستجوی فایل‌های حساس:** گشتن در فایل‌شرها (File Shares) برای پیدا کردن مستندات شبکه، رمزهای عبور ذخیره شده در فایل‌های متنی یا کدهای منبع.

### ۵. فاز حرکت عرضی (Move Laterally)
مهاجم از سیستم اولیه به سایر سیستم‌های شبکه منتقل می‌شود تا به هدف نهایی خود نزدیک‌تر شود.
*   **استفاده از پروتکل‌های مدیریت استاندارد:** سوءاستفاده از RDP, SSH, WMI یا PowerShell Remoting با استفاده از اعتبارنامه‌های سرقت شده.
*   **حملات Pass-the-Hash (PtH) و Pass-the-Ticket (PtT):** استفاده از هش رمز عبور یا بلیت‌های Kerberos (بدون نیاز به دانستن خود رمز عبور متنی) برای ورود به سیستم‌های دیگر.
*   **اجرای کد از راه دور (PsExec):** استفاده از ابزارهای مدیریتی مانند PsExec برای اجرای دستورات روی سیستم‌های دیگر شبکه.

### ۶. فاز حفظ حضور (Maintain Presence)
مهاجمان برای اینکه توسط تیم‌های امنیتی (SOC) شناسایی نشوند و دسترسی طولانی‌مدت داشته باشند، خود را پنهان کرده و راه‌های نفوذ جایگزین ایجاد می‌کنند.
*   **ایجاد حساب‌های کاربری جعلی (Rogue Accounts):** ساخت حساب‌های مدیریتی جدید در Active Directory یا سیستم‌های محلی.
*   **تزریق کد و مخفی‌سازی فرآیندها (Process Hollowing / DLL Injection):** اجرای کدهای مخرب در دل فرآیندهای قانونی سیستم‌عامل (مثل `svchost.exe`) تا نرم‌افزارهای امنیتی متوجه نشوند.
*   **تغییر تنظیمات شبکه و فایروال:** باز کردن پورت‌های جدید یا دستکاری تنظیمات VPN برای ایجاد مسیرهای ارتباطی پنهان.
*   **نصب روت‌کیت‌ها (Rootkits):** پنهان کردن عمیق فایل‌ها و ارتباطات شبکه در سطح کرنل (Kernel).

### ۷. فاز تکمیل مأموریت (Complete Mission)
در این مرحله نهایی، مهاجمان به هدف اصلی خود از نفوذ می‌رسند.
*   **سرقت و خروج داده‌ها (Data Exfiltration):** فشرده‌سازی، رمزنگاری و ارسال اطلاعات حساس (مالی، مالکیت معنوی، پایگاه داده مشتریان) به سرورهای خارج از سازمان (اغلب از طریق پروتکل‌های رمزنگاری شده یا تونل‌زنی DNS).
*   **باج‌افزار (Ransomware):** رمزنگاری فایل‌ها و سرورهای سازمان جهت اخاذی مالی.
*   **تخریب داده‌ها (Data Destruction):** استفاده از بدافزارهای پاک‌کننده (Wiper) برای پاک کردن کامل هارد دیسک‌ها و از کار انداختن زیرساخت سازمان (با هدف خرابکاری).
*   **تغییر ظاهر وب‌سایت (Defacement) یا دستکاری اطلاعات:** تغییر اطلاعات مهم دیتابیس‌ها برای اهداف خاص.
