

#### Function ProtoType

**نمونه‌اولیه تابع (Function Prototype)** که به آن **اعلان تابع (Function Declaration)** نیز گفته می‌شود، یک مفهوم بنیادی در زبان‌های برنامه‌نویسی مانند C و ++C است. 

نمونه‌اولیه در واقع به کامپایلر می‌گوید که تابعی با یک نام مشخص، نوع خروجی معین و پارامترهای ورودی خاص وجود دارد، **بدون اینکه بدنه (کدهای اجرایی) آن تابع را در آن لحظه پیاده‌سازی کند.**

### ساختار کلی
ساختار یک Function Prototype به شکل زیر است:
```c
ReturnType FunctionName(Type1 Param1, Type2 Param2, ...);
```
*   **ReturnType (نوع بازگشتی):** مشخص می‌کند تابع چه نوع داده‌ای (مثل `int`, `void`, `HWND`) برمی‌گرداند.
*   **FunctionName (نام تابع):** نامی که برای فراخوانی تابع استفاده می‌شود.
*   **Parameters (پارامترها):** نوع و تعداد ورودی‌های تابع را مشخص می‌کند. (نوشتن نام متغیرها در Prototype اختیاری است و فقط ذکر نوع آن‌ها کفایت می‌کند، اما برای خوانایی بیشتر معمولاً نام متغیرها هم نوشته می‌شود).

### دلایل استفاده از Function Prototype

۱. **مدیریت نحوه خوانش کامپایلر (Top-Down Parsing):**
کامپایلرهای C و ++C کدها را از بالا به پایین می‌خوانند. اگر شما تابعی را قبل از اینکه تعریف (پیاده‌سازی) شده باشد در برنامه فراخوانی کنید، کامپایلر خطا می‌دهد زیرا هنوز آن را نمی‌شناسد. با قرار دادن Prototype در بالای فایل یا در فایل‌های سرآیند (Header Files)، کامپایلر با ساختار تابع آشنا می‌شود و اجازه می‌دهد بدنه تابع را در انتهای فایل تعریف کنید.

۲. **بررسی صحت انواع داده (Type Checking):**
نمونه‌اولیه به کامپایلر اجازه می‌دهد تا هنگام فراخوانی تابع، نوع داده‌های ورودی و خروجی را بررسی کند. مثلاً اگر تابعی برای محاسبه مجموع $x + y$ نیاز به دو ورودی از نوع `int` دارد، ولی شما به آن `string` پاس بدهید، کامپایلر به کمک Prototype متوجه این مغایرت شده و از بروز خطای منطقی جلوگیری می‌کند.

### مثال عملی

در مثال زیر، نمونه‌اولیه قبل از تابع `main` نوشته شده است، اما پیاده‌سازی اصلی در انتهای کد قرار دارد:

```c
#include <stdio.h>

// Function Prototype (اعلان تابع)
int calculateSum(int a, int b); 

int main() {
    // فراخوانی تابع
    int result = calculateSum(10, 5);
    printf("Result: %d\n", result);
    return 0;
}

// Function Definition (تعریف و پیاده‌سازی بدنه تابع)
int calculateSum(int a, int b) {
    return a + b;
}
```

### ارتباط با Windows API
در گفتگوهای قبلی به Windows API اشاره شد. فایل معروف `windows.h` که برنامه‌نویسان ویندوز به پروژه‌های خود اضافه می‌کنند (Include)، در واقع حاوی هزاران **Function Prototype** (مانند `CreateWindowExA`) است. مایکروسافت از طریق این فایلِ سرآیند، توابع خود را به کامپایلر شما معرفی می‌کند، در حالی که کدهای اجرایی (بدنه توابع) درون فایل‌های سیستم‌عامل (فایل‌های `.dll`) قرار دارند.
