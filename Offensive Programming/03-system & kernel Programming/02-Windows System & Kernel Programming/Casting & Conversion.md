
در زبان‌های C و C++، هر زمان که نیاز باشد نوع یک داده (Data Type) به نوع دیگری تغییر کند، از دو مفهوم **Conversion** و **Casting** استفاده می‌شود. تفاوت اصلی این دو در **نحوه انجام (خودکار یا دستی)** و **مدیریت از دست رفتن داده‌ها (Data Loss)** است.

در ادامه، هر دو مفهوم به صورت کاملاً ساختاریافته و حرفه‌ای بررسی شده‌اند:

### ۱. Datatype Conversion (تبدیل نوع ضمنی - Implicit)
این روش که به آن **Implicit Type Conversion** یا **Coercion** نیز می‌گویند، **به‌صورت خودکار توسط کامپایلر** انجام می‌شود. برنامه‌نویس مستقیماً در این فرآیند دخالتی ندارد. 

این اتفاق معمولاً زمانی رخ می‌دهد که در یک عبارت محاسباتی (Math Expression)، متغیرهایی با انواع مختلف (مثلاً `int` و `float`) ترکیب شوند یا مقداری در متغیری با نوع متفاوت ذخیره شود.

*   **Type Promotion (ارتقاء نوع):** اگر داده‌ای با دقت پایین‌تر با داده‌ای با دقت بالاتر ترکیب شود، کامپایلر برای جلوگیری از از دست رفتن اطلاعات، نوع کوچک‌تر را به نوع بزرگ‌تر ارتقا می‌دهد.
    *   مثال: اگر $A$ از نوع `int` و $B$ از نوع `float` باشد، در عبارت $C = A + B$، کامپایلر ابتدا مقدار $A$ را موقتاً به `float` تبدیل کرده و سپس جمع را انجام می‌دهد.
*   **Data Demotion (تنزل نوع):** اگر مقدار یک نوعِ بزرگ‌تر را در یک نوعِ کوچک‌تر ذخیره کنید، کامپایلر آن را برش (Truncate) می‌دهد که منجر به از دست رفتن داده می‌شود.
    *   مثال: ذخیره کردن مقدار $3.14$ در یک متغیر `int`، باعث می‌شود بخش اعشاری حذف شده و فقط مقدار $3$ ذخیره شود. در این حالت کامپایلر معمولاً یک اخطار (Warning) تولید می‌کند.

### ۲. Datatype Casting (تبدیل نوع صریح - Explicit)
این روش که به آن **Explicit Type Conversion** می‌گویند، **توسط برنامه‌نویس و به‌صورت دستی** انجام می‌شود. در اینجا شما به کامپایلر دستور می‌دهید که اخطارها را نادیده بگیرد و متغیر را به زور به نوعی که شما می‌خواهید تبدیل کند. برنامه‌نویس مسئولیت هرگونه از دست رفتن داده یا خطای منطقی را می‌پذیرد.

#### الف) C-Style Casting (روش کلاسیک زبان C)
در زبان C، با قرار دادن نوع دلخواه در پرانتز قبل از متغیر یا مقدار، کستینگ انجام می‌شود.
```c
float f = 5.89;
// Casting float to int manually
int x = (int)f; 
```
در اینجا مقدار متغیر $x$ برابر با $5$ خواهد شد.

#### ب) C++ Casting Operators (روش مدرن و امن‌تر C++)
زبان C++ به دلیل خطرات پنهان C-Style Casting، چهار عملگر (Operator) اختصاصی برای Casting معرفی کرده است که کنترل بسیار دقیق‌تری به برنامه‌نویس می‌دهند (به‌خصوص در کار با Windows API و برنامه‌نویسی سیستمی):

1.  **`static_cast`**: برای تبدیل‌های معمول و ایمن در زمان کامپایل (Compile-time).
    *   مثال: `int x = static_cast<int>(3.14);`
2.  **`reinterpret_cast`**: خطرناک‌ترین نوع Cast. به کامپایلر می‌گوید بیت‌های حافظه را بدون تغییر، به عنوان یک نوع دیگر تفسیر کند. در اکسپلویت‌نویسی، تزریق کد و Windows API (مثل تبدیل یک آدرس حافظه یا یک `HANDLE` به `DWORD` و برعکس) بسیار کاربرد دارد.
3.  **`dynamic_cast`**: برای تبدیل امن اشاره‌گرها در کلاس‌های دارای ارث‌بری (Polymorphism) در زمان اجرا (Run-time).
4.  **`const_cast`**: صرفاً برای حذف یا اضافه کردن خاصیت `const` از یک متغیر استفاده می‌شود.

### جدول مقایسه (خلاصه برای جزوه)

| ویژگی                 | Datatype Conversion (تبدیل ضمنی)                                   | Datatype Casting (تبدیل صریح)                                       |
| :-------------------- | :----------------------------------------------------------------- | :------------------------------------------------------------------ |
| **عامل اجرا**         | خودکار توسط کامپایلر                                               | دستی توسط برنامه‌نویس                                               |
| **کلیدواژه / سینتکس** | ندارد                                                              | `(type)` یا عملگرهای `<type>_cast`                                  |
| **هدف اصلی**          | اجرای محاسبات ترکیبی و جلوگیری از ارور                             | اعمال تغییرات اجباری در نوع داده                                    |
| **امنیت داده‌ها**     | در صورت تنزل (Demotion) ممکن است داده از بین برود (همراه با اخطار) | برنامه‌نویس اخطار را سرکوب می‌کند (مسئولیت بر عهده برنامه‌نویس است) |


**مثال اول (Implicit Conversion): کاملاً درست است.**

در این مثال، مقدار `max` که از نوع `short` (معمولاً ۲ بایت) است، در متغیر `a` که از نوع `int` (معمولاً ۴ بایت) است، قرار می‌گیرد. کامپایلر این تبدیل (Type Promotion) را به‌طور **خودکار و ضمنی** انجام می‌دهد و هیچ داده‌ای از بین نمی‌رود.

---

**مثال دوم (Explicit Casting): نادرست است.**

کد دوم شما نه‌تنها مثالی از Explicit Casting نیست، بلکه کامپایل نمی‌شود (Compile Error می‌دهد). دلایل اشتباه بودن آن به شرح زیر است:

1. **عدم استفاده از عملگر کست (Cast Operator):** شما در این کد به‌صورت دستی متغیر را تبدیل نکرده‌اید (هیچ پرانتز یا دستور `cast` وجود ندارد). این فقط یک تلاش ناموفق برای انتساب (Assignment) است.
2. **خطای نحوی (Syntax Error):** تعریف آرایه `char* name[]` بدون تعیین اندازه یا مقداردهی اولیه در C++ مجاز نیست.
3. **عدم تطابق نوع (Type Mismatch):** شما نمی‌توانید یک عدد صحیح (`int`) را مستقیماً درون یک آرایه از اشاره‌گرها (`char*[]`) قرار دهید.

### مثال صحیح برای Explicit Casting

اگر می‌خواهید تبدیل نوع را به‌صورت **صریح (دستی)** انجام دهید، کد باید به یکی از دو شکل زیر باشد:

**روش اول (C-Style Casting):**
تبدیل یک عدد اعشاری به صحیح (از بین بردن عمدی بخش اعشاری).
```cpp
float pi = 3.14f;
int a = (int)pi; // Explicitly casting float to int
std::cout << a << std::endl; // Output: 3
```

**روش دوم (استفاده از C++ Casting Operators - پیشنهاد شده):**
در محیط C++، بهتر است از `static_cast` استفاده کنید تا قصد شما برای کامپایلر و برنامه‌نویس‌های دیگر کاملاً شفاف باشد:
```cpp
float pi = 3.14f;
int a = static_cast<int>(pi); // Modern C++ explicit casting
std::cout << a << std::endl; // Output: 3
```

**نکته درباره اشاره‌گرها (نزدیک به ایده کد شما):**
اگر قصد داشتید یک عدد صحیح را به زور به یک اشاره‌گر تبدیل کنید (که در برنامه‌نویسی سیستمی و اکسپلویت‌نویسی کاربرد دارد)، باید از Explicit Cast از نوع `reinterpret_cast` استفاده کنید:
```cpp
int address = 0x00FF10;
// Explicitly casting an integer to a char pointer
char* ptr = reinterpret_cast<char*>(address); 
```
