

مفهوم **مقدار بازگشتی تابع (Function Return)** یکی از ارکان اصلی برنامه‌نویسی است. به بیان ساده، مقدار بازگشتی راهی است تا یک تابع، پس از پایان یافتن عملیاتش، نتیجه‌ی کار یا وضعیت اجرای خود را به بخشی از برنامه که آن را فراخوانی کرده است (Caller)، گزارش دهد.

در ادامه، این مفهوم را با تمرکز بر تابع `MessageBox` در Windows API بررسی می‌کنیم:

### ۱. چرا `MessageBox` یک مقدار `int` (عدد صحیح) برمی‌گرداند؟
زمانی که شما تابع `MessageBox` را فراخوانی می‌کنید، سیستم‌عامل یک پنجره پیام روی صفحه نمایش می‌دهد و اجرای برنامه را متوقف می‌کند تا کاربر واکنشی نشان دهد (مثلاً روی یک دکمه کلیک کند یا پنجره را ببندد).

برنامه شما باید بداند کاربر چه تصمیمی گرفته است تا بر اساس آن واکنش مناسبی نشان دهد. از آنجا که کامپیوترها با اعداد کار می‌کنند، سیستم‌عامل تصمیم کاربر را در قالب یک عدد صحیح (`int`) به برنامه شما برمی‌گرداند. این عدد مشخص می‌کند که کاربر دقیقاً روی کدام دکمه کلیک کرده است.

### ۲. مقادیر بازگشتی استاندارد برای `MessageBox`
در Windows API، به جای اینکه برنامه‌نویس مجبور باشد اعداد خام را حفظ کند، از ثابت‌ها (Constants) استفاده می‌شود که در فایل `windows.h` تعریف شده‌اند. چند نمونه از این مقادیر بازگشتی عبارتند از:

*   **`IDOK`** (مقدار برابر با $1$): کاربر روی دکمه **OK** کلیک کرده است.
*   **`IDCANCEL`** (مقدار برابر با $2$): کاربر روی دکمه **Cancel** کلیک کرده یا کلید `Esc` را فشرده است.
*   **`IDYES`** (مقدار برابر با $6$): کاربر روی دکمه **Yes** کلیک کرده است.
*   **`IDNO`** (مقدار برابر با $7$): کاربر روی دکمه **No** کلیک کرده است.

### ۳. مثال کاربردی در کد
فرض کنید می‌خواهید هنگام خروج کاربر از برنامه، از او بپرسید که آیا مایل به ذخیره اطلاعات هست یا خیر. کد شما (در زبان C یا C++) به این شکل خواهد بود:

```cpp
#include <windows.h>

int main() {
    // فراخوانی تابع و ذخیره خروجی آن در متغیر result
    int result = MessageBox(NULL, "Do you want to save changes?", "Exit", MB_YESNOCANCEL | MB_ICONQUESTION);

    // بررسی مقدار بازگشتی برای تعیین جریان برنامه (Control Flow)
    if (result == IDYES) {
        // کدهای مربوط به ذخیره اطلاعات در اینجا قرار می‌گیرند
    } 
    else if (result == IDNO) {
        // برنامه بدون ذخیره اطلاعات بسته می‌شود
    } 
    else if (result == IDCANCEL) {
        // عملیات خروج لغو شده و کاربر به برنامه برمی‌گردد
    }

    return 0;
}
```

### جمع‌بندی
خروجی `int` در توابعی مانند `MessageBox` در واقع یک **مکانیزم ارتباطی** است. این خروجی به کامپایلر و برنامه شما می‌گوید: *"عملیات با موفقیت انجام شد و انتخاب کاربر، گزینه‌ای است که با این عدد مشخص می‌شود."* استفاده از مقادیر بازگشتی برای کنترل جریان برنامه (Control Flow) و مدیریت خطاها در نرم‌افزارهای حرفه‌ای کاملاً ضروری است.

######  برای یک مثال دیگر تابع Beep یک صدایی رو بسته به فرکانسی که تنظیم میکنیم در می اورد 
 
```c
#include <windows.h>
#include <stdio.h>

int main()
{
	if (Beep(950, 200))
		MessageBox(NULL, L"hello charon", L"caption", MB_OK);
	return 0x0;
}
```
