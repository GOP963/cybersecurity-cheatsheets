


### System programming

System programming involves creating software that interacts closely with the Windows
operating system's core components and hardware resources.

This type of programming leverages the Windows API to control processes, manage memory,
handle files, and communicate with system hardware.

Interfaces:
1. Win32 API
2. Native API
3. COM (Component Object Model)
4. WMI (Windows Management Instrumentation)



### Kernel programming

Kernel programming refers to developing software that operates at the core of an
operating system, known as the kernel.

The kernel is responsible for managing hardware resources, system security, process
scheduling, memory management, and other critical system functions.

In Windows, kernel programming involves writing code that interacts directly with the
Windows kernel, providing low-level control over system operations.

Frameworks/Toolkits:
1. NTDDK (Windows NT Device Driver Kit)
2. WDM  (Windows Driver Model)
3. WDK   (Windows Driver Kit)
4. WDF   (Windows Driver Frameworks)

##### Windows Internals and System/Kernel Programming

Windows Internals refers to the core workings of the Windows operating system, including
its architecture, components, and mechanisms.

It focuses on how Windows manages things like processes, memory, hardware, and security,
and how different parts of the system interact to keep everything running smoothly.

Understanding Windows Internals is essential for optimizing performance, troubleshooting,
and working on low-level system programming.

For example, when working with processes or files, we first explain how they work inside
the system to build a strong foundation.

This includes understanding how they function, interact with the operating system, and
manage resources. Once this is clear, we can move on to coding, using that knowledge to
write effective programs or tools.
