

در زبان‌های C و C++، انواع داده‌ای وجود دارند که به آن‌ها **Built-in Data Types** (یا Primitive/Fundamental Data Types) گفته می‌شود. این نوع داده‌ها مستقیماً در هسته‌ی خود زبان تعریف شده‌اند و کامپایلر آن‌ها را ذاتاً می‌شناسد؛ در نتیجه برای استفاده از آن‌ها **هیچ نیازی به `include` کردن هدر فایل خاصی نیست**.

برای ثبت در جزوه‌تان، می‌توانید این دسته‌بندی را به این شکل ساختاردهی کنید:

### ویژگی‌های Built-in Data Types
*   **شناخت ذاتی:** جزو کلمات کلیدی (Keywords) رزرو شده‌ی زبان برنامه‌نویسی هستند.
*   **عدم وابستگی:** بدون نیاز به فایل‌های سرآیند (مثل `<windows.h>` یا `<iostream>`) مستقیماً قابل استفاده‌اند.

### لیست Built-in Data Types پایه‌ای
1.  **انواع صحیح (Integer Types):** `int`, `char`, `short`, `long`, `long long` (به همراه پیشوندهای `unsigned` و `signed`).
2.  **انواع اعشاری (Floating-Point Types):** `float`, `double`, `long double`.
3.  **نوع منطقی (Boolean):** `bool` (در C++ کاملاً Built-in است).
4.  **نوع پوچ (Void):** `void` (برای توابعی که خروجی ندارند یا اشاره‌گرهای بدون نوع).

**نکته‌ی تکمیلی برای جزوه:**
در نقطه‌ی مقابلِ این دسته، **User-defined**ها و **Library-defined**ها قرار دارند. مواردی مانند `DWORD`، `HANDLE`، `size_t` یا `std::string` انواع داده‌ی Built-in نیستند؛ بلکه بر اساس همان نوع‌های پایه ساخته شده‌اند و حتماً نیازمند هدر فایل‌های مربوطه (مثل `windows.h` یا `string`) هستند.


برای تکمیل جزوه‌ی شما، **Windows Data Types** (انواع داده‌ی اختصاصی ویندوز) را می‌توان به صورت زیر دسته‌بندی و تعریف کرد. 

این نوع داده‌ها Built-in نیستند؛ بلکه مایکروسافت آن‌ها را در فایل سرآیند `<windows.h>` با استفاده از `typedef` یا `#define` بر پایه‌ی همان انواع داده‌ی استاندارد C/C++ ساخته است. هدف اصلی این کار، **حفظ سازگاری کدها** در معماری‌های مختلف ($16$-بیتی، $32$-بیتی و $64$-بیتی) و **افزایش خوانایی** است.

### دسته‌بندی Windows Data Types 

#### ۱. انواع صحیح (Integer Types)
این نوع‌ها برای نگهداری اعداد بدون علامت (Unsigned) و مقادیر باینری استفاده می‌شوند:
*   **`BYTE`**: یک عدد صحیح بدون علامت $8$-بیتی. معادل `unsigned char` است.
*   **`WORD`**: یک عدد صحیح بدون علامت $16$-بیتی (معادل $2$ بایت). معادل `unsigned short` است.
*   **`DWORD`** (Double Word): یک عدد صحیح بدون علامت $32$-بیتی (معادل $4$ بایت). در ویندوز بسیار پرکاربرد است و معمولاً معادل `unsigned long` است.
*   **`QWORD`** (Quad Word): یک عدد صحیح بدون علامت $64$-بیتی (معادل $8$ بایت).

#### ۲. نوع منطقی (Boolean Type)
*   **`BOOL`**: برخلاف `bool` در ++C که فقط $1$ بایت است، `BOOL` در ویندوز در واقع یک `int` (عدد صحیح $32$-بیتی) است. 
    *   مقدار صفر ($0$) معادل `FALSE`
    *   مقدار غیر صفر (معمولاً $1$) معادل `TRUE`

#### ۳. شناسه‌ها یا دستگیره‌ها (Handles)
هندل‌ها در واقع مقادیری (غالباً اشاره‌گرهای پنهان‌شده) هستند که سیستم‌عامل برای شناسایی و مدیریت منابع سیستم به برنامه می‌دهد.
*   **`HANDLE`**: نوع پایه‌ای و عمومی برای شناسایی یک شیء در ویندوز (مثل فایل، پراسس، یا ترد).
*   **`HWND`** (Handle to a Window): شناسه اختصاصی برای یک پنجره (Window).
*   **`HINSTANCE`**: شناسه‌ی نمونه‌ی در حال اجرای یک برنامه یا ماژول.
*   **`HDC`** (Handle to a Device Context): شناسه‌ای برای محیط رسم گرافیکی (رسم خط، متن و...).

#### ۴. اشاره‌گرها و رشته‌ها (Pointers & Strings)
در سبک نام‌گذاری ویندوز، پیشوند `P` یا `LP` (Long Pointer) نشان‌دهنده‌ی اشاره‌گر است.
*   **`LPVOID`**: اشاره‌گر به هر نوع داده‌ای. دقیقاً معادل `void*` در C است.
*   **`LPSTR`** (Long Pointer to String): اشاره‌گر به یک رشته‌ی ANSI که با کاراکتر Null پایان می‌یابد. معادل `char*`.
*   **`LPCSTR`** (Long Pointer to Constant String): همان `LPSTR` است، با این تفاوت که محتوای آن ثابت (Constant) است. معادل `const char*`.
*   **`LPWSTR`** (Long Pointer to Wide String): اشاره‌گر به یک رشته‌ی Unicode (Wide) که با Null پایان می‌یابد. معادل `wchar_t*`.
*   **`LPCWSTR`**: نسخه‌ی ثابت و غیرقابل تغییر `LPWSTR`. معادل `const wchar_t*`.

**خلاصه:**
شما در برنامه‌نویسی Windows API به ندرت از `int` یا `char*` به صورت مستقیم استفاده می‌کنید؛ بلکه برای هماهنگی با توابع ویندوز (مثل `MessageBox` یا `CreateWindowEx`) از معادل‌های ویندوزی آن‌ها یعنی `DWORD`، `BOOL` یا `LPCWSTR` بهره می‌برید.


در واقع، کامپایلر C/C++ در پایین‌ترین سطح فقط همان **Built-in Data Type**ها را می‌فهمد و با آن‌ها کار می‌کند. تمام انواع داده‌ی ویندوزی (Windows Data Types) صرفاً یک لایه انتزاع (Abstraction) یا «نام مستعار» (Alias) هستند که به عنوان یک پوسته روی انواع پایه‌ای زبان کشیده شده‌اند.
