
فرض کنید برنامه ما میخواد یه دیتایی رو ذخیره کنه یا میخواد یه دیتایی رو بخونه زمانی که پروسس بخواد اینکارو رو انجام بده می‌تونه از طریق variable ها انجام بدن 
البته که اینکار رو هم میشه از طریق یه سری  Special variables  ماننده   data segment ،code segment  هم انجام بده 
نکته یی که وجود داره اینه که محدودیتی هست که فضای اینها در اختیار پروسس قرار میدن 
به عنوان مثال  در فضای Heap ما ادرس بیشتری رو میتونیم در اختیار داشته باشیم اما در  فضای stack اینکار کمتر اتفاق می افته 
ولی از طرف دیگر stack توسط خوده سیستم عامل مدیریت میشه، اما فضای Heap توسط خوده برنامه نویس مدیریت میشه

پس فایل ها در سیستم عامل object هایی هستن که این امکان رو میدن تا برنامه بتونه از طریق این فایل ها یه سری منابعی رو به اشتراک بزار، بخونه، ذخیره کنه، چرا چون که هندل  کردن فایل توسط خوده سیستم عامل انجام میشه 
حالا این فایل ها شامل یه سری Structure هستن که ما میتونیم هنگام کار با فایل بسته به نیازی که داریم member های مربوط به این structure رو پر کنیم
