یکی از مفاهیم کلیدی در بحث **شبکه و امنیت**، حالتی به نام **Promiscuous Mode** هست که مربوط به **کارت شبکه (Network Interface Card - NIC)** می‌شه.

---

## 🟡 Promiscuous Mode چیست؟

در حالت عادی، کارت شبکه فقط **بسته‌هایی (Packets)** رو دریافت می‌کنه که:

- یا مخصوص خودش هستن (بر اساس MAC address خودش)
    
- یا **broadcast** یا **multicast** هستن
    

اما در **Promiscuous Mode**، کارت شبکه **همه‌ی ترافیک عبوری** از شبکه محلی (LAN) رو دریافت می‌کنه، **حتی اگه مقصد بسته MAC خودش نباشه!** 🎯

---

## 🧠 تعریف ساده:

> در Promiscuous Mode، کارت شبکه «فضولی» می‌کنه و همه‌چیز رو گوش می‌ده، نه فقط چیزهایی که مخصوص خودشه.

## 🛠 فعال‌سازی Promiscuous Mode

بسته به سیستم‌عامل و ابزار:

### 🔹 در لینوکس:

```bash
ip link set eth0 promisc on
```

یا با `ifconfig`:

```bash
ifconfig eth0 promisc
```

### 🔸 در Wireshark:

- به‌صورت خودکار هنگام شروع ضبط (capture) فعال می‌شه.
    
- یا دستی می‌تونی تیک گزینه‌ی Promiscuous Mode رو بزنـی.
