

با استفاده از علامت * میتونیم value تارگت اشاره گر مون رو چاپ کنیم 

مثال : 

```c
int num = 5;
int *pi = &num;
```

```c
printf("%d\n", *pi); // مقدار 5 را نمایش می‌دهد
```

اگر بخواهیم ادرس حافظه تارگت اشاره گرمون رو چاپ کنیم با استفاده از format specifiers (%p) 

```c
printf("%p",pi);
```

اگر هم بخواهیم value تارگت اشاره گرمون رو ببینیم باید از format scpecfires (%p) استفاده کنیم با این تفاوت قبل از نوشتن اشاره گر بیایم و  از علامت * نکته یی که داره اینه که اون مقدار اگر integer باشد به ما به صورت hex نشون میده 



## تبدیل اشاره‌گرها به void و برعکس

هر نوع اشاره‌گری را می‌توان به `void*` نسبت داد،  
و بعد دوباره به نوع اصلی‌اش برگرداند.

در این حالت:

- مقدار آدرس **دقیقاً همان مقدار قبلی** خواهد بود.


```c
int num;
int *pi = &num;

printf("Value of pi: %p\n", pi);

void *pv = pi;
pi = (int*) pv;

printf("Value of pi: %p\n", pi);

```


## size_t چیست؟

`size_t`
یک نوع داده برای نگهداری **اندازه‌ها** است  
و در بخش «انواع داده‌ی از پیش تعریف‌شده‌ی مرتبط با اشاره‌گرها» توضیح داده می‌شود.
