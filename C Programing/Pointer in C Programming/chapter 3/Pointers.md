

اشاره‌گرها  
تو می‌تونی آدرس یک شیء رو توی یک شیء دیگه ذخیره کنی، و اینجا می‌رسیم به مفهوم اشاره‌گرها. یک **اشاره‌گر** متغیریه که آدرس‌های حافظهٔ سایر اشیاء رو نگه می‌داره. وقتی می‌خواهیم یک متغیر را به‌عنوان اشاره‌گر اعلام کنیم، یک ستاره `*` بلافاصله بعد از نوع داده‌ای که به آن اشاره می‌کند اضافه می‌کنیم. اگر بنویسیم:

```
int i = 1;
int *pi = &i;
int **ppi = &pi;
```

آنگاه `i` یک عدد صحیح است، `pi` یک اشاره‌گر به عدد صحیح است (نوع آن `int *` است)، و `ppi` یک اشاره‌گر به یک اشاره‌گر به عدد صحیح است (نوع آن `int **` است، یعنی اشاره‌گری به `int *` که خودش اشاره‌گری به یک عدد صحیح است). متغیر `pi` آدرس `i` را ذخیره می‌کند (چون `pi = &i` انجام شده)، و متغیر `ppi` آدرس `pi` را ذخیره می‌کند.

اگر بخواهیم مقدار تارگت Pointer رو چاپ کنیم به این شکل مینویسم 

```
printf("%d\n",**ppi);  OR   printf("%d\n",**pi); 
```

یعنی داریم میگیم که مقداری که تارگت Pointer  که pointer فعلی داره بهش اشاره میکنه رو میخوام برای من نمایش بدی 

با استفاده از فرمت %d اینکارو میکنیم  یعنی میخوام %d  باشه اما با استفاده از * بهش میگیم که متغیرم از نوع pointer هستش

```
    printf("i = %d\n, &i = %p\n", i, &i);
    printf("pi = %p\n, &pi = %p\n", pi, &pi);
    printf("ppi = %p\n, &ppi = %p\n", ppi, &ppi);
```

می‌توانیم مقادیر داخل متغیرها و آدرس‌هایی که آنها در حافظه قرار دارند را ببینیم. روی ماشین من، خروجی‌ای مانند زیر

```
i = 1
, 
&i = 0x7ffee283d8fc
pi = 0x7ffee283d8fc
, 
&pi = 0x7ffee283d8f0
ppi = 0x7ffee283d8f0
, 
&ppi = 0x7ffee283d8e8

```

این به این معنی است که عدد داخل متغیر `i` در آدرس حافظه‌ی `0x7ffee283d8fc` قرار دارد. وقتی قبلاً `&i` را به `pi` نسبت دادیم، `pi` این آدرس را به‌عنوان مقدار خود گرفت. مقدار `pi` در آدرس `&pi` قرار دارد که آن آدرس `0x7ffee283d8f0` است. متغیر `ppi` هم آدرس `pi` یعنی `0x7ffee283d8f0` را نگه می‌دارد و خودش در آدرس `0x7ffee283d8e8` قرار گرفته است



```
*pi = 2;
printf("i = %d, pi = %p, ppi = %p\n", i, pi, ppi);
**ppi = 3;
printf("i = %d, pi = %p, ppi = %p\n", i, pi, ppi);
```


```
i = 2, pi = 0x7ffee283d8fc, ppi = 0x7ffee283d8f0
i = 3, pi = 0x7ffee283d8fc, ppi = 0x7ffee283d8f0
```



```
#include <math.h>
#include <float.h>
#include <stdio.h>

typedef struct vector {
    double x;
    double y;
    double z;
} vector;

void print_vector(vector const *v)
{
    double x = v->x, y = v->y, z = v->z;
    printf("<%.2f, %.2f, %.2f>\n", x, y, z);
}

double vector_length(vector *v)
{
    double x = v->x, y = v->y, z = v->z;
    return sqrt(x*x + y*y * z*z);
}

vector *shortest(int n, vector *vectors[n])
{
    vector *shortest = &(vector){
        .x = DBL_MAX, .y = DBL_MAX, .z = DBL_MAX
    };
    double shortest_length = vector_length(shortest);
    for (int i = 0; i < n; ++i) {
        vector *v = vectors[i];
        double length = vector_length(v);
        if (length < shortest_length) {
            shortest = v;
            shortest_length = length;
        }
    }
    return shortest;
}

int main(void)
{
    vector *vectors[] = {
        &(vector){ .x = 10.0, .y = 13.0, .z = 42.0 },
        &(vector){ .x = -1.0, .y = 32.0, .z = 15.0 },
        &(vector){ .x = 0.0, .y = 3.0, .z = 1.0 }
    };
    print_vector(shortest(3, vectors));
    print_vector(shortest(2, vectors));
    print_vector(shortest(1, vectors));
    print_vector(shortest(0, vectors)); // BOOOM!!!
    return 0;
}

```

## designated initializer

اون **نقطه قبل از اسم فیلد** مثل `.x = ...` دقیقاً یکی از ویژگی‌های پیشرفته‌ی زبان C هست، که بهش می‌گن **“designated initializer”**.  
بیای دقیق و مرحله‌به‌مرحله ببینیم چی می‌گذره 👇

---

### 🧩 ۱. اول از همه: این عبارت یعنی چی؟

کد زیر رو داریم:

```c
&(vector){ .x = DBL_MAX, .y = DBL_MAX, .z = DBL_MAX }
```

بیای تکه‌تکه‌اش کنیم:

1. `(vector){ ... }` → یعنی **ساختن یک مقدار موقت (temporary)** از نوع `vector`.
    
2. داخل آکولادها (`{}`) داریم:  
    `.x = DBL_MAX, .y = DBL_MAX, .z = DBL_MAX`  
    یعنی:
    
    - فیلد `x` در struct مقدارش بشه `DBL_MAX`
        
    - فیلد `y` هم `DBL_MAX`
        
    - فیلد `z` هم `DBL_MAX`
        
3. قبل از اون هم `&` گذاشته، یعنی **آدرس اون struct موقتی** رو گرفته تا اشاره‌گر (`pointer`) بهش بسازه.
    

---

### 💡 حالا `DBL_MAX` چیه؟

`DBL_MAX` از کتابخانه‌ی `<float.h>` میاد و بزرگ‌ترین عددی هست که از نوع `double` می‌تونه نگه داره.

پس `DBL_MAX` یعنی:

> «بیشترین مقدار ممکن برای یک عدد double.»

---

### 🎯 هدف برنامه‌نویس چی بوده؟

تابع `shortest()` قراره بین چند تا بردار (vector) **کوتاه‌ترین** رو پیدا کنه.

اما قبل از اینکه حلقه شروع بشه، باید یه مقدار اولیه برای «کوتاه‌ترین بردار فعلی» تعریف کنه.

برای همین، برنامه‌نویس می‌گه:

> «در ابتدا فرض کن کوتاه‌ترین بردار، برداریه که طولش خیلی خیلی بزرگه (عملاً بی‌نهایت).»

و این کار رو با `DBL_MAX` انجام می‌ده.

پس این خط:

```c
vector *shortest = &(vector){ .x = DBL_MAX, .y = DBL_MAX, .z = DBL_MAX };
```

در واقع می‌گه:

> یه بردار موقت بساز با مختصات خیلی بزرگ (`x=y=z=DBL_MAX`)  
> و اشاره‌گری به اون نگه دار، تا بعداً اگر بردار کوتاه‌تری پیدا شد، جایگزینش کنیم.

---

### 🔍 خلاصه:

|بخش کد|معنی|
|---|---|
|`.x = DBL_MAX`|مقداردهی فیلد `x` با بیشترین مقدار ممکن برای double|
|`.y = DBL_MAX`|مقداردهی فیلد `y`|
|`.z = DBL_MAX`|مقداردهی فیلد `z`|
|`(vector){ ... }`|ساختن یک struct موقت از نوع `vector`|
|`&`|گرفتن آدرس اون struct موقت|

### 🔹 مفهوم NULL Pointer در C

در زبان C، **NULL pointer** یعنی اشاره‌گری که _به هیچ چیز اشاره نمی‌کند_.  
اما نکته‌ی مهم اینجاست:  
این **با اشاره‌گرهای مقداردهی‌نشده یا نامعتبر فرق دارد.**

- اگه یه pointer تعریف کنی ولی مقدارش رو مشخص نکنی، ممکنه به یه آدرس تصادفی توی حافظه اشاره کنه، که خطرناک و غیرقابل‌پیش‌بینیه.
    
- اما اگر اون pointer مقدارش `NULL` باشه، یعنی ما _خودمون_ مشخص کرده‌ایم که این اشاره‌گر فعلاً به هیچ شیء یا آدرسی اشاره نکنه.


```
int *i_null = 0;       // اشاره‌گر NULL برای int
double *d_null = NULL; // اشاره‌گر NULL برای double
```

### 🔹 مقایسه‌ی NULL pointers

همه‌ی اشاره‌گرهای NULL از هر نوعی که باشن، وقتی با هم مقایسه می‌شن **برابر** هستن:

```
if (i_null == (int *)d_null) printf("Yep!\n");   // درست
if (d_null == (double *)i_null) printf("Also yep!\n"); // درست
```

و یا حتی بگذاریم 0 یا NULL بازم جوابش میشه True 

اما اگر اشاره‌گر NULL رو با یه اشاره‌گر واقعی مقایسه کنی، همیشه نابرابر هستن:

```
int *ip = &some_int;
if (i_null == ip) printf("Never happens.\n");
```


اگه یه متغیر عددی با مقدار صفر داری و اونو به pointer تبدیل کنی:
```
int zero = 0;
int *ip = (int *)zero;
```


ممکنه فکر کنی این یعنی NULL، ولی نه دقیقاً.
چون مقدار 0 وقتی به صورت عددی استفاده می‌شه با NULL که یه مقدار مخصوص pointerها هست فرق داره.
به همین خاطر همیشه از NULL یا 0 مستقیم استفاده کن، نه از متغیرهای عددی.

## **const pointers**


---

### 🧩 مفهوم کلی

در زبان C، وقتی از `const` استفاده می‌کنی، ممکنه منظورت یکی از دو چیز باشه:

1. **داده ثابت باشه**، اما اشاره‌گر قابل تغییر.
    
2. **اشاره‌گر ثابت باشه**، اما داده قابل تغییر.
    
3. یا **هردو ثابت باشن.**
    

---

### 📘 چهار ترکیب ممکن:

|تعریف|معنا|
|---|---|
|`int *i_p = 0;`|اشاره‌گر معمولی. هم اشاره‌گر و هم داده قابل تغییرن.|
|`int const *ic_p = 0;`|داده ثابت است، اما اشاره‌گر قابل تغییره.|
|`int * const i_pc = 0;`|اشاره‌گر ثابت است، اما داده قابل تغییره.|
|`int const * const ic_pc = 0;`|هم اشاره‌گر و هم داده ثابت هستند.|

🟢 یعنی:

- `const` **قبل از `*`** = داده ثابت
    
- `const` **بعد از `*`** = اشاره‌گر ثابت
    

---

### 🔄 تفاوت‌ها

- در `int const *ic_p`: نمی‌تونی مقدار متغیری که اشاره‌گر بهش اشاره می‌کنه رو تغییر بدی، ولی می‌تونی اشاره‌گر رو به آدرس دیگه‌ای ببری.
    
- در `int *const i_pc`: می‌تونی مقدار متغیر رو تغییر بدی، ولی نمی‌تونی اشاره‌گر رو جای دیگه‌ای ببری.
    
- در `int const *const ic_pc`: هیچ‌کدوم قابل تغییر نیستن.
    

---

### 🔐 قوانین انتساب (Assignment Rules)

- از **غیر ثابت → ثابت** مجازه ✅
    
- از **ثابت → غیر ثابت** مجاز نیست ❌ (چون ممکنه داده‌ای که نباید تغییر کنه، از طریق اشاره‌گر غیر ثابت تغییر کنه).
    

مثلاً:

```c
int *p;
const int *q;

q = p;  // ✅ مجازه
p = q;  // ❌ غیرمجاز
```

---

### 🧠 چرا این‌قدر سخت‌گیری؟

فرض کن این کد رو داری:

```c
int *p = 0;
int const **q = 0;
int const i = 42;

q = (int const **)&p;
*q = &i;
*p = 5; // ❌ خطرناک!
```

توضیح:

- `q` به `p` اشاره می‌کنه.
    
- `*q = &i` یعنی حالا `p` (از طریق alias) داره به `i` اشاره می‌کنه.
    
- ولی `i` یک مقدار ثابت (`const`) است!
    
- با `*p = 5` داری مقدار `i` رو تغییر می‌دی → این **رفتار تعریف‌نشده (undefined behavior)** محسوب میشه.
    

یعنی در واقع با تبدیل نوع اشتباه (casting) تونستی از قانون "const بودن" فرار کنی، که خطرناک و غیرقانونیه.

---

### ⚠️ قانون کلی برای جلوگیری از رفتار خطرناک

اگر در زنجیره‌ی اشاره‌گرها (مثلاً `int **`, `int ***`, …)  
قبل از سطحی که const شده، اشاره‌گر غیرثابت وجود داشته باشه، ممکنه بتونی alias بسازی و داده‌ی ثابت رو تغییر بدی.

بنابراین C این اجازه رو نمی‌ده مگر اینکه نوع کاملاً یکسان باشه.

---

### 💡 جمع‌بندی ساده

|نوع تعریف|قابل تغییر بودن|
|---|---|
|`int *`|هم داده هم اشاره‌گر|
|`int const *`|فقط اشاره‌گر|
|`int * const`|فقط داده|
|`int const * const`|هیچ‌کدام|
