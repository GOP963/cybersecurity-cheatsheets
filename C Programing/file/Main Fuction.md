
تابع main تابع اصلی برنامه هست که که میشه گفت نقطه شروع برنامه ما محسوب میشود

نکته : ما میتونیم در  تابع main بیایم و کل برنامه مون رو بنویسم اما اگر بخواهیم  پروژه بزرگی مثله نوشتن یک Firmware یا یک RTOS باید حتما توابع مستغلی داشته باشیم تا بعدا بتونیم در برنامه های دیگر هم به نوعی call کنیمش


```
#include <stdio.h>

int main(){
	
	return 0;

}
```

اگر بخواهیم برنامه های مختلفی بنویسم و به نوعی توابع مختلفی داشته باشیم و در تابع main بیایم و صداش کنیم  یعنی نقطه شروع برنامه ما میشه اون توابع دیگر که در تابع main صدا میشوند 

```
#include <stdio.h>

void charon(int a, int b){}
int main(){

	charon(10,12);
	return 0;
}
```


ما سه مدل پیاده سازی تابع main داریم در زبان C 

```
int main(int argc, char* argv[], **envp){
}
```

توی حالت سوم میتونه هم از خط فرمان ورودی بگیره و میتونه متغیر محلی سیستم رو صدا کنه و داشته باشیم 


```
int main(int argc, char* argv[]){
}
```

در این حالت برنامه ما از خط فرمان ورودی میگیره 

```
int main(){
}
```

توی این حالت برنامه ما هیچ ورودی نمیگیره یعنی ما یه برنامه داریم که هیچ ورودی نمیگره

## ۱. امضاهای مختلف تابع `main` در C

### 🔹 حالت اول: با `argc`, `argv`, و `envp`
```c
int main(int argc, char* argv[], char* envp[])
{
    printf("Program name: %s\n", argv[0]);   // اسم برنامه
    printf("First argument: %s\n", argv[1]); // اولین ورودی
    printf("PATH: %s\n", getenv("PATH"));    // متغیر محیطی PATH
    return 0;
}
```

- `argc` = تعداد آرگومان‌ها  
- `argv` = آرایه‌ای از رشته‌ها (آرگومان‌های خط فرمان)  
- `envp` = آرایه‌ای از رشته‌ها (متغیرهای محیطی سیستم، مثل PATH, HOME و ...)  

👉 در این حالت هم از خط فرمان ورودی می‌گیریم، هم می‌تونیم متغیر محیطی رو بخونیم.  

---

### 🔹 حالت دوم: فقط `argc` و `argv`
```c
int main(int argc, char* argv[])
{
    printf("Program name: %s\n", argv[0]);   // اسم برنامه
    if(argc > 1)
        printf("Hello, %s!\n", argv[1]);     // ورودی خط فرمان
    else
        printf("No argument passed!\n");
    return 0;
}
```

📌 اجرای این برنامه:
```
./a.out Martin
```
خروجی:
```
Program name: ./a.out
Hello, Martin!
```

👉 اینجا فقط می‌تونی از خط فرمان ورودی بگیری، ولی به متغیر محیطی دسترسی نداری (مگر اینکه `getenv` صدا بزنی).  

---

### 🔹 حالت سوم: بدون ورودی
```c
int main(void)
{
    printf("This program takes no arguments.\n");
    return 0;
}
```

👉 هر بار اجرا بشه، فقط همین خروجی رو میده، چون نه از خط فرمان چیزی می‌گیره نه از محیط.

## ۲. حالا بریم سراغ سؤال اصلی: این `*` دقیقاً چیه؟

در C، `*` یعنی **pointer** (اشاره‌گر).  
یعنی متغیر به جای اینکه خودش مقدار داشته باشه، **آدرس جایی در حافظه** رو نگه می‌داره.  

- `char* argv[]` یعنی آرایه‌ای از **اشاره‌گر به char**  
  (در واقع آرایه‌ای از رشته‌ها)  

برای روشن‌تر شدن:  
```c
char* argv[]
```
معادل است با:
```c
char** argv
```

چون:  
- `argv[i]` → یک رشته (آدرس شروع رشته در حافظه)  
- `argv[i][j]` → یک کاراکتر از اون رشته  

📌 مثال:
```c
int main(int argc, char* argv[])
{
    printf("argv[0] = %s\n", argv[0]); // اسم برنامه
    printf("argv[1] = %s\n", argv[1]); // اولین آرگومان
    printf("argv[1][0] = %c\n", argv[1][0]); // اولین کاراکتر اولین آرگومان
    return 0;
}
```

اگر اجرا کنی:
```
./a.out Martin
```

خروجی میشه:
```
argv[0] = ./a.out
argv[1] = Martin
argv[1][0] = M
```

---

### 🔑 خلاصه خیلی ساده
- `*` یعنی **اشاره‌گر به چیزی**.  
- `char*` یعنی اشاره‌گر به یک کاراکتر (که میشه همون رشته).  
- `char* argv[]` یعنی آرایه‌ای از اشاره‌گرها به کاراکتر → پس آرایه‌ای از رشته‌هاست.  
- `char** argv` هم همینه، فقط نوشتنش فرق می‌کنه.
