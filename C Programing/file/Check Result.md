
[[format specifier & Pointer]]
---

## 🧠 مفهوم اصلی:
در زبان C، **هر تابعی یه مقدار (return value)** برمی‌گردونه.  
اون مقدار معمولاً نشون می‌ده که آیا عملیات موفق بوده یا خطا رخ داده.

مثلاً:
- اگه تابع مقدار `0` برگردونه → معمولاً یعنی موفقیت  
- اگه مقدار منفی یا غیر صفر برگردونه → معمولاً یعنی خطا  

البته هر تابع قانون خودش رو داره. پس همیشه باید بدونی **اون تابع خاص چه مقداری موقع خطا برمی‌گردونه.**

---

## 💡 مثال‌های عمومی در C:

### 1. تابع `printf()`
```c
int result = printf("Hello\n");
if (result < 0) {
    printf("خطا در چاپ داده!\n");
}
```
🔹 اگر `printf()` نتونه بنویسه (مثلاً خروجی بسته شده باشه)، مقدار منفی برمی‌گردونه.  
در حالت عادی، تعداد کاراکترهای چاپ‌شده رو برمی‌گردونه.

---

### 2. تابع `fopen()` (باز کردن فایل)
```c
FILE *file = fopen("test.txt", "r");

if (file == NULL) {
    printf("خطا در باز کردن فایل!\n");
} else {
    printf("فایل با موفقیت باز شد!\n");
}
```
🔹 اگر فایل پیدا نشه یا اجازه‌ی دسترسی نداشته باشی، تابع `NULL` برمی‌گردونه.

---

### 3. تابع `system()` (اجرای دستور سیستم)
```c
int result = system("xdg-open https://www.openai.com");

if (result == 0) {
    printf("✅ دستور با موفقیت اجرا شد!\n");
} else {
    printf("❌ خطا در اجرای دستور! کد: %d\n", result);
}
```
🔹 اگر مقدار `0` برگرده → موفقیت.  
🔹 مقدار غیر صفر → خطا یا اجرای ناقص.

---

### 4. تابع `ShellExecute()`
مثل مثالی که با هم دیدیم:
```c
HINSTANCE result = ShellExecute(0, "open", "https://www.openai.com", 0, 0, SW_SHOWNORMAL);
if ((int)result > 32) {
    printf("✅ موفقیت!\n");
} else {
    printf("❌ خطا! کد: %d\n", (int)result);
}
```

---

### 5. تابع `malloc()` (اختصاص حافظه)
```c
int *ptr = malloc(sizeof(int) * 10);
if (ptr == NULL) {
    printf("❌ خطا در تخصیص حافظه!\n");
} else {
    printf("✅ حافظه با موفقیت رزرو شد!\n");
}
```

---

## 📘 نتیجه‌گیری کلی:
در زبان C برای بررسی موفقیت یا خطا باید:
1. **نتیجه‌ی تابع رو در متغیر ذخیره کنی**  
2. **اون متغیر رو با مقدارهای مشخص‌شده (مثل NULL، 0 یا >32 و...) مقایسه کنی**

---

### ✅ فرمول ذهنی ساده:
| نوع تابع | بررسی موفقیت | بررسی خطا |
|-----------|---------------|-------------|
| بازگشتی از نوع `int` | `== 0` یا `> 0` | `< 0` یا `!= 0` |
| بازگشتی از نوع `pointer` | `!= NULL` | `== NULL` |
| بازگشتی از نوع خاص (مثل HINSTANCE) | طبق مستندات تابع | طبق مستندات تابع |

## 🧾 لیست بررسی موفقیت / خطا در توابع پرکاربرد زبان C

| تابع                         | نوع مقدار برگشتی    | نشانه‌ی موفقیت                     | نشانه‌ی خطا          | توضیح کوتاه                                               |
| ---------------------------- | ------------------- | ---------------------------------- | -------------------- | --------------------------------------------------------- |
| `printf()`                   | `int`               | عدد ≥ 0 (تعداد کاراکترهای چاپ‌شده) | مقدار منفی           | اگه خروجی بسته باشه یا حافظه کافی نباشه، منفی برمی‌گردونه |
| `scanf()`                    | `int`               | تعداد مقادیر درست خوانده‌شده       | 0 یا EOF             | مثلاً اگه ورودی اشتباه باشه یا فایل تموم بشه              |
| `fopen()`                    | `FILE *`            | مقدار ≠ `NULL`                     | `NULL`               | فایل با موفقیت باز شده یا نه                              |
| `fclose()`                   | `int`               | 0                                  | EOF (معمولاً -1)     | اگر بستن فایل با خطا مواجه بشه                            |
| `fread()` / `fwrite()`       | `size_t`            | مقدار > 0                          | مقدار کمتر از انتظار | یعنی کمتر از تعداد داده مورد نظر خونده یا نوشته           |
| `malloc()`                   | اشاره‌گر (`void *`) | ≠ `NULL`                           | `NULL`               | حافظه با موفقیت رزرو شده یا نه                            |
| `free()`                     | `void`              | —                                  | —                    | برنمی‌گردونه، ولی استفاده ازش روی `NULL` مشکلی نداره      |
| `system()`                   | `int`               | 0 (یا طبق دستور)                   | غیر صفر              | اگه اجرای دستور سیستم خطا بده                             |
| `remove()`                   | `int`               | 0                                  | غیر صفر              | حذف فایل با موفقیت انجام شده یا نه                        |
| `rename()`                   | `int`               | 0                                  | غیر صفر              | تغییر نام فایل موفق بوده یا نه                            |
| `getchar()`                  | `int`               | عدد ≥ 0 (کاراکتر معتبر)            | EOF                  | اگر ورودی تموم بشه                                        |
| `putchar()`                  | `int`               | عدد ≥ 0                            | EOF                  | اگه چاپ کاراکتر موفق نباشه                                |
| `ShellExecute()` *(Windows)* | `HINSTANCE`         | > 32                               | ≤ 32                 | اجرای دستور موفق یا خطا                                   |
| `execvp()` *(Linux)*         | `int`               | فقط در صورت خطا برمی‌گرده          | -1                   | چون اگر موفق بشه، برنامه جدید جایگزین میشه!               |
| `fork()` *(Linux)*           | `pid_t`             | ≥ 0                                | -1                   | اگر موفق باشه، شناسه‌ی فرزند (child) رو برمی‌گردونه       |
| `socket()`                   | `int`               | ≥ 0                                | -1                   | در صورت خطا، -1 برمی‌گردونه                               |
| `connect()`                  | `int`               | 0                                  | -1                   | در صورت عدم اتصال، خطا                                    |
| `send()` / `recv()`          | `int`               | ≥ 0                                | -1                   | در صورت خطا (مثلاً اتصال قطع)، -1 برمی‌گردونه             |

## 🧠 قاعده‌ی کلی ذهنی:
اگر خواستی خودت تشخیص بدی چطور باید بررسی کنی:

| نوع برگشتی تابع         | موفقیت                | خطا            |
| ----------------------- | --------------------- | -------------- |
| `int`                   | معمولاً `0`           | هر عدد غیر صفر |
| `pointer`               | هر چیزی غیر از `NULL` | `NULL`         |
| `size_t` یا `unsigned`  | عدد بزرگ‌تر از صفر    | عدد صفر        |
| `HINSTANCE` (در ویندوز) | > 32                  | ≤ 32           |

---

## 📘 مثال ترکیبی برای تمرین

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    FILE *fp = fopen("data.txt", "r");
    if (fp == NULL) {
        printf("❌ خطا در باز کردن فایل!\n");
        return 1;
    }

    char buffer[100];
    size_t readCount = fread(buffer, 1, sizeof(buffer), fp);
    if (readCount == 0) {
        printf("⚠️ هیچ داده‌ای خوانده نشد یا خطا رخ داد!\n");
    } else {
        printf("✅ %zu بایت خوانده شد.\n", readCount);
    }

    if (fclose(fp) == 0) {
        printf("📁 فایل با موفقیت بسته شد.\n");
    } else {
        printf("❌ خطا در بستن فایل!\n");
    }

    return 0;
}
```
