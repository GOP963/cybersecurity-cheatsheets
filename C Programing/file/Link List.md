### لیست پیوندی چیست؟

**Linked List (لیست پیوندی)** 
یک ساختار داده‌ست که برای **ذخیره‌ی مجموعه‌ای از داده‌ها** استفاده میشه، درست مثل آرایه،  
اما تفاوت بزرگش اینه که داده‌ها در حافظه **پشت سر هم ذخیره نمی‌شن**.

در عوض، هر داده در یک **جعبه (Node)** ذخیره میشه، و اون جعبه یه "اشاره‌گر" داره که آدرس جعبه‌ی بعدی رو نشون میده.

فرض کن می‌خوای چند تا عدد ذخیره کنی، مثل:

```
10, 20, 30
```

در **آرایه**، این اعداد پشت سر هم در حافظه ذخیره می‌شوند:

```
[10][20][30]
```

اما در **لیست پیوندی**، هر عدد داخل یک جعبه (Node) قرار می‌گیرد و هر جعبه به جعبه بعدی **یک نخ (Pointer)** وصل است:

```
[10|نخ] -> [20|نخ] -> [30|نخ] -> NULL
```

- قسمت اول هر جعبه: **داده (Data)**
    
- قسمت دوم هر جعبه: **نخ یا اشاره‌گر به جعبه بعدی (Next)**s
    
- آخرین جعبه همیشه **به NULL** اشاره می‌کند، یعنی لیست تمام شده است.
    

---

### چرا از لیست پیوندی استفاده می‌کنیم؟

1. می‌توانیم **هر وقت خواستیم عدد جدید اضافه کنیم**، بدون اینکه همه چیز را جابه‌جا کنیم.
    
2. اندازه لیست **دینامیک است**؛ یعنی لازم نیست تعداد عناصر را از قبل مشخص کنیم.
    

---

### یک مثال خیلی ساده ذهنی:

فرض کن کارت‌های بازی داری و می‌خوای آن‌ها را پشت سر هم بچینی.

- در آرایه: کارت‌ها را دقیقاً کنار هم روی میز می‌گذاری.
    
- در لیست پیوندی: هر کارت یک نخ به کارت بعدی دارد، می‌توانی کارت‌ها را جا‌به‌جا کنی یا یک کارت جدید بین دو کارت اضافه کنی بدون اینکه بقیه کارت‌ها را جابه‌جا کنی.

## 1️⃣ ساختار اصلی Linked List

همان‌طور که گفتیم، هر عنصر لیست پیوندی یک **Node** است. هر Node شامل:

1. **داده (Data):** مقداری که می‌خواهیم ذخیره کنیم.
    
2. **اشاره‌گر به Node بعدی (Next):** آدرس Node بعدی در حافظه.
    

در C، می‌توانیم Node را با یک `struct` تعریف کنیم:

```c
struct Node {
    int data;           // داده
    struct Node* next;  // اشاره‌گر به Node بعدی
};
```

> نکته: `struct Node* next` یعنی **next یک اشاره‌گر به همان نوع struct است**.

---

## 2️⃣ انواع Linked List

1. **Singly Linked List (یک‌طرفه)**
    
    - هر Node فقط به Node بعدی اشاره می‌کند.
        
    - مسیر رفتن فقط یک‌طرفه است.
        
    - شکل:
        
        ```
        head -> [10|next] -> [20|next] -> [30|next] -> NULL
        ```
        
2. **Doubly Linked List (دوطرفه)**
    
    - هر Node دو اشاره‌گر دارد:
        
        - `next` → Node بعدی
            
        - `prev` → Node قبلی
            
    - می‌توان به جلو و عقب حرکت کرد.
        
    - شکل:
        
        ```
        NULL <- [10|prev|next] <-> [20|prev|next] <-> [30|prev|next] -> NULL
        ```
        
3. **Circular Linked List (حلقوی)**
    
    - Node آخر دوباره به Node اول اشاره می‌کند.
        
    - شکل:
        
        ```
        [10] -> [20] -> [30] -> [10] (و دوباره ادامه دارد)
        ```

## 3️⃣ نحوه ایجاد Linked List در C

### مثال: ایجاد یک لیست ساده با سه Node

```c
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node* next;
};

int main() {
    struct Node *head, *second, *third;

    // تخصیص حافظه برای سه Node
    head = (struct Node*)malloc(sizeof(struct Node));
    second = (struct Node*)malloc(sizeof(struct Node));
    third = (struct Node*)malloc(sizeof(struct Node));

    // مقداردهی و اتصال Nodeها
    head->data = 10;
    head->next = second;
 
    second->data = 20;
    second->next = third;

    third->data = 30;
    third->next = NULL; // پایان لیست

    // چاپ لیست
    struct Node* ptr = head;
    while(ptr != NULL) {
        printf("%d -> ", ptr->data);
        ptr = ptr->next;
    }
    printf("NULL\n");

    // آزاد کردن حافظه
    free(head);
    free(second);
    free(third);

    return 0;
}
```

**خروجی:**

```
10 -> 20 -> 30 -> NULL
```

## 4️⃣ عملیات اصلی روی Linked List

1. **ایجاد Node** → با `malloc()`
    
2. **افزودن Node**
    
    - در ابتدای لیست (Push Front)
        
    - در انتهای لیست (Append)
        
    - بین دو Node (Insert Middle)
        
3. **حذف Node**
    
    - از ابتدا، انتها یا موقعیت مشخص
        
4. **جستجو (Search)**
    
5. **چاپ لیست (Traversal)**
    

> این عملیات‌ها با استفاده از اشاره‌گرها انجام می‌شوند و آرایه نیستند.

---

## 5️⃣ نکات مهم

- لیست پیوندی **دینامیک است** و محدودیت اندازه ندارد.
    
- **دسترسی به عناصر تصادفی کند است**، باید از اول لیست عبور کنیم.
    
- حافظه مصرفی بیشتر است (هر Node شامل یک اشاره‌گر اضافی است).
    
- استفاده از malloc/free اهمیت زیادی دارد؛ در غیر این صورت **Memory Leak** ایجاد می‌شود.
    

---

|بخش|توضیح|
|---|---|
|`data`|مقداری که می‌خوای ذخیره کنی (مثلاً عدد یا رشته)|
|`next`|اشاره‌گری که آدرس Node بعدی رو نگه می‌داره|
