**Microcontroller
(میکروکنترلر)** در واقع یک **کامپیوتر کوچک روی یک تراشه (SoC)** هست.

یعنی روی یه چیپ خیلی کوچیک، این بخش‌ها وجود دارن:

- **CPU (واحد پردازش مرکزی)** → مغز اصلی برای پردازش دستورها.
    
- **RAM (حافظه موقت)** → برای ذخیره داده‌ها هنگام اجرای برنامه.
    
- **Flash/ROM (حافظه دائمی)** → جایی که برنامه و داده‌ها ذخیره می‌شن.
    
- **I/O Ports (پورت‌های ورودی/خروجی)** → برای ارتباط با سنسورها، موتور، LED، صفحه‌کلید و غیره.
    
- **Timer / Counter** → برای اندازه‌گیری زمان یا تولید سیگنال.
    
- بعضی وقتا ماژول‌های اضافی مثل **ADC (مبدل آنالوگ به دیجیتال)** یا **PWM** هم دارن.
    

🔹 تفاوتش با **Microprocessor (میکروپروسسور)** اینه که میکروکنترلر همه‌چیز رو روی یک چیپ داره و برای کنترل مستقیم دستگاه‌ها (مثل لوازم خانگی، خودرو، رباتیک، دستگاه‌های IoT و کارت‌های هوشمند) استفاده می‌شه، در حالی که میکروپروسسور بیشتر توی کامپیوترها و موبایل‌ها هست و نیاز به قطعات جانبی مثل RAM و هارد داره.

مثال از میکروکنترلرها:

- **Arduino (ATmega328p)**
    
- **ESP8266 / ESP32** (برای IoT و وای‌فای)
    
- **STM32** (قدرت بالا در صنعت و رباتیک)

در زبان **C** (و خیلی زبان‌های سطح پایین دیگه)، وقتی می‌گی:

```c
signed int a = 12;
unsigned int b = 12;
```

🔹 تفاوت اصلی در **نحوه ذخیره و تفسیر بیت‌ها** هست.

---

### 1. `signed`

- یعنی **علامت‌دار** (می‌تونه هم مثبت باشه هم منفی).
    
- به طور پیش‌فرض، وقتی فقط بنویسی `int`، در اکثر کامپایلرها همون `signed int` در نظر گرفته میشه.
    
- مثال:
    
    ```c
    signed int x = -5;
    signed int y = 12;
    ```
    
- حافظه مثلاً برای `int` (۴ بایت) اینجوری تقسیم میشه:
    
    - ۱ بیت برای علامت (+ یا -)
        
    - ۳۱ بیت برای مقدار
        

بنابراین `signed int` محدوده‌اش هست:  
`-2,147,483,648` تا `2,147,483,647` (روی سیستم‌های ۳۲ بیتی)

---

### 2. `unsigned`

- یعنی **بدون علامت** (فقط مثبت).
    
- چون دیگه نیازی به ذخیره بیت علامت نداره، همه‌ی بیت‌ها صرف مقدار میشن.
    
- مثال:
    
    ```c
    unsigned int z = 12;   // اوکیه
    unsigned int w = -5;   // اینجا Warning یا خطا می‌گیری چون منفی مجاز نیست
    ```
    
- محدوده `unsigned int` روی ۴ بایت میشه:  
    `0` تا `4,294,967,295`
    

---

### 3. نکته مهم

مثلاً اینو نگاه کن:

```c
signed int a = -1;
unsigned int b = -1;
printf("%d\n", a); // خروجی: -1
printf("%u\n", b); // خروجی: 4294967295
```

چون `b` بدون علامته، اون بیت‌های -1 رو (که همه‌اش 1 هستن توی سیستم دو مکمل) به عنوان یه عدد خیلی بزرگ مثبت می‌خونه.

---

🔑 خلاصه:

- `signed` → می‌تونه منفی و مثبت باشه.
    
- `unsigned` → فقط مثبت، اما بازه‌ی بیشتری از اعداد مثبت رو پوشش میده.
    

---

## 🎯 دلیل وجود `signed` و `unsigned`

1. **انعطاف در نمایش داده‌ها**
    
    - بعضی وقت‌ها ما نیاز داریم هم اعداد منفی و هم مثبت رو نگه داریم → پس `signed`.
        
    - بعضی وقت‌ها فقط اعداد مثبت معنی دارن (مثل شمارش تعداد فایل، سایز حافظه، طول آرایه، سن، آی‌دی‌ها و …) → پس `unsigned`، چون بازه بزرگ‌تری از اعداد مثبت رو می‌گیره.
        

---

2. **بهینه‌سازی مصرف حافظه**
    
    - اگه بدونیم مقدار منفی هیچ‌وقت نیاز نیست، چرا نصف بازه رو هدر بدیم برای اعداد منفی؟
        
    - با `unsigned` کل ظرفیت رو می‌دیم به مثبت‌ها.
        

مثلاً:

- `signed char` → از -128 تا 127
    
- `unsigned char` → از 0 تا 255  
    هر دو فقط ۱ بایت می‌گیرن، اما بازه‌شون فرق می‌کنه.


✅ خلاصه:

- وقتی هم منفی و هم مثبت مهمه → `signed`.
    
- وقتی فقط مثبت مهمه (و نیاز به بازه بزرگ‌تر مثبت داری) → `unsigned`.
    
- هدفشون اینه که بتونی حافظه و منطق برنامه رو بهینه‌تر با نیازت هماهنگ



---

| عملگر | معنی             | مثال     | نتیجه    |
| ----- | ---------------- | -------- | -------- |
| `==`  | برابر است با     | `5 == 5` | true (1) |
| `!=`  | برابر نیست با    | `5 != 3` | true (1) |
| `>`   | بزرگ‌تر است      | `7 > 3`  | true (1) |
| `<`   | کوچک‌تر است      | `2 < 5`  | true (1) |
| `>=`  | بزرگ‌تر یا مساوی | `5 >= 5` | true (1) |
| `<=`  | کوچک‌تر یا مساوی | `3 <= 4` | true (1) |
