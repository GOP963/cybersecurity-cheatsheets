

 در زبان C وقتی که میخواهیم از printf استفاده کنیم باید یک ماکرو به اسم stdio.h رو به نوعی include کنیم 

اما نکته یی که هست اینه که printf یک تابع نیست در زبان C بلکه یک Variadic است 

یعنی چی Variadic  می‌تونه تعداد متغیر آرگومان بگیره

یعنی : 

```
printf("My age is %d and my name is %s", 24, "Martin");
```

 یعنی ما میتونیم بهش هم یک متنی رو بدیم که برای ما داخل console چاپ کنه و هم میتونیم متغیر مون با هر فرمتی که میخواهیم چاپ کنیم البته نکته یی که هست اینه که ما اگر متغیرمون یک int باشه باید یا از %d استفاده کنیم یا متیونیم از موارد دیگری کع وجود دارد مثله %ld یا %lld یا %zl و موارد این چنینی فرمت که میخواهیم چاپ کنیم بسته به متغیرمون داره که چی هستشش اما میتونیم در بعضی مواقع از %p استفاده کنیم که این به این معنی است که ادرس حافظه اون متغیر رو بیاد برای ما بگیره 


```
printf("Result: %5d ****\n",1000);
printf("Result: %5d ****\n",100);
```
اینکار باعث میشود که 5 تا بین هر خروجی ستاره بزاریم بعد بریم خط بعدی که دیزاین بهتری داشته باشه
