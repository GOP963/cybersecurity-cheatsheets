### `%d` در `scanf` و `printf`

- توی C، وقتی از `scanf` یا `printf` استفاده می‌کنی، همیشه یه **format string** می‌دی (یعنی یه رشته که میگه "ورودی/خروجی چه شکلی باشه").
    
- توی این رشته علامت‌های خاصی هستن مثل `%d`, `%f`, `%c`, `%s` و … که هر کدوم مربوط به یه **نوع داده (datatype)** خاص هستن.

### مثال با `printf`:

```c
int x = 42;
printf("x = %d\n", x);
```

```
x = 42
```

اینجا `%d` می‌گه "یک عدد int رو چاپ کن".

```c
int y;
scanf("%d", &y);
```

وقتی کاربر مثلاً بزنه:

```
123
```

این عدد به عنوان `int` خونده میشه و داخل `y` ذخیره میشه.  
اینجا `%d` میگه "منتظر یک عدد صحیح باش".

### چند تا از پرکاربردترین فرمت‌ها:

- `%d` → عدد صحیح (`int`)
    
- `%u` → عدد صحیح بدون علامت (`unsigned int`)
    
- `%f` → عدد اعشاری (`float`)
    
- `%lf` → عدد اعشاری دقیق‌تر (`double`)
    
- `%c` → یک کاراکتر (`char`)
    
- `%s` → رشته (`char *`)

- توی `scanf`: "اینجا یک عدد صحیح از ورودی بگیر."
    
- توی `printf`: "اینجا یک عدد صحیح چاپ کن."

### Race Condition چیست؟

**Race Condition** وقتی اتفاق می‌افتد که **دو یا چند برنامه یا thread هم‌زمان به یک منبع مشترک (مثلاً یک متغیر یا حافظه) دسترسی داشته باشند و نتیجه اجرای برنامه به ترتیب اجرای آنها بستگی داشته باشد.**

به عبارت دیگر، وقتی ترتیب دسترسی و نوشتن مهم است و کنترل نشده، رفتار غیرقابل پیش‌بینی ایجاد می‌شود.

مثال کلاسیک:  
دو thread می‌خواهند روی یک متغیر `counter` بنویسند و افزایش بدهند:

```c
counter = counter + 1;
```

اگر دو thread هم‌زمان این دستور را اجرا کنند، ممکن است یکی از افزایش‌ها “گم شود” و `counter` به مقدار صحیح نرسد.

### نمونه کد ساده در C (دو thread روی یک متغیر مشترک می‌نویسند)

```c
#include <stdio.h>
#include <pthread.h>

int shared_data = 0;  // حافظه مشترک

void* thread_func(void* arg) {
    for(int i = 0; i < 100000; i++) {
        shared_data++;  // نوشتن روی حافظه مشترک
    }
    return NULL;
}

int main() {
    pthread_t t1, t2;

    pthread_create(&t1, NULL, thread_func, NULL);
    pthread_create(&t2, NULL, thread_func, NULL);

    pthread_join(t1, NULL);
    pthread_join(t2, NULL);

    printf("Final shared_data = %d\n", shared_data);
    return 0;
}
```

> انتظار داری `shared_data` برابر 200000 باشد، ولی به دلیل **Race Condition** مقدار واقعی کمتر از این خواهد بود، چون دو thread هم‌زمان `shared_data++` را اجرا می‌کنند.

---

### نمونه ساده با فرآیندها (Processes) در Python

```python
from multiprocessing import Process, Value

def increment(shared_data):
    for _ in range(100000):
        shared_data.value += 1  # نوشتن روی حافظه مشترک

if __name__ == "__main__":
    shared_data = Value('i', 0)  # حافظه مشترک بین فرآیندها

    p1 = Process(target=increment, args=(shared_data,))
    p2 = Process(target=increment, args=(shared_data,))

    p1.start()
    p2.start()

    p1.join()
    p2.join()

    print("Final shared_data =", shared_data.value)
```

همینجا هم ممکنه مقدار `shared_data.value` از 200000 کمتر باشه، چون Race Condition رخ می‌دهد.

### Thread چیست؟

**Thread** (یا نخ) **کوچک‌ترین واحد اجرایی داخل یک برنامه است**.  
می‌توانی برنامه را مثل یک **کارخانه** در نظر بگیری:

- **Process (فرآیند)** → کل کارخانه است، با همه تجهیزات و منابعش.
    
- **Thread (نخ)** → کارگری است که یک وظیفه مشخص را داخل کارخانه انجام می‌دهد.
    

> یک Process می‌تواند **چند Thread داشته باشد** که هم‌زمان کار می‌کنند و منابع مشترک Process (مثل حافظه) را استفاده می‌کنند.

---

#### ویژگی‌های مهم Thread

1. **حافظه مشترک:**  
    همه Threadهای یک Process می‌توانند به همان متغیرها و داده‌های Process دسترسی داشته باشند.
    
    - این باعث می‌شود سرعت کار بالا برود ولی احتمال **Race Condition** هم زیاد می‌شود.
        
2. **اجرای هم‌زمان:**  
    Threadها می‌توانند به طور هم‌زمان (concurrently) یا حتی واقعی (parallel) اجرا شوند، اگر CPU هسته‌های متعدد داشته باشد.
    
3. **سبک‌تر از Process:**  
    ایجاد Thread خیلی سریع‌تر و کم‌هزینه‌تر از ایجاد یک Process جدید است.
    

---

#### مثال تصویری ساده:

```
Process:    +----------------------------+
            |        Shared Memory       |
            |   var1, var2, var3...     |
Thread 1 -> | Task A using var1          |
Thread 2 -> | Task B using var2          |
Thread 3 -> | Task C using var1 & var3  |
            +----------------------------+
```

همه Threadها داخل یک Process می‌توانند روی حافظه مشترک کار کنند، ولی هر Process حافظه خودش را دارد.
