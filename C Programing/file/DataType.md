# مودایفایرها/صفات نوع در C

## ۱) **تغییردهنده‌های اندازه / علامت برای عددی‌ها**  
این‌ها روی نوع‌های عددی (معمولاً `int` و گاهی `char`) اعمال می‌شن:

- `signed`  
  - یعنی مقدار می‌تونه منفی باشه. (پیش‌فرض برای `int` است)
  - مثال: `signed int x;`

- `unsigned`  
  - فقط اعداد غیرمنفی (بیتِ بالا به عنوان قسمت مقدار، نه علامت)
  - مثال: `unsigned int u;`

- `short`  
  - عرض/اندازهٔ کمتر از `int` (معمولاً 16 بیت در بسیاری از پلتفرم‌ها)
  - مثال: `short s;` یا `short int s;`

- `long`  
  - عرض بیشتر (معمولاً 32 یا 64 بیت بسته به پلتفرم)
  - مثال: `long l;` یا `long int l;`

- `long long`  
  - برای عرض خیلی بزرگ‌تر (حداقل 64 بیت در استاندارد)
  - مثال: `long long ll;`

> ترکیب‌ها رایج‌اند: `unsigned long`, `short int`, `long long unsigned` (ترتیب کلمات اهمیتی نداره).

## ۲) **qualifiers — صفات نوع (رفتاری)**  
این صفات رفتار و قواعد استفاده از نوع رو تغییر میدن:

- `const`  
  - مقدار قابل تغییر نیست (ثابت)؛ کامپایلر تلاش می‌کنه جلوی تغییرش بگیره.  
  - مثال: `const int ci = 5;`

- `volatile`  
  - به کامپایلر می‌گه مقدار ممکنه از بیرون تغییر کنه (مثلاً سخت‌افزار یا چندنخی)، بنابراین بهینه‌سازی‌های مربوطه رو انجام نده.  
  - مثال: `volatile int v;`

- `restrict` (C99)  
  - مخصوص اشاره‌گرها؛ اعلام می‌کنه که اون اشاره‌گر تنها راه دسترسی به آن داده در طول بلوک است (برای بهینه‌سازی).  
  - مثال: `int * restrict p;`

- (در C++) `mutable` — مربوط به اعضای کلاس؛ در C معمول نیست.

## ۳) **storage-class specifiers — مشخص‌کنندهٔ کلاسِ ذخیره‌سازی**  
این‌ها مشخص می‌کنن متغیر کجا و چه مدت ذخیره می‌شه تا کی زندگی  میکنه و چه مقدار اولیه میگیره 

- `auto`  
  - پیش‌فرض برای متغیرهای محلی (در C99 عملاً غیرضروری شد).  
  - مثال: `auto int x;` (نادرتا استفاده می‌شه)

- `register`  
  - پیشنهاد به کامپایلر برای نگهداری در رجیستر (امروزه معمولاً بی‌اثر است).  
  - مثال: `register int r;`

- `static`  
  - برای متغیرهای محلی: مقدار بین فراخوانی‌ها حفظ می‌شه (ذخیره‌سازی static).  
  - برای توابع/متغیر‌های فایل: محدودهٔ دید (linkage) را محدود می‌کنه (internal linkage).  
  - مثال: `static int counter = 0;`

- `extern`  
  - اعلام می‌کنه تعریف متغیر/تابع در جای دیگر هست؛ برای اشتراک بین فایل‌ها.  
  - مثال: `extern int errno;`

- `typedef`  
  - نوع جدید تعریف می‌کنه (از نظر نگهداری/ذخیره‌سازی نیست ولی تو گروه کلاس‌ها قرار می‌گیره وقتی می‌گیم «مودایفایرها/specifier»).

## ۴) **مودایفایرها/انواع شناخته‌شده برای اعشارها**  
- `float` (معمول)  
- `double`  
- `long double` (دقت/عرض بالاتر)

> برای این‌ها معمولاً `short/long` به شکل `long double` وجود داره؛ `unsigned float` معنی ندارد.

## ۵) **مودایفایرهای مربوط به اشاره‌گر / آرایه / فانکشن**  
این‌ها صِرفاً مودایفایر نیستند اما در ترکیب با qualifiers/const مهم‌اند:
- `const char *p` (اشاره‌گری به دادهٔ ثابت)  
- `char * const p` (خود اشاره‌گر ثابت است)  
- `const char * const p` (هر دو ثابت‌اند)

نکته: جای `const` (قبل یا بعد از `*`) معنی را تغییر می‌دهد — در جزوه‌ات حتما این را با مثال نشان بده.

## ۶) **سایر موارد مفید/استانداردهای جدیدتر**
- `_Alignas`، `_Alignof` (C11) — برای ترازبندی (alignment)  
- `_Atomic` (C11) — برای عملیات اتمیک  
- `__attribute__` (گنو/کامپایلر خاص) — برای افزودن خصایص مخصوص کامپایلر (در جزوه فقط ذکر کن، جزئیات در صورت نیاز جدا)

---

# جدول خلاصهٔ سریع (کاربرد اصلی)
- **signed / unsigned / short / long / long long** → برای **اعداد صحیح**  
- **long double** → برای **اعداد اعشاری با دقت بالا**  
- **const / volatile / restrict** → **صفات/qualifiers** (رفتار دسترسی/بهینه‌سازی)  
- **static / extern / auto / register / typedef** → **storage-class specifiers** (مدت/محدودهٔ دید)  
- **_Atomic / _Alignas** → امکانات C11 (همگام‌سازی، ترازبندی)

# چند مثال کاربردی که تو جزوه بزن
```c
// اندازه و علامت
unsigned long ul = 0;
short s = -5;
long long big = 1234567890123LL;

// qualifiers
const int MAX = 100;
volatile int *p = hardware_reg_address; // مثال سخت‌افزاری

// storage class
static int counter = 0;   // مقدار بین فراخوانی‌ها حفظ می‌شود
extern int global_var;    // تعریف در فایل دیگر

// pointer combos
const char *name = "ali";      // داده ثابت، اشاره‌گر متحرک
char * const ptr = buffer;     // اشاره‌گر ثابت، داده قابل تغییر
```

## 📌 Declaration (اعلان)

یعنی:  
به کامپایلر **می‌گی چیزی وجود داره** (نوع و اسمش چیه) ولی هنوز حافظه/فضای واقعی براش نمی‌سازی.

- فقط معرفی می‌کنی که این متغیر یا تابع در یه جایی (فایل دیگه یا پایین‌تر) تعریف شده.
    
- هیچ حافظه‌ای رزرو نمی‌شه (مگر برای برخی موارد خاص).
    

### مثال:

```c
extern int a;   // اعلان متغیر a (می‌گیم یه int به اسم a یه جایی هست)
int func(int x); // اعلان تابع func (فقط می‌گیم همچین تابعی وجود داره)
```

---

## 📌 Definition (تعریف)

یعنی:  
هم معرفی می‌کنی و هم **واقعاً حافظه براش رزرو می‌کنی** یا بدنهٔ واقعی تابع رو می‌نویسی.

### مثال:

```c
int a = 10;     // تعریف متغیر a (حافظه رزرو شد و مقداردهی شد)
int func(int x) // تعریف تابع func (بدنه هم نوشته شد)
{
    return x * x;
}
```

---

## 📌 فرق اصلی Declaration vs Definition

|ویژگی|Declaration (اعلان)|Definition (تعریف)|
|---|---|---|
|هدف|اطلاع دادن به کامپایلر که چیزی وجود داره|واقعاً ایجاد کردن اون چیز|
|حافظه|حافظه رزرو نمی‌کنه (معمولاً)|حافظه رزرو می‌کنه|
|محل استفاده|وقتی می‌خوای بین فایل‌ها به متغیر/تابع دسترسی داشته باشی|وقتی می‌خوای واقعاً متغیر/تابع رو بسازی|
|کلیدواژه رایج|`extern`|بدون `extern`، یا با مقداردهی/بدنه|

---

## 📌 مثال ترکیبی (چند فایل)

### file1.c

```c
int count = 0;    // تعریف متغیر (حافظه ساخته میشه)
```

### file2.c

```c
extern int count; // اعلان متغیر (حافظه اینجا ساخته نمی‌شه)
void main() {
    count = 5;    // استفاده از همون متغیر
}
```

## 📌 نکته مهم

- هر **متغیر** یا **تابع** باید دقیقاً یک **Definition** داشته باشه.
    
- ولی می‌تونی چندین بار **Declaration** انجام بدی (تا وقتی ناسازگار نباشن).
    

---

👉 خلاصه‌ی خیلی ساده:

- **Declaration** = معرفی (می‌گم یه چیزی هست).
    
- **Definition** = ساختن واقعی (حافظه/بدنه می‌سازم).

## 🔹 دسته اول: داده‌های پایه (Primitive & Composite types)

1. **char**
    
    - برای ذخیره کاراکترها (`'a'`, `'b'`, `'1'`, `'#'`)
        
    - معمولاً **۱ بایت** (۸ بیت) حافظه می‌گیره.
        
    - می‌تونه به صورت signed یا unsigned باشه.
        
2. **int**
    
    - برای اعداد صحیح (مثلاً `-10`, `0`, `200`)
        
    - اندازه‌اش به معماری سیستم بستگی داره (معمولاً ۴ بایت = ۳۲ بیت).
        
3. **float**
    
    - برای اعداد اعشاری (ممیز شناور) با دقت معمولی.
        
    - معمولاً **۴ بایت** (۳۲ بیت).
        
4. **double**
    
    - برای اعداد اعشاری با دقت دو برابر float.
        
    - معمولاً **۸ بایت** (۶۴ بیت).
        
5. **pointer**
    
    - متغیری که به آدرس حافظه‌ی یک متغیر دیگه اشاره می‌کنه.
        
    - اندازه‌اش بستگی به معماری داره (روی سیستم ۳۲ بیتی = ۴ بایت، روی ۶۴ بیتی = ۸ بایت).
        
6. **void**
    
    - نوعی که هیچ مقداری نداره.
        
    - به کار می‌ره برای توابعی که چیزی برنمی‌گردونن یا برای تعریف pointer بدون نوع (`void *`).
        
7. **struct**
    
    - ساختار داده‌ای که می‌تونه چند متغیر با انواع مختلف رو کنار هم نگه داره.
        
    - مثل کلاس ساده در C.
        
    
    ```c
    struct Person {
        char name[20];
        int age;
    };
    ```
    
8. **union**
    
    - مثل struct هست ولی همه اعضا از **یک محل حافظه مشترک** استفاده می‌کنن.
        
    - کاربرد: صرفه‌جویی در حافظه یا نمایش چند نوع داده مختلف در یک فضا.
        
9. **enum**
    
    - نوع داده‌ای که یک مجموعه مقادیر ثابت (ثابت‌های عددی نام‌گذاری شده) رو تعریف می‌کنه.
        
    
    ```c
    enum Days { MON, TUE, WED, THU, FRI, SAT, SUN };
    ```
    
10. **array**
    
    - آرایه، مجموعه‌ای از عناصر هم‌نوع که پشت سر هم در حافظه ذخیره می‌شن.
        
    
    ```c
    int numbers[5] = {1,2,3,4,5};
    ```

## 🔹 دسته دوم: داده‌های استاندارد (Fixed-width types - از `<stdint.h>`)

این‌ها در C99 معرفی شدن و اندازه مشخصی دارن (دیگه وابسته به سیستم نیستن):

1. **int8_t**
    
    - عدد صحیح علامت‌دار با اندازه **۸ بیت** (از -128 تا 127).
        
2. **uint8_t**
    
    - عدد صحیح بدون علامت با اندازه **۸ بیت** (از 0 تا 255).
        
3. **int64_t**
    
    - عدد صحیح علامت‌دار با اندازه **۶۴ بیت** (از -2^63 تا 2^63 - 1).
