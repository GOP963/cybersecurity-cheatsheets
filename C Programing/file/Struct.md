## 🔹 تعریف Struct در زبان C

`struct` 
(مخفف structure) یعنی **ساختار داده‌ای ترکیبی** که می‌تونه چند متغیر از **نوع‌های مختلف** رو در یک واحد واحد کنار هم نگه داره.  
برخلاف **Array** که فقط از یک نوع داده استفاده می‌کنه، ساختارها می‌تونن داده‌هایی از چند نوع مختلف رو با هم ترکیب کنن.

---

## 🧩 هدف از استفاده از struct

وقتی بخوای چند متغیر مرتبط رو که به یک مفهوم تعلق دارن در کنار هم نگه داری، از ساختار استفاده می‌کنی.

مثلاً فرض کن می‌خوای اطلاعات یک کاربر رو ذخیره کنی:

- شماره (int)
    
- نام (char)
    
- سن (int)
    
- جنسیت (char)
    

می‌تونی به‌جای تعریف چند متغیر جدا، از یک `struct` استفاده کنی که همه رو با هم نگه داره.

---

## 🔹 نحوه‌ی تعریف ساختار

```c
struct Info {
    int v1;
    char c1;
    unsigned long long int v2;
};
```

توضیح:

- `struct` : کلمه‌ی کلیدی برای تعریف ساختار
    
- `Info` : نام ساختار
    
- `{ ... }` : اعضای داخل ساختار
    
- هر عضو (field) می‌تونه از نوع متفاوت باشه
    

این ساختار شامل سه فیلد است:

1. `v1` از نوع `int`
    
2. `c1` از نوع `char`
    
3. `v2` از نوع `unsigned long long int`
    

---

## 🔹 ایجاد متغیر از نوع ساختار

بعد از تعریف، می‌تونی از اون ساختار **متغیر بسازی**:

```c
struct Info mydata;
```

🔸 یعنی: "یک متغیر به نام `mydata` بساز که از نوع `struct Info` است."

---

## 🔹 مقداردهی اعضای ساختار

برای دسترسی به فیلدهای داخل ساختار، از **نقطه (.)** استفاده می‌کنیم:

```c
mydata.v1 = 10;
mydata.c1 = 'A';
mydata.v2 = 1000;
```

🔸 به این ترتیب، به هر عضو مقدار می‌دیم.  
🔸 علامت `.` یعنی "به عضو داخلی این ساختار دسترسی پیدا کن".

---

## 🔹 مقداردهی اولیه هنگام تعریف

می‌تونی همون موقعی که ساختار رو تعریف می‌کنی، بهش مقدار هم بدی:

```c
struct Info data2 = {10, 'A', 1000};
```

🔸 ترتیب مقادیر باید دقیقاً مطابق ترتیب تعریف اعضا در `struct` باشه:

```
v1 = 10
c1 = 'A'
v2 = 1000
```

---

## 🔹 استفاده در داخل تابع main

کد کامل‌تر و صحیح:

```c
#include <stdio.h>

int main() {
    struct Info {
        int v1;
        char c1;
        unsigned long long int v2;
    };

    struct Info mydata;
    mydata.v1 = 10;
    mydata.c1 = 'A';
    mydata.v2 = 1000;

    printf("v1 = %d, c1 = %c, v2 = %llu\n", mydatia.v1, mydata.c1, mydata.v2);

    struct Info data2 = {10, 'A', 1000};
    printf("data2 -> v1=%d, c1=%c, v2=%llu\n", data2.v1, data2.c1, data2.v2);

    return 0;
}
```

📤 خروجی:

```
v1 = 10, c1 = A, v2 = 1000
data2 -> v1=10, c1=A, v2=1000
```

## 🔹 جدول خلاصه برای جزوه‌ات

|مفهوم|توضیح|مثال|
|---|---|---|
|تعریف ساختار|ایجاد نوع داده‌ای جدید شامل چند فیلد|`struct Info { int v1; char c1; };`|
|تعریف متغیر از ساختار|ساخت متغیر از نوع ساختار|`struct Info mydata;`|
|مقداردهی به اعضا|استفاده از نقطه `.`|`mydata.v1 = 10;`|
|مقداردهی هم‌زمان|در لحظه تعریف|`struct Info data2 = {10, 'A', 1000};`|
|دسترسی به اعضا|با عملگر `.`|`printf("%d", mydata.v1);`|
