
## **Core Dump**

در سیستم عامل لینوکس وقتی که داریم برنامه یی مینویسم یا برنامه یی رو اجرا میکنیم اگر موقعی که داریم برنامه مینویسیم و کامپایلش میکنیم برنامه با segmentation fail رو به رو شود و ERROR ماننده Core Dump بی افتد به این معنی  اگر این برنامه بنا به دلایلی ماننده ایراد از کد و ..... توسط سیستم عامل kill بشه سیستم عامل لینوکس میاد و یک dump کلی از برنامه که داخل Segment های مختلف بوده یه dump میگیره و دخیره میکنه 
و به طور کلی کرنل لینوکس این قابلیت رو داره تا برنامه هایی که ایراد دارن و اجر نمیشن یک dump ازشون گرفته بشه و برای اون برنامه نویس ارسال بشه 



دستوری که میتونیم بزنیم و core dump های سیستم رو ببینم دستور 
```
ulimit -a
```

این  دستور محدودیت های که user فعلی دارد رو به ما نشان میدهد 

حالا یه کدوم از این ulimit ها سوییچ -c است که به معنی core dump هست حالا اگر core dump برابر با 0 باشد به این معنی است که core dump خاموش است

میتونیم با همین سوییچ مقدار core dump رو تغییر بدیم 

```
core dump -c 5000
```

یعنی داریم میگیم که core dump های کمتر از 5 کیلو بایت رو برای من بگیر 


---

فایل تنظیمات کرنل لینوکس 

```
nvim /etc/sysctl.conf
```
