### 🔹 ۱. حلقه `while` معمولی  
این حلقه شرط رو **قبل** از اجرا بررسی می‌کنه.  

```c
#include <stdio.h>

int main() {
    int i = 0;

    while (i < 5) {   // تا وقتی i کوچکتر از 5 باشه اجرا میشه
        printf("i = %d\n", i);
        i++;   // هر بار 1 واحد به i اضافه میشه
    }

    return 0;
}
```

📌 خروجی:
```
i = 0
i = 1
i = 2
i = 3
i = 4
```

---

### 🔹 ۲. حلقه بی‌نهایت با `while(1)`  

```c
#include <stdio.h>

int main() {
    while (1) {  // همیشه درست است → بی‌نهایت
        printf("این یک حلقه بی نهایت است!\n");
        break;  // اگر بخوایم بشکنیم، باید از break استفاده کنیم
    }
    return 0;
}
```

📌 اگر `break` رو نذاری، برنامه تا ابد اجرا میشه.

---

### 🔹 ۳. حلقه `do while`  
اینجا **اول بدنه اجرا میشه، بعد شرط بررسی میشه**.  
یعنی حتی اگر شرط **از اول نادرست باشه**، بدنه حداقل **یک بار** اجرا میشه.  

```c
#include <stdio.h>

int main() {
    int i = 10;

    do {
        printf("i = %d\n", i);
        i++;
    } while (i < 5);   // شرط غلطه ولی حلقه یک بار اجرا شد

    return 0;
}
```

📌 خروجی:
```
i = 10
```

---

👉 خلاصه:
- `while` → شرط قبل از اجرا بررسی میشه.  
- `while(1)` → حلقه بی‌نهایت.  
- `do while` → شرط بعد از اجرا بررسی میشه (حداقل یک بار اجرا میشه).

## 🔹 دستور `switch-case-default`

ساختارش اینطوریه:

```c
switch(متغیر یا عبارت) {
    case مقدار1:
        // کدهایی که وقتی مقدار برابر مقدار1 بود اجرا میشه
        break;

    case مقدار2:
        // کدهایی که وقتی مقدار برابر مقدار2 بود اجرا میشه
        break;

    ...
    default:
        // وقتی هیچکدوم از case ها درست نبود اجرا میشه
}
```

---

### 📌 نکات مهم:

1. مقدار داخل `switch` باید از نوع **عدد صحیح (int, char, short, long)** یا چیزی قابل تبدیل به int باشه.
    
2. هر `case` یک مقدار ثابت می‌گیره.
    
3. بعد از اجرای یک case، اگر `break` نذاری، برنامه ادامه case های بعدی رو هم اجرا می‌کنه (بهش میگن _fall-through_).
    
4. بخش `default` اختیاریه و وقتی اجرا میشه که هیچ `case`ی درست نباشه.
    

---

### 🔹 مثال ساده: منو انتخابی
	
```c
#include <stdio.h>

int main() {
    int choice;

    printf("یک عدد وارد کن (1 تا 3): ");
    scanf("%d", &choice);

    switch(choice) {
        case 1:
            printf("شما عدد 1 رو انتخاب کردید.\n");
            break;

        case 2:
            printf("شما عدد 2 رو انتخاب کردید.\n");
            break;

        case 3:
            printf("شما عدد 3 رو انتخاب کردید.\n");
            break;

        default:
            printf("عدد وارد شده معتبر نیست!\n");
    }

    return 0;
}
```

---

### 🔹 مثال با `char`

```c
#include <stdio.h>

int main() {
    char grade = 'B';

    switch(grade) {
        case 'A':
            printf("عالی!\n");
            break;

        case 'B':
            printf("خوب.\n");
            break;

        case 'C':
            printf("قابل قبول.\n");
            break;

        default:
            printf("نمره نامعتبر.\n");
    }

    return 0;
}
```

---

### 🔹 مثال بدون `break` (fall-through)

```c
#include <stdio.h>

int main() {
    int x = 2;

    switch(x) {
        case 1:
            printf("Case 1\n");

        case 2:
            printf("Case 2\n");

        case 3:
            printf("Case 3\n");

        default:
            printf("Default case\n");
    }

    return 0;
}
```

📌 خروجی:

```
Case 2
Case 3
Default case
```

چون توی `case 2` **break** نگذاشتیم، ادامه case های بعدی هم اجرا شدن.

## 🔹 ۱. پیش‌افزایشی `++a`

یعنی:  
اول مقدار **یک واحد زیاد میشه** → بعد توی عبارت استفاده میشه.

```c
int a = 2;
int b = ++a;   // اول a میشه 3، بعد b هم میشه 3
```

📌 نتیجه:

- `a = 3`
    
- `b = 3`
    

---

## 🔹 ۲. پس‌افزایشی `a++`

یعنی:  
اول مقدار فعلی استفاده میشه → بعد یک واحد زیاد میشه.

```c
int a = 2;
int b = a++;   // اول b مقدار 2 میگیره، بعد a میشه 3
```

📌 نتیجه:

- `a = 3`
    
- `b = 2`
    

---

## 🔹 حالا این رو بررسی کنیم:

```c
int a = 2;
int b = ++a;   // b=3, a=3

int c = b = a++; // اینجاشو درست تایپ نکردی ولی احتمالا منظورت همچین چیزی بود
```

اینجا چه میشه؟

1. `a++` → اول مقدار `a` (که 3 هست) داده میشه به `b`.  
    بعد `a` یک واحد زیاد میشه → `a=4`.
    
2. پس: `b=3 , a=4`.
    

---

## 🔹 و اما `int b = +++a;` 😅

اینجا خیلی‌ها گیج میشن.  
این چیزی عجیب نیست، فقط **ترکیب دو عملگر** هست:

- `++a` (پیش‌افزایشی)
    
- و یک عملگر مثبت `+` (unary plus)
    

کامپایلر این رو اینطوری می‌بینه:

```c
int b = + (++a);
```

یعنی اول `a` یک واحد زیاد میشه، بعد یه `+` بی‌اثر جلوی اون قرار میگیره.

مثال:

```c
int a = 2;
int b = +++a;   // درواقع b = +(++a)
```

📌 نتیجه:

- `a = 3`
    
- `b = 3`
    

---

### ✅ خلاصه:

- `++a` → اول زیاد میشه، بعد استفاده.
    
- `a++` → اول استفاده میشه، بعد زیاد میشه.
    
داستان اینجاس که اگر ++ بعد از متغیر بیاد اول مقدار متغیر برمیگرده به عنوان جواب بعد یه دونه به متغیر اضافه میشه اما اگر ++ قبل از متغیر بیاد اول یه دونه به متغیر اضافه میشه بعد مقدارش برمیگرده میره تو تو b

تفاوت بین **`switch-case`** و **دستورهای شرطی مثل `if-else`** یکی از نکات مهم در زبان‌های C، C++ و حتی زبان‌های دیگه‌ست.  
بریم مرحله‌به‌مرحله و خیلی دقیق بررسیش کنیم 👇


### 🧩 ۱. مفهوم کلی:

- **`if-else`** برای بررسی **شرط‌های منطقی (Boolean expressions)** استفاده میشه.  
    یعنی هر چیزی که در نهایت **درست (true)** یا **غلط (false)** بشه.
    
- **`switch-case`** فقط برای **مقایسه مقدار یک متغیر ثابت** با چند **مقدار مشخص (case)** استفاده میشه.
    

---

### 🔹 ۲. شکل کلی هرکدوم:

#### ✅ if – else:

```c
if (x > 10)
    printf("بزرگتر از ۱۰\n");
else if (x == 10)
    printf("مساوی با ۱۰\n");
else
    printf("کوچکتر از ۱۰\n");
```

در اینجا شرط‌ها می‌تونن شامل **عملگرهای مقایسه‌ای، منطقی و ترکیبی** باشن.

---

#### ✅ switch – case:

```c
switch (x) {
    case 1:
        printf("x برابر 1 است\n");
        break;
    case 2:
        printf("x برابر 2 است\n");
        break;
    default:
        printf("هیچکدام نیست\n");
}
```

در اینجا فقط بررسی میشه که **مقدار `x` برابر با کدوم case هست**.

---

### ⚙️ ۳. تفاوت‌های اصلی:

|ویژگی|if-else|switch-case|
|---|---|---|
|نوع شرط|می‌تونه هر عبارت منطقی باشه|فقط مقدار متغیر (مثل عدد یا کاراکتر)|
|نوع داده مجاز|عدد، اعشاری، منطقی، ترکیبی|معمولاً `int`, `char`, `enum`|
|کاربرد|وقتی شرط‌های پیچیده داری|وقتی مقدار ثابتی بین چند حالت مشخص مقایسه میشه|
|سرعت اجرا|کمی کندتر در حالت‌های زیاد|در حالت زیاد معمولاً سریع‌تر|
|خوانایی|در شرط‌های زیاد سخت‌تر خوانده میشه|برای حالت‌های زیاد مرتب‌تر و خواناتر|
|استفاده از break|ندارد|برای جلوگیری از اجرای case بعدی لازم است|

## 🧩 اول از همه: تفاوت اصلی do-while با while

🔹 **حلقه `while`**:
قبل از اجرای بدنه، شرط بررسی میشه.  
یعنی اگه شرط از همون اول غلط باشه، حلقه حتی **یه بار هم اجرا نمیشه**.

```c
int x = 10;
while (x < 5) {
    printf("x = %d\n", x);
    x++;
}
// اینجا هیچ‌چیزی چاپ نمیشه چون شرط از اول غلطه
```

---

🔹 **حلقه `do-while`**:
بدنه‌ی حلقه **حداقل یک بار اجرا میشه**،  
و بعدش شرط بررسی میشه.

```c
int x = 10;
do {
    printf("x = %d\n", x);
    x++;
} while (x < 5);
// خروجی: x = 10  (چون بدنه اول اجرا شد، بعد شرط بررسی شد)
```

---

## 🧠 پس: چرا مفیده؟
چون در بعضی از برنامه‌ها، **می‌خوای حداقل یک بار کاری انجام بشه**  
حتی اگه بعداً شرط برقرار نبود.

## ⚙️ مثال‌های واقعی کاربردی

### ۱. 🔑 منوهای کاربر (User Menu)
وقتی می‌خوای کاربر **حداقل یک بار منو رو ببینه** و بعد بر اساس انتخابش ادامه بدی:

```c
#include <stdio.h>

int main() {
    int choice;
    do {
        printf("\n--- منوی اصلی ---\n");
        printf("1. نمایش اطلاعات\n");
        printf("2. تنظیمات\n");
        printf("3. خروج\n");
        printf("انتخاب شما: ");
        scanf("%d", &choice);

        switch (choice) {
            case 1:
                printf("نمایش اطلاعات...\n");
                break;
            case 2:
                printf("باز کردن تنظیمات...\n");
                break;
            case 3:
                printf("خروج از برنامه...\n");
                break;
            default:
                printf("انتخاب نامعتبر!\n");
        }

    } while (choice != 3); // تا وقتی کاربر عدد 3 نزده، منو تکرار کن

    return 0;
}
```

📌 اینجا **منو حداقل یک‌بار باید نمایش داده بشه**،  
به همین خاطر از `do-while` استفاده می‌کنیم.

---

### ۲. 🔁 اعتبارسنجی ورودی کاربر (Input Validation)

مثلاً بخوای از کاربر عددی بگیری تا وقتی درست وارد نکرده، دوباره ازش بپرسی:

```c
#include <stdio.h>

int main() {
    int age;
    do {
        printf("سن خود را وارد کنید (بیشتر از 0): ");
        scanf("%d", &age);
    } while (age <= 0); // تا وقتی مقدار معتبر نیست، تکرار کن

    printf("سن شما: %d\n", age);
    return 0;
}
```

✅ اینجا لازمه کاربر **حداقل یک بار** بتونه عدد وارد کنه،  
برای همین `do-while` دقیقاً مناسب‌ترین انتخابه.

---

### ۳. 🔄 اجرای برنامه تا زمان خروج کاربر
در بسیاری از برنامه‌های کنسولی یا بازی‌های ساده:

```c
char again;
do {
    printf("یک بار دیگه بازی کنیم؟ (y/n): ");
    scanf(" %c", &again);
} while (again == 'y' || again == 'Y');
```

📍 اینجا هم تا وقتی کاربر بخواد، برنامه تکرار میشه — ولی **حداقل یک بار باید اجرا بشه.**
