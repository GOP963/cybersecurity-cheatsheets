## 💡 اول از همه: چرا اصلاً باید از `%d`, `%f`, `%s` و این چیزا استفاده کنیم؟

در زبان C، توابعی مثل `printf()` و `scanf()` **توابع عمومی (generic)** هستن،  
یعنی خودشون **نمی‌دونن نوع داده‌ای که باهاش کار می‌کنن چیه** 😅

مثلاً:

```c
printf("عدد من = ", x);
```

اینجا کامپایلر نمی‌فهمه `x` عدد صحیحه، اعشاریه، کاراکتره یا یه رشته!  
برای همین باید **با یک “قالب” (format specifier)** بهش بگیم دقیقاً چه نوع داده‌ایه.

---

## 🧩 پس این `%` چیزیه شبیه یه "برچسب نوع داده"ه

یعنی وقتی می‌گی:

```c
printf("%d", x);
```

در واقع داری می‌گی:

> "برو مقدار x رو بگیر، چون نوعش integer هست، اون رو به شکل عدد صحیح چاپ کن."

---

## ⚙️ ساختار کلی format specifier

| ساختار        | توضیح                                 |
| ------------- | ------------------------------------- |
| `%`           | شروع قالب                             |
| `[flags]`     | اختیاری، برای تنظیمات ظاهری           |
| `[width]`     | اختیاری، برای اندازه‌ی محل چاپ        |
| `[precision]` | اختیاری، برای دقت در اعشار            |
| `[length]`    | نوع سایز عدد (`long`, `short`)        |
| `specifier`   | نوع اصلی داده (عدد، رشته، کاراکتر...) |

مثلاً:

```c
%6.2f
```

یعنی:

> عدد اعشاری (float/double) با **۶ کاراکتر فضا** و **۲ رقم بعد از اعشار** چاپ کن.

---

## 🧠 حالا بریم سراغ انواعش 👇

### 🔹 ۱. برای اعداد صحیح (Integer)

|نوع داده|توضیح|علامت|
|---|---|---|
|`int`|عدد صحیح (مثلاً 10 یا -5)|`%d` یا `%i`|
|`short`|عدد صحیح کوتاه‌تر|`%hd`|
|`long`|عدد صحیح بلندتر|`%ld`|
|`unsigned int`|عدد صحیح بدون علامت (فقط مثبت)|`%u`|
|`unsigned long`|عدد صحیح بلند و بدون علامت|`%lu`|
|`unsigned short`|کوتاه و بدون علامت|`%hu`|
|`int` در مبنای ۸ (octal)|نمایش در مبنای ۸|`%o`|
|`int` در مبنای ۱۶ (hexadecimal)|نمایش در مبنای ۱۶|`%x` یا `%X`|

---

### 🔹 ۲. برای اعداد اعشاری (Floating Point)

| نوع داده                                           | توضیح                    | علامت        |
| -------------------------------------------------- | ------------------------ | ------------ |
| `float`                                            | عدد اعشاری معمولی        | `%f`         |
| `double`                                           | عدد اعشاری دقیق‌تر       | `%lf`        |
| `long double`                                      | اعشار با دقت خیلی بالا   | `%Lf`        |
| `scientific notation`                              | نمایش علمی (مثل 1.2e+02) | `%e` یا `%E` |
| ترکیبی (بهتر بین حالت معمولی و علمی انتخاب می‌کنه) | `%g` یا `%G`             |              |

---

### 🔹 ۳. برای کاراکترها و رشته‌ها

|نوع داده|توضیح|علامت|
|---|---|---|
|`char`|یک کاراکتر|`%c`|
|`char[]` (رشته)|رشته‌ی متنی (مثل "hello")|`%s`|

---

### 🔹 ۴. برای آدرس‌ها (Pointer)

| نوع داده                               | توضیح      | علامت |
| -------------------------------------- | ---------- | ----- |
| هر نوع اشاره‌گر (`int*`, `char*`, ...) | آدرس حافظه | `%p`  |

---

### 🔹 ۵. برای درصد واقعی

اگه بخوای خود علامت درصد چاپ بشه:

```c
printf("درصد: 100%%");
```

✅ خروجی:

```
درصد: 100%
```

---

## 🎯 چند مثال کاربردی:

```c
#include <stdio.h>

int main() {
    int a = 10;
    float b = 3.1415;
    char c = 'A';
    char str[] = "Martin";

    printf("عدد صحیح: %d\n", a);
    printf("عدد اعشاری: %.2f\n", b);
    printf("کاراکتر: %c\n", c);
    printf("رشته: %s\n", str);
    printf("آدرس متغیر a: %p\n", &a);

    return 0;
}
```

📤 **خروجی:**

```
عدد صحیح: 10
عدد اعشاری: 3.14
کاراکتر: A
رشته: Martin
آدرس متغیر a: 0x7ffee98d9a8c
```

## 💡 اول از همه: علامت `&` در C یعنی چی؟

در زبان C، علامت `&` (ampersand) یعنی **"آدرس حافظه‌ی متغیر"**.  
یعنی به‌جای اینکه مقدار خود متغیر رو بگیری، **محل (location)** اون در حافظه رو می‌گیری.

---

### 🔹 مثال ساده:

```c
int a = 10;
printf("مقدار a: %d\n", a);
printf("آدرس a: %p\n", &a);
```

📤 خروجی مثلاً:

```
مقدار a: 10
آدرس a: 0x7ffce123abc0
```

اینجا:

- `a` → یعنی "مقدار درون متغیر"
    
- `&a` → یعنی "آدرس متغیر a در حافظه"
    

---

## 🧠 یعنی چی “آدرس در حافظه”؟

کامپیوتر برای ذخیره‌ی هر داده، جایی در **RAM** براش رزرو می‌کنه.  
هر خونه از حافظه یک **آدرس عددی** داره (مثل پلاک خانه 😄).

مثلاً:

|متغیر|مقدار|آدرس حافظه|
|---|---|---|
|`a`|10|0x7ffce123abc0|

پس وقتی می‌گی `&a`، داری می‌گی:

> “برو اون عددی رو به من بده که نشون میده متغیر `a` کجای حافظه قرار گرفته.”

---

## 🧩 حالا چرا در printf و scanf فرق داره؟

### ✅ در `printf`:

وقتی از `&` استفاده می‌کنی، فقط **آدرس متغیر** رو چاپ می‌کنی.

```c
printf("%p", &a);
```

در اینجا `%p` مخصوص آدرس‌هاست (pointer address).

---

### ✅ در `scanf`:

اما در `scanf` قضیه برعکسه 👇

تابع `scanf` باید مقدار ورودی کاربر رو در جایی ذخیره کنه.  
برای این کار، باید **آدرس حافظه‌ی متغیر** رو بدونه تا بتونه اونجا بنویسه!

```c
int num;
scanf("%d", &num);
```

🔹 `%d` یعنی "کاربر قراره عدد صحیح وارد کنه"  
🔹 `&num` یعنی "آدرس حافظه‌ی num، جایی که باید مقدار کاربر در اون ذخیره بشه"

اگر بنویسی:

```c
scanf("%d", num); // ❌ اشتباه
```

برنامه **کرش می‌کنه یا مقدار اشتباه می‌نویسه**  
چون `scanf` نمی‌دونه عدد رو کجا بریزه — فقط مقدار `num` رو داره، نه آدرسش.

---

## ⚙️ مقایسه‌ی دیداری

|حالت|کاری که انجام میشه|مثال|
|---|---|---|
|بدون `&`|مقدار متغیر گرفته میشه|`printf("%d", a);` ← چاپ 10|
|با `&`|آدرس متغیر گرفته میشه|`printf("%p", &a);` ← چاپ آدرس حافظه|
|در `scanf`|باید از `&` استفاده کنی تا مقدار در آدرس ذخیره بشه|`scanf("%d", &a);`|

---

## 🧩 جمع‌بندی کوتاه

|مورد|معنی `&`|
|---|---|
|در `printf`|نمایش آدرس متغیر|
|در `scanf`|دادن آدرس متغیر تا مقدار در اون ذخیره بشه|
|در اشاره‌گرها (`int *p = &a;`)|گرفتن آدرس متغیر برای ذخیره در pointer|

## 💡 تعریف ساده:

## **Pointer 
(اشاره‌گر)** یعنی متغیری که **آدرس حافظه‌ی یه متغیر دیگه رو ذخیره می‌کنه.**

یعنی به‌جای اینکه خودش یه عدد یا متن نگه‌داره،  
می‌گه: «اون مقدار اون‌جا توی حافظه‌ست! من فقط آدرسش رو دارم.»

---

## 🧱 مرحله ۱: یه متغیر عادی بسازیم

```c
int a = 10;
```

الان حافظه یه خونه برای `a` درست می‌کنه، مثلاً اینطوری:

|متغیر|مقدار|آدرس حافظه|
|---|---|---|
|`a`|10|0x7ffc1234abc0|

---

## 🧱 مرحله ۲: آدرس متغیر رو بگیریم

```c
printf("%p", &a);
```

خروجی مثلاً:

```
0x7ffc1234abc0
```

پس `&a` یعنی "آدرس متغیر `a`".

---

## 🧱 مرحله ۳: حالا یه اشاره‌گر بسازیم که اون آدرس رو نگه‌داره

```c
int *p = &a;
```

اینجا 👇

- `int *` یعنی این اشاره‌گر به **یه عدد صحیح (int)** اشاره می‌کنه.
    
- `p` اسم اشاره‌گره.
    
- `&a` یعنی آدرس متغیر `a` رو بریز داخل `p`.
    

---

📦 حالا وضعیت حافظه این شکلی میشه:

|متغیر|مقدار|آدرس حافظه|
|---|---|---|
|`a`|10|0x7ffc1234abc0|
|`p`|0x7ffc1234abc0|0x7ffc1234ac00|

یعنی:

> اشاره‌گر `p` خودش یه متغیره که داخلش **آدرس متغیر `a`** ذخیره شده.

---

## 🧱 مرحله ۴: گرفتن مقدار متغیری که اشاره‌گر بهش اشاره می‌کنه (`*` operator)

علامت `*` (بهش می‌گن **dereference operator**)  
میگه:

> “برو به اون آدرسی که داخل اشاره‌گر هست و مقدار واقعی اونجا رو بهم بده.”

```c
printf("مقدار a: %d\n", *p);
```

📤 خروجی:

```
مقدار a: 10
```

چون:

- `p` خودش آدرس `a` رو داره
    
- `*p` یعنی "مقدار موجود در اون آدرس" → همون مقدار `a`
    

---

## 💡 یه نگاه خلاصه:

|عبارت|معنی|
|---|---|
|`a`|مقدار واقعی متغیر|
|`&a`|آدرس متغیر|
|`p`|متغیر اشاره‌گر که آدرس `a` رو نگه‌می‌داره|
|`*p`|مقدار واقعی که اشاره‌گر بهش اشاره می‌کنه (همون مقدار `a`)|

---

## ✨ یه مثال کامل و قابل اجرا:

```c
#include <stdio.h>

int main() {
    int a = 10;      // یه عدد معمولی
    int *p = &a;     // یه اشاره‌گر به a

    printf("مقدار a: %d\n", a);
    printf("آدرس a: %p\n", &a);
    printf("مقدار p (که همون آدرس a هست): %p\n", p);
    printf("مقدار درون آدرس p (یعنی مقدار a): %d\n", *p);

    // حالا مقدار a رو از طریق اشاره‌گر تغییر می‌دیم:
    *p = 99;
    printf("مقدار جدید a بعد از تغییر از طریق *p: %d\n", a);

    return 0;
}
```

📤 خروجی:

```
مقدار a: 10
آدرس a: 0x7ffd7d3a2c30
مقدار p (که همون آدرس a هست): 0x7ffd7d3a2c30
مقدار درون آدرس p (یعنی مقدار a): 10
مقدار جدید a بعد از تغییر از طریق *p: 99
```

---

## 🧠 جمع‌بندی سریع:

|نماد|معنی|مثال|
|---|---|---|
|`&`|گرفتن آدرس متغیر|`&a`|
|`*`|رفتن به آدرسی که اشاره‌گر نگه‌داشته|`*p`|
|`int *p`|تعریف اشاره‌گر به متغیر از نوع int|`int *p = &a;`|

---

## 🚀 کاربردهای واقعی اشاره‌گرها:

1. **ارسال متغیرها به تابع‌ها بدون کپی‌کردن مقدار** (یعنی کار با آدرس واقعی)
    
2. **مدیریت حافظه (malloc, free)**
    
3. **کار با آرایه‌ها و رشته‌ها (string)**
    
4. **برنامه‌نویسی سطح پایین (مثل kernel، system programming، network bufferها)**
