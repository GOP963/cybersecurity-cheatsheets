## 🔹 چی هست `enum` (Enumeration)؟

`enum`
یک نوع شمارشی در C است که مجموعه‌ای از نام‌های نمادین (مثل `GENDER_MALE`) را به مقادیر صحیح (integer) نگاشت می‌کند.  
در واقع هر عضوِ `enum` یک عدد صحیح است — اگر مقدار مشخص نکنی، از **۰** شروع می‌کند و به ترتیب افزایش می‌یابد.

---

## 🔹 ساختار پایه و مثال ساده

```c
enum Gender { GENDER_MALE, GENDER_FEMALE }; 
// GENDER_MALE == 0, GENDER_FEMALE == 1
```

مثال کامل در `main`:

```c
#include <stdio.h>

enum Gender { GENDER_MALE, GENDER_FEMALE };
int main(void) {
    enum Gender data;
    data = GENDER_MALE;
    printf("value = %d\n", data); // چاپ: value = 0
    data = GENDER_FEMALE;
    printf("value = %d\n", data); // چاپ: value = 1
    return 0;
}
```

---

## 🔹 می‌تونی مقدار صریح بدی

```c
enum Country { IRAN = 1, US = 2, UK = 44 };
```

اگر مقادیر را مشخص نکنی، به‌صورت خودکار ۰، ۱، ۲، ... خواهند بود.

---

## 🔹 نکات فنی و محدودیت‌ها

- **نوع پایه‌ی مقادیر:** در C استاندارد، اعضای `enum` از نوع `int` هستند (اندازه واقعی ممکن است implementation-defined باشد اما معمولاً `int`).
    
- **نوع‌نگهداری ایمن نیست:** در C، `enum` نوع‌ امن (type-safe) نیست — می‌توان هر مقدار عددی (مثلاً `42`) را به یک متغیر `enum` نسبت داد بدون ارور کامپایل (هشدار ممکن است).
    
- **پیچیدگی در اندازه:** برای ذخیره‌سازی فشرده (مثلاً در فایل یا شبکه) نباید بدون تبدیل صریح فرض کنی `enum` مثلاً 1 بایت دارد. اندازه‌اش implementation-dependent است.
    
- **نام‌گذاری:** از نام‌های معنادار و پیش‌ونددار استفاده کن (مثل `GENDER_` یا `COUNTRY_`) تا با سایر نمادها تداخل نداشته باشه.
    
- **تداخل نام‌ها:** اگر `enum` داخل بلوک یا تابع تعریف نشده باشه و نام‌های عمومی مثل `US` یا `UK` استفاده کنی، ممکنه با macroها یا نمادهای دیگر تداخل کند.

## 🔹 مثال‌های کاربردی (جزوه‌ای)

1. استفاده همزمان با `struct`:
    

```c
enum Gender { MALE, FEMALE };

struct Person {
    char name[32];
    enum Gender gender;
    int age;
};

struct Person p = { "Ali", MALE, 30 };
```

2. در `switch`:
    

```c
switch (p.gender) {
    case MALE:   /* ... */ break;
    case FEMALE: /* ... */ break;
}
```

3. مقداردهی صریح و استفاده به‌عنوان بیت‌فلگ (وقتی لازم باشه):
    

```c
enum FilePerm {
    PERM_READ  = 1 << 0, // 1
    PERM_WRITE = 1 << 1, // 2
    PERM_EXEC  = 1 << 2  // 4
};
// سپس میشه از عملگر بیتی استفاده کرد
```

## 🔹 چرا `enum` مفیده؟

- خواناتر می‌کنه کد (به‌جای اعداد «جادویی» می‌تونی نام معنی‌دار ببینی).
    
- خطاهای منطقی کم‌تر میشه چون اسم‌گذاری واضحه.
    
- مناسب برای حالاتی که مقدارهای گسسته و محدود داریم (مثلاً وضعیت‌ها، نوع‌ها، گزینه‌ها).
    

---

## 🔹 هشدارهای امنیتی / عملیاتی (مختصر)

- `enum` خودش امنیتی/غلط سالمتی ایجاد نمی‌کنه — همیشه ورودی‌های خارجی که به `enum` نگاشت می‌شن رو validate کن.
    
- هیچ‌وقت به‌صورت ضمنی فرض نکن مقدار `enum` در محدوده‌ی تعریف‌شده‌است؛ قبل از استفاده در switch/اندیس آرایه چک کن.

## 🔹 نسخه‌ای که برای جزوه بذاری (خلاصه)

```c
// مثال خلاصه:
enum Gender { GENDER_MALE, GENDER_FEMALE }; // 0, 1

enum Country { IRAN = 1, US = 2, UK = 44 };

enum Gender g = GENDER_MALE;
if (g == GENDER_FEMALE) { /* ... */ }
```

توضیح کوتاه: `enum` نام‌ها را به مقادیر int نگاشت می‌کند؛ قابل‌استفاده در switch/struct؛ مقداردهی صریح و نکات نوع/اندازه را در نظر بگیر.
