نکته یی که درباره pointer هست اینه که اگر ما بخواهیم pointer رو به متغیر مون وصل کنیم در اصل read انجام میده اما اگر سمت چپ بزاریم write انجام میده 


```
int main(){

	void *ptr;
	int x = *ptr; //-----> read | Rvalue |
	// ------------------------------------->> LRvalue ---> Pointer
	*ptr = 50; //-----> write | lvalue   |
	return 0;
}
```

حالا ما یه مفهومی داریم در برنامه نویسی سیستمی به اسم ( lvalue , rvalue , lrvalue )

به مقادیری که میتونیم بزاریم سمت چپ مساوی میگن lvalue یا همون left side 
به مقادیری که میشه سمت راست مساوی گذاشت میگیم rvalue 
به مقادیری که میشه هم سمت چپ و هم سمت راست گذاشت میگیم lrvalue که pointer شامل هر دوتاش میشه 

اما مثلا عدد rvalue
