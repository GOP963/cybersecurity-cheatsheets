

در زبان C ما میتونیم بیایم و شرط هارو به سه حالت بنویسم مثلا


1

```
int x = 10;

if (x == 10)printf("True");
```

در این حالت ما هیچ بدنه یی براش تایین نمیکنیم فقط میگیم شرطی که داریم رو بهش میگیم تا برامو اجرا کنه 


2 

```
int x  = 10;
if (x == 10){

	printf("True");
	return 0;
}
```

در این حالت ما یه بدنه برای شرطمون در نظر میگیریم و میایم داخل اون بدنه شرط مون رو اجرا میکنیم در این حالت میتونیم بیایم و بیشتر روی شرطی که داریم کار کنیم 


اگر بخواهیم که بگیم در غیر این صورت هم میایم و خیلی راحت از else استفاده میکنیم 

```
int x = 10;
if (x == 10){

	printf("True");
	return 0;

}else{

	printf("False");
	return 1;
}
```


اگرم بخواهیم بگیم که هم اره و هم نه از else if استفاده میکنیم 

در حالت میگیم که اگر این شرط برقرار نبود بیا این شرط رو اجرا کن 

```
int x = 10;
if (x == 10){

	printf("True");
	return 0;

}else if{
	
	printf("hello world\n");
	return 1;
}
```
