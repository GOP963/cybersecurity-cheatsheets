

اگر متغیر ما 20 تا خوه جا داشته باشه اما دیتای ما کلا 5 تا باشه برای اینکه بهش بفهمونیم دیتای ما همینقدره اخرش باید از 0 استفاده کنیم که کد اسکیش میشه همون 0

```
char x[20] = {'h','e','l','l','o',}
```

به این استرینگ ها در اصطلاح میگن C-Strings 

هر موقهع بخواهیم تهه String رو بهش معرفی کنیم از این علامت استفاهد میکنیم و وقتی که از این علامت استفاده کنیم یک Intrupt درست میشود  و استرینگ ما به پایان میرسد 



در زبان C اگر بیایم و از "" استفاده کنیم خودش به صورت دیفالت اخرش 0 میزاره 


```
char x = "hello";
```



اگر بخواهیم کتابخونه برای زبان C نصب کنیم میتونیم با استفاده از پکیج apt بیایم و اینکارو بکنیم 


```
sudo apt install lib
```

وقتی که Lib رو بزنیم و تب بزنیم میاد برای ما کل کتابخونه ها رو نشون میده
