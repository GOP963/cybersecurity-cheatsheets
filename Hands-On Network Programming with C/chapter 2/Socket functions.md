


---

### 🧩 1. `socket()`

🔹 **هدف:** ساخت یک سوکت جدید در برنامه.  
🔹 **نقش:** اولین قدم برای هر ارتباط شبکه‌ای است — یعنی باز کردن یک “درگاه ارتباطی” بین برنامه و شبکه.  
🔹 **در C:**

```c
int sockfd = socket(AF_INET, SOCK_STREAM, 0);
```

🔹 **پارامترها:**

- `AF_INET`: نوع آدرس‌دهی (IPv4)
    
- `SOCK_STREAM`: نوع ارتباط (TCP)
    
- `0`: پروتکل پیش‌فرض (TCP در این حالت)
    

---

### 🧩 2. `bind()`

🔹 **هدف:** اتصال (Binding) سوکت به یک IP و پورت خاص روی سیستم محلی.  
🔹 **نقش:** برای سرورها استفاده می‌شود تا بگویند “من روی پورت 8080 منتظر درخواست‌ها هستم”.  
🔹 **در C:**

```c
bind(sockfd, (struct sockaddr*)&addr, sizeof(addr));
```

---

### 🧩 3. `listen()`

🔹 **هدف:** گذاشتن سوکت در حالت “گوش دادن” برای ارتباطات ورودی.  
🔹 **نقش:** فقط برای **TCP سرورها** استفاده می‌شود.  
🔹 **در C:**

```c
listen(sockfd, 10);
```

🔹 عدد 10 یعنی حداکثر چند اتصال می‌توانند در صف انتظار باشند.

---

### 🧩 4. `accept()`

🔹 **هدف:** پذیرفتن یک اتصال جدید از کلاینت.  
🔹 **نقش:** وقتی کلاینت با `connect()` به سرور وصل می‌شود، `accept()` یک سوکت جدید برای آن اتصال می‌سازد.  
🔹 **در C:**

```c
int client_sock = accept(sockfd, (struct sockaddr*)&client, &len);
```

🟢 حالا سرور می‌تواند از `client_sock` برای ارسال/دریافت داده استفاده کند.

---

### 🧩 5. `connect()`

🔹 **هدف:** اتصال کلاینت به آدرس و پورت مشخص سرور.  
🔹 **در C:**

```c
connect(sockfd, (struct sockaddr*)&server, sizeof(server));
```

🔹 اگر اتصال موفق باشد، حالا کلاینت و سرور می‌توانند داده رد و بدل کنند.

---

### 🧩 6. `send()` و `recv()`

🔹 **هدف:** ارسال و دریافت داده در ارتباط‌های TCP.  
🔹 **در C:**

```c
send(sockfd, buffer, len, 0);
recv(sockfd, buffer, len, 0);
```

🔹 `send()` داده را می‌فرستد، `recv()` منتظر داده از سمت دیگر می‌ماند.

---

### 🧩 7. `sendto()` و `recvfrom()`

🔹 **هدف:** ارسال و دریافت داده در ارتباط‌های بدون اتصال (UDP).  
🔹 چون UDP برخلاف TCP اتصال پایدار ندارد، باید مقصد را در هر بار ارسال مشخص کنیم:

```c
sendto(sockfd, buffer, len, 0, (struct sockaddr*)&dest, sizeof(dest));
recvfrom(sockfd, buffer, len, 0, (struct sockaddr*)&src, &len);
```

---

### 🧩 8. `close()` / `closesocket()`

🔹 **هدف:** بستن سوکت و آزاد کردن منابع سیستم.  
🔹 در لینوکس/مک:

```c
close(sockfd);
```

🔹 در ویندوز:

```c
closesocket(sockfd);
```

---

### 🧩 9. `shutdown()`

🔹 **هدف:** بستن یکی از مسیرهای ارتباطی (فقط خواندن یا فقط نوشتن).  
🔹 مثلاً برای گفتن به طرف مقابل که “من دیگه داده نمی‌فرستم، ولی می‌تونم هنوز دریافت کنم.”  
🔹 در C:

```c
shutdown(sockfd, SHUT_WR); // بستن مسیر ارسال
```

---

### 🧩 10. `select()`

🔹 **هدف:** مانیتور کردن چند سوکت به طور همزمان تا ببینیم کدوم‌یک آماده‌ی خواندن/نوشتن است.  
🔹 **نقش:** برای سرورهایی با چند اتصال همزمان استفاده می‌شود.  
🔹 در C:

```c
select(maxfd+1, &readfds, NULL, NULL, NULL);
```

---

### 🧩 11. `getaddrinfo()` و `getnameinfo()`

🔹 **هدف:** تبدیل بین نام‌ها (hostname) و آدرس‌های IP.  
🔹 مثلاً:

```c
getaddrinfo("example.com", "80", &hints, &res);
```

🔹 یعنی آدرس IP مربوط به example.com را پیدا کن.

---

### 🧩 12. `setsockopt()`

🔹 **هدف:** تغییر تنظیمات سطح پایین سوکت (مثل timeout، reuse address و ...).  
🔹 در C:

```c
setsockopt(sockfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
```

---

### 🧩 13. `fcntl()` (در Linux) و `ioctlsocket()` (در Windows)

🔹 **هدف:** کنترل رفتار سوکت — مثلاً تنظیم حالت non-blocking یا گرفتن اطلاعات وضعیت.  
🔹 در لینوکس:

```c
fcntl(sockfd, F_SETFL, O_NONBLOCK);
```

🔹 در ویندوز:

```c
u_long mode = 1;
ioctlsocket(sockfd, FIONBIO, &mode);
```
