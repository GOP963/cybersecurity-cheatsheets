## 🧠 TCP Program Flow — از دید کلاینت و سرور

---

### 🖥️ **Client (کلاینت)** — مرحله‌به‌مرحله

1. **شناختن آدرس سرور**
    
    - کاربر آدرس سرور رو وارد می‌کنه (مثلاً `example.com` یا IP مستقیم).
        
    - برنامه باید این آدرس رو به یک آدرس IP واقعی تبدیل کنه.
        
    - برای این کار از تابع `getaddrinfo()` استفاده می‌کنیم:
        
        ```c
        getaddrinfo("example.com", "80", &hints, &res);
        ```
        
2. **ساخت سوکت**
    
    - حالا باید یک سوکت TCP بسازیم تا از طریقش ارتباط برقرار کنیم:
        
        ```c
        int sockfd = socket(AF_INET, SOCK_STREAM, 0);
        ```
        
3. **اتصال به سرور**
    
    - بعد با تابع `connect()` به آدرس و پورت سرور وصل می‌شیم:
        
        ```c
        connect(sockfd, res->ai_addr, res->ai_addrlen);
        ```
        
4. **ارسال و دریافت داده**
    
    - بعد از اتصال موفق، کلاینت می‌تونه با `send()` داده بفرسته و با `recv()` پاسخ بگیره:
        
        ```c
        send(sockfd, "Hello", 5, 0);
        recv(sockfd, buffer, sizeof(buffer), 0);
        ```
        
5. **بستن ارتباط**
    
    - در نهایت با `close()` یا `closesocket()` سوکت رو می‌بندیم.
        

---

### 🖧 **Server (سرور)** — مرحله‌به‌مرحله

1. **آماده‌سازی آدرس**
    
    - سرور باید مشخص کنه روی چه IP و پورت گوش بده (مثلاً روی پورت 8080).
        
    - با `getaddrinfo()` می‌تونیم برای IPv4 و IPv6 به صورت مستقل این کار رو انجام بدیم.
        
2. **ساخت سوکت**
    
    - مشابه کلاینت:
        
        ```c
        int sockfd = socket(AF_INET, SOCK_STREAM, 0);
        ```
        
3. **اتصال به پورت و آدرس (Bind)**
    
    - سوکت رو به پورت مورد نظر وصل می‌کنیم:
        
        ```c
        bind(sockfd, res->ai_addr, res->ai_addrlen);
        ```
        
4. **گذاشتن سوکت در حالت گوش دادن**
    
    - برای دریافت اتصال‌های جدید از کلاینت:
        
        ```c
        listen(sockfd, SOMAXCONN);
        ```
        
5. **پذیرفتن اتصال جدید**
    
    - وقتی کلاینت درخواست می‌فرسته، با `accept()` اتصال جدید رو می‌گیریم:
        
        ```c
        int client_sock = accept(sockfd, (struct sockaddr*)&client, &len);
        ```
        
    - این تابع یک سوکت جدید برای هر کلاینت ایجاد می‌کنه تا داده‌ها از طریق اون رد و بدل بشن.
        
6. **ارسال و دریافت داده**
    
    - حالا می‌تونیم با همون `client_sock` از `send()` و `recv()` استفاده کنیم.
        
7. **ادامه‌ی گوش دادن**
    
    - سوکت اصلی (`sockfd`) همچنان باز می‌مونه و `accept()` می‌تونه دوباره برای اتصال‌های بعدی صدا زده بشه.
        

---

## 🔁 خلاصه تصویری جریان TCP

### 🔹 Client side:

```
getaddrinfo()  →  socket()  →  connect()  →  send()/recv()  →  close()
```

### 🔹 Server side:

```
getaddrinfo()  →  socket()  →  bind()  →  listen()  →  accept()  →  send()/recv()  →  close()
```

---

## ⚙️ نکات پیشرفته

- **نکته ۱:** معمولاً `bind()` در کلاینت لازم نیست، چون سیستم خودش به‌طور خودکار پورت آزاد انتخاب می‌کند.  
    ولی اگر سیستم چند کارت شبکه دارد و می‌خواهی از کارت خاصی استفاده کنی، کلاینت هم می‌تواند `bind()` کند.
    
- **نکته ۲:** هیچ قانونی وجود ندارد که بگوید کدام سمت باید اول `send()` یا `recv()` را صدا بزند.  
    هر دو طرف می‌توانند بلافاصله بعد از اتصال داده بفرستند.
    
- **نکته ۳:** سوکت اصلی سرور فقط برای گوش دادن است.  
    هر اتصال جدید از `accept()` یک سوکت جداگانه می‌گیرد.
