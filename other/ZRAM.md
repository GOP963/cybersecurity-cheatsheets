


قابلیت **ZRAM** در لینوکس یعنی استفاده از یک فضای فشرده‌سازی (compressed block device) در داخل RAM برای بهینه‌سازی مصرف حافظه.

به زبان ساده:

- به‌طور معمول وقتی حافظه RAM پر می‌شود، سیستم داده‌های کم‌استفاده را به **Swap** روی دیسک (HDD/SSD) می‌فرستد. این کار سرعت سیستم را به شدت کاهش می‌دهد چون دیسک خیلی کندتر از RAM است.
    
- اما **ZRAM** به جای دیسک، یک بلاک‌دستگاه (block device) فشرده‌شده داخل RAM ایجاد می‌کند و داده‌ها را به صورت **فشرده‌شده** در همان RAM ذخیره می‌کند.
    
- یعنی قبل از اینکه داده‌ها به swap روی دیسک بروند، اول در **ZRAM** قرار می‌گیرند. این باعث می‌شود سیستم بتواند داده‌های بیشتری را در همان RAM نگه دارد و فشار کمتری روی دیسک بیاید.
    

📌 ویژگی‌های مهم ZRAM:

1. **افزایش ظرفیت مؤثر RAM**: چون داده‌ها فشرده می‌شوند، فضای بیشتری در RAM آزاد می‌شود.
    
2. **سرعت بالاتر از Swap دیسکی**: دسترسی به ZRAM خیلی سریع‌تر از خواندن/نوشتن روی دیسک است.
    
3. **کاهش استفاده از دیسک**: مخصوصاً روی دستگاه‌هایی با SSD یا فلش (که تعداد نوشتن محدودی دارند)، باعث افزایش عمر سخت‌افزار می‌شود.
    
4. **کاربرد در سیستم‌های کم‌رم**: در لپ‌تاپ‌ها، دستگاه‌های اندرویدی، رزبری‌پای و سرورهایی با رم محدود خیلی استفاده می‌شود.
    

📍 مثال:  
اگر شما ۴ گیگ RAM دارید و ZRAM را فعال کنید، با توجه به الگوریتم فشرده‌سازی ممکن است بتوانید عملاً چیزی بین ۵ تا ۶ گیگ داده داخل حافظه جا بدهید.

📌 نکته: ZRAM با **ZSWAP** فرق دارد.

- **ZRAM** یک بلاک‌دستگاه فشرده داخل RAM می‌سازد.
    
- **ZSWAP** به صورت لایه‌ی فشرده‌سازی روی swap دیسکی عمل می‌کند (یعنی قبل از نوشتن روی دیسک داده‌ها را فشرده می‌کند).
    

می‌خوای برات توضیح بدم که چطوری ZRAM رو روی اوبونتوی خودت (۲۴.۰۴) فعال کنی و ببینی الان فعاله یا نه؟




---

🔹 **بدون ZRAM**:

- RAM پر می‌شود → داده‌های کمتر استفاده‌شده می‌روند روی **Swap دیسک**.
    
- دیسک (HDD/SSD) خیلی کندتر از RAM است → سیستم کند می‌شود.
    

🔹 **با ZRAM**:

- کرنل یک بخش از RAM را به شکل **بلاک‌دستگاه مجازی** رزرو می‌کند.
    
- هر داده‌ای که قرار است به Swap برود، **اول در ZRAM ذخیره می‌شود، ولی به صورت فشرده**.
    
- چون فشرده‌سازی انجام شده، یک داده 4000 بایتی ممکن است بشود 3000 بایت (یا حتی کمتر) و همین باعث می‌شود RAM به شکل **موثر بزرگ‌تر** دیده شود.
    

---

📌 نکته مهم:

- ZRAM **جای RAM معمولی را نمی‌گیرد**.
    
- بلکه یک **لایه اضافی** می‌سازد: قبل از اینکه داده‌ها بروند روی دیسک (Swap واقعی)، اول درون ZRAM می‌روند و چون فشرده هستند، فضای کمتری می‌گیرند و خیلی سریع‌تر هم خوانده/نوشته می‌شوند.
    

---

یعنی در عمل:

- شما هم RAM معمولی دارید (داده‌های فعال و داغ).
    
- هم یک فضای فشرده داخل RAM (ZRAM) برای داده‌های کم‌استفاده.
    
- و تازه اگر همه‌ی اینها پر شد، می‌رود روی دیسک (Swap).
    

---

می‌خوای برات نشون بدم روی اوبونتوی خودت (۲۴.۰۴) چطوری ببینی چه مقدار ZRAM داری و الان چقدرش استفاده شده؟



---

## 🔹 ۱. بررسی پشتیبانی کرنل

تقریباً همه کرنل‌های مدرن لینوکس ZRAM رو پشتیبانی می‌کنن. برای اطمینان:

```bash
lsmod | grep zram
```

اگر خروجی چیزی نشون نداد، ماژول رو بارگذاری کن:

```bash
sudo modprobe zram
```


دستور `modprobe` برای **بارگذاری (load)** یا **حذف (unload)** ماژول‌های کرنل استفاده می‌شه.


### 🔹 اتفاقی که پشت پرده میفته

1. کرنل بررسی می‌کنه آیا ماژول `zram.ko` (kernel object) در مسیر `/lib/modules/$(uname -r)/kernel/drivers/` وجود داره یا نه.
    
2. اگر موجود بود، اون ماژول رو بارگذاری می‌کنه.
    
3. بعد از بارگذاری، یک **دستگاه جدید به نام `/dev/zram0`** (و در صورت نیاز `/dev/zram1`, `/dev/zram2`, ...) ساخته می‌شه.
    
    - این دستگاه مثل یک **بلاک‌دستگاه مجازی** عمل می‌کنه.

---

## 🔹 ۲. ساخت یک بلاک‌دستگاه ZRAM

مثلاً می‌خوای یه دستگاه ZRAM با اندازه 2GB بسازی:

```bash
echo 2G | sudo tee /sys/block/zram0/disksize
```

📌 این دستور می‌گه: دستگاه `/dev/zram0` بساز و اندازه‌اش ۲ گیگ باشه.

---

## 🔹 ۳. فرمت کردن ZRAM برای استفاده به عنوان Swap

```bash
sudo mkswap /dev/zram0
```

---

## 🔹 ۴. فعال کردن Swap روی ZRAM

```bash
sudo swapon /dev/zram0
```

الان ZRAM فعاله ✅

---

## 🔹 ۵. بررسی وضعیت

برای دیدن وضعیت ZRAM:

```bash
cat /proc/swaps
```

یا اطلاعات دقیق‌تر:

```bash
zramctl
```

---

## 🔹 ۶. غیرفعال‌سازی (در صورت نیاز)

اگر خواستی خاموشش کنی:

```bash
sudo swapoff /dev/zram0
```

---

📌 نکته:  
روی اوبونتوهای جدید (از 20.04 به بعد)، **ZRAM به صورت پیش‌فرض فعاله**. معمولاً پکیج `zram-generator` یا `systemd-zram-generator` این کارو می‌کنه. پس شاید الان روی سیستم تو همین الآن روشن باشه.
