# 🔹 Pointer (اشاره‌گر) چیست؟

به زبان خیلی ساده:  
👉 **Pointer یک متغیر است که به جای نگهداری مقدار، آدرس یک متغیر دیگر در حافظه را نگه می‌دارد.**

---

## 🔸 مثال ساده

فرض کن یه متغیر معمولی داری:

```c
int x = 10;
```

- این یعنی یه **بخش از حافظه** گرفته شده و داخلش مقدار `10` ذخیره شده.
    
- حالا آدرس اون بخش حافظه (مثلاً `0x7ffeefbff45c`) هم وجود داره.
    

اگر بخوای آدرس رو ذخیره کنی، نیاز به **pointer** داری:

```c
int *p = &x;
```

- `int *p` → میگه `p` یک pointer به نوع `int` هست.
    
- `&x` → یعنی "آدرس متغیر x".
    
- حالا `p` آدرس `x` رو نگه می‌داره.
    

---

## 🔸 دسترسی به مقدار از طریق Pointer

اگر بخوای به **مقدار داخل آدرسی که pointer اشاره کرده** دسترسی داشته باشی، از `*` استفاده می‌کنی:

```c
printf("%d", *p);  // خروجی: 10
```

- `*p` → یعنی "برو به آدرسی که p توش ذخیره شده و مقدارش رو بیار".
    

---

## 🔸 چرا Pointer مهمه؟

1. **مدیریت مستقیم حافظه** → مثلاً در زبان C می‌تونی دقیقاً بگی چه آدرسی استفاده بشه.
    
2. **ارجاع به داده‌های بزرگ** → به جای کپی کردن کل یک آرایه یا ساختار، فقط آدرسش رو پاس می‌دی.
    
3. **کار با توابع و آرایه‌ها** → خیلی از توابع برای تغییر مستقیم روی داده‌ها از pointer استفاده می‌کنن.
    
4. **استفاده در سیستم‌عامل و Exploitation** → خیلی از باگ‌های امنیتی (Buffer Overflow, Use After Free, ROP) به خاطر pointer ها به وجود میان.
    

---

## 🔸 مثال تصویری

فرض کن تو حافظه داری:

|آدرس|مقدار|
|---|---|
|0x1000|10|
|0x2000|0x1000|

- `x = 10`
    
- `p = &x`
    
- `*p = 10`
    

---

## 📌 جمع‌بندی

- Pointer یک **متغیر** است که **آدرس یک متغیر دیگر** را ذخیره می‌کند.
    
- `&` = گرفتن آدرس
    
- `*` = رفتن به آدرس و گرفتن مقدار
    
- در زبان‌هایی مثل C و C++ فوق‌العاده مهمه و در مباحث امنیتی هم پایه خیلی از آسیب‌پذیری‌هاست.
    

---

---

## 🔹 نسخه درست‌شده کد:

```c
#include <stdio.h>

int main() {
    int x = 18;
    int *p = &x;

    printf("%d\n", *p);  // چاپ مقدار داخل x از طریق pointer
    return 0;
}
```

---

## 🔹 توضیح:

- `int *p = &x;` → آدرس متغیر `x` رو در `p` ذخیره کردی.
    
- `*p` → یعنی "برو به آدرسی که `p` اشاره می‌کنه و مقدارشو بیار" → در اینجا `18`.
    
- `printf("%d", *p);` → می‌گه: این مقدار یه **عدد صحیح (int)** هست، پس با `%d` چاپش کن.
