### **حمله DHCP Starvation چیست؟**

حمله **DHCP Starvation** یکی از حملات **لایه ۲ شبکه** است که هدف آن **تمام کردن آدرس‌های IP موجود در محدوده DHCP** است.

به زبان ساده:  
وقتی یک کلاینت به شبکه وصل می‌شود، از طریق **پروتکل DHCP** درخواست یک آدرس IP می‌دهد. سرور DHCP معمولاً یک محدوده مشخص از IPها (Pool) دارد. اگر یک مهاجم بتواند **تمام این آدرس‌ها را بگیرد**، دیگر هیچ کلاینت جدیدی نمی‌تواند آدرس IP دریافت کند و عملاً **ارتباطش با شبکه قطع می‌شود**.

---

### **چطور انجام می‌شود؟**

1. مهاجم یک ابزار (مثل **Yersinia**، **dhcpstarv** یا حتی اسکریپت‌های شخصی) اجرا می‌کند.
    
2. این ابزار **تعداد زیادی درخواست DHCP (DHCP Discover)** را به سرور می‌فرستد.
    
3. مهاجم در هر درخواست، **یک آدرس MAC جعلی** استفاده می‌کند (چون سرور DHCP معمولاً آدرس IP را بر اساس MAC می‌دهد).
    
4. سرور DHCP به هر درخواست یک IP اختصاص می‌دهد و به‌مرور **کل Pool آدرس‌ها پر می‌شود**.
    
5. وقتی Pool پر شد، کلاینت‌های واقعی دیگر نمی‌توانند IP بگیرند و **از شبکه محروم می‌شوند**.
    

---

### **چرا خطرناک است؟**

- باعث **Denial of Service (DoS)** برای کلاینت‌های قانونی می‌شود.
    
- اگر مهاجم کنترل شبکه را در دست داشته باشد، می‌تواند یک **سرور DHCP جعلی (Rogue DHCP)** راه‌اندازی کند و به کلاینت‌ها **IP، Gateway و DNS جعلی** بدهد (که زمینه‌ساز حملات Man-in-the-Middle می‌شود).
    

---

### **ابزارهای متداول برای این حمله**

- **Yersinia** (در لینوکس)
    
- **dhcpstarv** (در کالی لینوکس)
    
- اسکریپت‌های سفارشی با **Scapy (پایتون)**
    

---

### **راه‌های مقابله**

- **DHCP Snooping** روی سوئیچ‌ها (برای شناسایی و محدود کردن درخواست‌های غیرمجاز).
    
- **Port Security** (محدود کردن تعداد آدرس‌های MAC مجاز در یک پورت).
    
- استفاده از **Static IP** در شبکه‌های حساس.
    
- **Monitoring** و هشداردهی برای تعداد غیرعادی درخواست‌های DHCP.

## **Yersinia چیست؟**

یک ابزار تست نفوذ **لایه ۲ (Layer 2)** است که می‌تواند چندین پروتکل شبکه (مثل DHCP، STP، CDP، DTP، HSRP و …) را هدف قرار دهد.  
برای **حمله DHCP Starvation**، این ابزار می‌تواند **تعداد زیادی درخواست DHCP با آدرس‌های MAC جعلی** تولید کند و Pool آدرس‌های DHCP را پر کند.

---

## **نصب Yersinia**

در کالی لینوکس به صورت پیش‌فرض نصب است. اگر نداشتی:

```bash
sudo apt update && sudo apt install yersinia
```

---

## **اجرای Yersinia در حالت اینتراکتیو**

برای اجرای رابط تعاملی:

```bash
sudo yersinia -I
```

وقتی باز شد:

- با کلید **F2** لیست پروتکل‌ها رو می‌بینی.
    
- با کلید **F3** حملات ممکن برای هر پروتکل رو می‌بینی.
    
- با کلید **F7** حمله رو اجرا می‌کنی.
    

---

## **اجرای حمله DHCP Starvation**

1. بعد از اجرای Yersinia با `sudo yersinia -I`
    
2. با **کلید F2** برو روی پروتکل **DHCP**.
    
3. با **کلید F3** لیست حملات DHCP رو ببین.
    
4. گزینه **DHCP Discover Flooding** رو انتخاب کن (معمولاً Attack 1).
    
5. با **F7** حمله رو فعال کن.
    

حالا Yersinia شروع می‌کنه به ارسال **انفجاری DHCP Discover** با آدرس‌های MAC رندوم.  
نتیجه؟ سرور DHCP کل Pool رو می‌ده به MACهای جعلی → کلاینت واقعی دیگه IP نمی‌گیره.

## **تست نتیجه حمله**

روی یک کلاینت واقعی:

```bash
ip a
```

یا

```bash
dhclient
```

می‌بینی که کلاینت نمی‌تونه آدرس IP بگیره (Timeout میشه).

برگرد توی Yersinia و همون حمله رو دوباره انتخاب کن و **F7** بزن تا متوقف بشه.  
یا Yersinia رو کامل ببند (`Ctrl+C`).

## **حمله DHCP Spoofing چیست؟**

**DHCP Spoofing** یعنی مهاجم یک **سرور DHCP جعلی** (Rogue DHCP Server) توی شبکه راه می‌اندازه و **به کلاینت‌ها اطلاعات اشتباه می‌ده**.

این اطلاعات اشتباه می‌تونن شامل:

- **Gateway جعلی** (تا ترافیک از مهاجم رد بشه → حمله Man-in-the-Middle)
    
- **DNS جعلی** (برای حملات فیشینگ یا هدایت به سرورهای مهاجم)
    
- حتی **IP Address و Subnet غلط** (برای قطع دسترسی کلاینت)
    

---

## **چطور انجام میشه؟**

1. **مهاجم به شبکه دسترسی پیدا می‌کنه** (فیزیکی یا وای‌فای).
    
2. روی سیستم خودش یک **DHCP Server جعلی** اجرا می‌کنه (ابزارهایی مثل `dhcpd`, `Ettercap`, `Yersinia`).
    
3. **وقتی یک کلاینت به شبکه وصل میشه و DHCP Discover می‌فرسته**، هم سرور اصلی DHCP و هم سرور جعلی مهاجم جواب میدن.
    
4. اگر **پاسخ مهاجم زودتر به کلاینت برسه** → کلاینت تنظیمات جعلی رو می‌گیره.
    
5. حالا مهاجم می‌تونه:
    
    - **کل ترافیک رو شنود یا تغییر بده** (MITM).
        
    - **کلاینت رو به سرورهای مخرب بفرسته**.
        

---

## **DHCP Spoofing vs DHCP Starvation**

- **DHCP Starvation**: فقط Pool رو پر می‌کنه تا کلاینت‌ها IP نگیرن.
    
- **DHCP Spoofing**: یک سرور جعلی اضافه می‌کنه و اطلاعات اشتباه به کلاینت‌ها می‌ده. (خیلی خطرناک‌تر برای حملات پیشرفته).
    

---

## **ابزارهای مورد استفاده**

- **Yersinia** (برای ساخت سرور DHCP جعلی)
    
- **Ettercap** (برای ترکیب با حملات MITM)
    
- **dhcpd** (ساده‌ترین راه برای ساخت Rogue DHCP Server)
    
- **Scapy (Python)** (برای ساخت پاسخ‌های DHCP سفارشی)
    

---

## **حمله با Yersinia**

مثل Starvation، اما این بار:

1. اجرای Yersinia:
    
    ```bash
    sudo yersinia -I
    ```
    
2. انتخاب پروتکل **DHCP** با **F2**.
    
3. در **F3** انتخاب حمله **Rogue DHCP Server**.
    
4. زدن **F7** برای فعال‌سازی.
    

حالا Yersinia نقش سرور DHCP جعلی رو بازی می‌کنه و به کلاینت‌ها IP و Gateway/DNS جعلی می‌ده.

---

## **سناریوی حمله**

- **مهاجم**: سرور جعلی DHCP راه می‌اندازه (Gateway = 192.168.1.100 → خودش).
    
- **کلاینت**: به شبکه وصل میشه و این اطلاعات رو می‌گیره.
    
- **نتیجه**: تمام ترافیک کلاینت به جای روتر واقعی، به مهاجم میره → **Man-in-the-Middle**.
    

---

## **راه‌های دفاعی**

- **DHCP Snooping** روی سوئیچ‌ها → فقط پورت‌های مشخص اجازه پاسخ DHCP داشته باشن.
    
- **Dynamic ARP Inspection (DAI)** → بررسی ARP و جلوگیری از حملات ترکیبی.
    
- **IP Source Guard** → محدود کردن ترافیک به IP/MAC معتبر.
    
- مانیتورینگ برای **تشخیص چند DHCP Server** در شبکه.
