

مکانیزم app locker یک مکانیزم امنیتی در سیستم عامل ویندوز است که این قابلیت را برای ما فراهم میکند تا بتوانیم در تا در حین اجرای برنامه ها اسکریپت ها و موارد این چنینی مدیریت کنیم و از طریق راه هایی مثله هش برنامه ها بیایم اون هارو اجرا کنیم 

مثلا من هش برنامه رسمی putty رو دارم حالا میام و این هش رو درون این سرویس یعنی app locker اضافه میکنم تا اگر برنامه به اسم putty نصب شد روی هاست ایکس اگر هشی غیر از این بود اما اسمش putty بود در اجرای اون جلوگیری کن

## نکته :  در حین استفاده از این نرم افزار باید دقت بالایی برخوردار باشیم چرا که کوچکترین اشتباه ممکن است کل سیستم شما را قفل کرده و به سختی قابل Recovery باشد


## how to start

مکانیزم Applocker دارای سرویسی در ویندوز میباشد که به صورت پیش فرض این سرویس غیرفعال میباشد و برای کار کردن با آن و اجرای Applocker باشد ابتدا این سرویس را که Application identity نام دارد را Start کنید

```
Win + R = Services.msc
find ---> Application identity 
start
```


![[Pasted image 20250828183307.png]]

پس از Start شدن این سرویس دوباره کنسول Run را باز کنید و در آن دستور Gpedit.msc را تایپ کنید تا وارد Group policy شوید.پس از ورود به Group policy وارد قسمت Computer configuration شوید و در آن جا گزینه ی Windows setting را بزنید سپس وارد Security setting شوید و در آن جا بر روی گزینه ی Application control policies بزنید تا Applocker را به شما نمایش دهد و بر روی آن کلیک کنید


```
Win + R = gpedit.msc

Go To ---> Computer configuration  | Windows setting | Security setting | Application control policies

```


![[Pasted image 20250828183926.png]]

در این قسمت ما میتونیم رول های مختلفی برای اجرای برنامه ها مون بزاریم 
مثلا میتونیم یک رول اجرای برای یه سری فایل های باینری بدیم یا میتونیم یک رول اسکریپتی بنویسم برای اینکه مثلا فایل هایی با پسوند .bat اجرا نشن  و Windows installer ruls که ماژول هایی است که برای نصب نرم افزارها میباشد را جلوگیری میکند

و در نهایت میتونیم رول مد نظرمون رو بنویسم 
رول نوشتن در app locker شبیه به رول نوشتن در فایروال ویندوز است
