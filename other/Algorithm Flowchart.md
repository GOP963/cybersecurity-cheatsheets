
الگوریتم یعنی یک مجموعه دستور مرحله به مرحله برای حل یک مسئله
یعنی:

- از کجا شروع می‌کنیم
    
- چه کارهایی انجام می‌دیم
    
- چطور تصمیم می‌گیریم
    
- و در نهایت چطور تمام می‌کنیم
    

مثل دستور پخت یک غذا:

1. آب رو می‌جوشونی
    
2. برنج رو می‌شوری
    
3. نمک اضافه می‌کنی
    
4. اگر آب جوشید → برنج رو بریز
    
5. بعد دم می‌کنی
    

این‌ها یک **الگوریتم** هستن.

# 🔶 فلوچارت (Flowchart) چیه؟

**فلوچارت یعنی نقشه‌ی تصویری الگوریتم.**

یعنی همون مراحل الگوریتم رو میای با شکل‌ها نمایش می‌دی تا خیلی واضح و قابل فهم بشه.

در فلوچارت از شکل‌های استاندارد استفاده می‌کنیم:

| شکل               | معنی                          |
| ----------------- | ----------------------------- |
| 🔷 بیضی           | شروع / پایان                  |
| ⬛ مستطیل          | انجام یک کار (عملیات)         |
| 🔶 لوزی           | شرط / تصمیم‌گیری (بله یا خیر) |
| 🔽 فلش            | جهت حرکت مراحل                |
| 🔹 متوازی‌الاضلاع | ورودی/خروجی                   |
