

# 🧠 CPU چیست؟

CPU مخفف **Central Processing Unit** است یعنی «واحد پردازش مرکزی».

🔹 در متن گفته شده:

- CPU «مغز کامپیوتر» است
    
- همه‌ی عملیات اصلی کامپیوتر زیر نظر CPU انجام می‌شود
    
- هر چیزی (برنامه‌ها، داده‌ها، دستورها) در نهایت باید توسط CPU پردازش شود
    

---

# ⚙️ وظیفه CPU چیست؟

CPU سه کار اصلی انجام می‌دهد:

1. **Fetch (واکشی دستور)**  
    دستور را از حافظه (RAM) می‌گیرد
    
2. **Decode (تفسیر دستور)**  
    CPU می‌فهمد دستور چیست و چه کاری باید انجام دهد
    
3. **Execute (اجرا)**  
    عملیات را انجام می‌دهد (محاسبات، انتقال داده و …)
    

---

# 🧩 اجزای داخل CPU

## 1. ALU (Arithmetic Logic Unit)

🔸 بخش محاسباتی CPU

- جمع، تفریق
    
- مقایسه‌ها (بزرگ‌تر/کوچک‌تر)
    
- عملیات منطقی (AND, OR, NOT)
    

---

## 2. Control Unit (واحد کنترل)

🔸 مثل «مدیر CPU»

- دستورها را کنترل می‌کند
    
- مشخص می‌کند داده کجا برود و چه زمانی اجرا شود
    

---

## 3. Registers (رجیسترها)

🔸 حافظه خیلی سریع داخل CPU

- برای نگهداری موقت داده‌ها
    
- خیلی سریع‌تر از RAM
    

---

## 4. Cache (کش)

🔸 حافظه سریع بین CPU و RAM

- دستورها و داده‌های پر استفاده را نگه می‌دارد
    
- باعث سرعت بیشتر سیستم می‌شود
    

---

# 🚀 سرعت CPU به چه چیزهایی بستگی دارد؟

در متن گفته شده:

- فرکانس (Hz / GHz)
    
- پهنای باس (Bus width)
    
- مقدار Cache
    
- معماری CPU
    

---

# 🧬 معماری‌های مهم CPU

## 1. RISC

- دستورهای ساده و کم
    
- سرعت اجرای بالا
    

## 2. CISC

- دستورهای پیچیده‌تر
    
- تعداد دستور بیشتر
    

---

# 🧠 ویژگی‌های مهم CPU (در متن)

چند تکنولوژی مهم هم توضیح داده شده:

- **Superscalar** → اجرای همزمان چند دستور
    
- **Pipelining** → اجرای مرحله‌ای دستورها
    
- **Branch Prediction** → حدس زدن مسیر اجرای برنامه
    
- **Overclocking** → افزایش سرعت CPU (غیر رسمی و خطرناک)
    
- **Multicore** → چند هسته داخل یک CPU
    

---

# 🔌 انواع حالت‌های CPU (Operating Modes)

- **Real Mode** → حالت ساده قدیمی (سازگاری با سیستم‌های خیلی قدیمی)
    
- **Protected Mode** → حالت امن و چندوظیفه‌ای
    
- **Virtual Mode** → اجرای چند محیط همزمان
    

---

# 🧱 شکل فیزیکی CPU

CPUها در دو نوع اصلی هستند:

- **PGA (Pin Grid Array)** → پایه‌دار (پین‌دار)
    
- **SEC (Single Edge Contact)** → روی کارت نصب می‌شود
    

و از سوکت‌هایی مثل ZIF استفاده می‌کنند که نصب راحت باشد.

---

چون CPU هنگام کار شدید خیلی داغ می‌شود.
