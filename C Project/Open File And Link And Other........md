### 💡 اما...

اگه منظورت اینه که **یه URL رو در مرورگر سیستم باز کنیم (مثلاً در ویندوز یا لینوکس)**، اون وقت از **ماکرو یا تابع خاصی در سطح سیستم‌عامل** استفاده می‌کنیم.  
بذار بر اساس سیستم‌عامل توضیح بدم 👇

---

## 🪟 در Windows:

می‌تونی از تابع `ShellExecute()` که در کتابخانه `shell32.h` تعریف شده استفاده کنی:

```c
#include <windows.h>

int main() {
    ShellExecute(0, "open", "https://www.openai.com", 0, 0, SW_SHOWNORMAL);
    return 0;
}
```

🔹 کاری که این می‌کنه:  
مرورگر پیش‌فرض سیستم رو باز می‌کنه و وارد اون URL میشه.  
یعنی دقیقاً مثل اینه که روی یه لینک کلیک کرده باشی.

---

## 🐧 در Linux:

اینجا معمولاً از دستور `xdg-open` استفاده می‌کنن (ابزاری برای باز کردن فایل یا لینک با برنامه‌ی پیش‌فرض):

```c
#include <stdlib.h>

int main() {
    system("xdg-open https://www.openai.com");
    return 0;
}
```

🔹 این هم با تابع `system()` یه فرمان ترمینال اجرا می‌کنه  
که باعث میشه مرورگر باز بشه و URL رو باز کنه.

---

## 🍏 در macOS:

دقیقاً مشابه لینوکسه ولی دستور فرق می‌کنه:

```c
#include <stdlib.h>

int main() {
    system("open https://www.openai.com");
    return 0;
}
```

---

### 🧩 نکته درباره‌ی "ماکرو"

در C چیزی مثل `#define OPEN_URL "https://..."` می‌تونی تعریف کنی،  
ولی اون فقط یه جایگزینی متنیه، خودش کاری انجام نمی‌ده.

مثلاً:

```c
#define URL "https://www.openai.com"

int main() {
    system("xdg-open " URL);
    return 0;
}
```

اینجا `URL` صرفاً یه **ماکرو متنی**ه که داخل دستور جایگزین میشه.

بریم خط‌به‌خط بررسیش کنیم، خیلی قشنگه 👇

## 📘 تابع ShellExecute

تابع `ShellExecute()` از **Windows API** هست و در کتابخانه‌ی `shell32.h` تعریف شده.  
وظیفه‌اش اینه که یه فایل، فولدر، یا URL رو **با برنامه‌ی پیش‌فرض سیستم** باز کنه.

---

### ✅ ساختار کلی تابع:

```c
HINSTANCE ShellExecute(
    HWND hwnd,
    LPCSTR lpOperation,
    LPCSTR lpFile,
    LPCSTR lpParameters,
    LPCSTR lpDirectory,
    INT nShowCmd
);
```

---

حالا خط خودت رو بیاریم و جزء به جزءش ترجمه کنیم 👇

```c
ShellExecute(0, "open", "https://www.openai.com", 0, 0, SW_SHOWNORMAL);
```

---

## 🔹 ۱. پارامتر اول → `0`

```c
HWND hwnd = 0;
```

🔸 یعنی **هیچ پنجره والد (Parent Window)** نداریم.  
این عدد در واقع `NULL` هست (ولی 0 هم معادلشه).  
اگر برنامه‌ات یه رابط گرافیکی داشت، می‌تونستی اینجا **هندل (handle)** پنجره اصلیت رو بدی تا اون مالک این عملیات بشه.

در برنامه‌های ساده‌ی کنسولی معمولاً همون `0` می‌نویسیم.

---

## 🔹 ۲. پارامتر دوم → `"open"`

```c
LPCSTR lpOperation = "open";
```

🔸 این یعنی قراره اون فایل یا URL **باز بشه** (Open operation).  
می‌تونه مقدارهای دیگه هم داشته باشه مثل:

- `"edit"` → باز کن برای ویرایش
    
- `"print"` → ارسال برای چاپ
    
- `"explore"` → باز کن در فایل اکسپلورر
    

اما برای URL همیشه `"open"` استفاده می‌کنیم.

---

## 🔹 ۳. پارامتر سوم → `"https://www.openai.com"`

```c
LPCSTR lpFile = "https://www.openai.com";
```

🔸 اینجا چیزی که باید باز بشه رو مشخص می‌کنی:  
ممکنه باشه:

- آدرس اینترنتی (URL)
    
- مسیر فایل (مثلاً `"C:\\Users\\Martin\\file.txt"`)
    
- فولدر (`"C:\\Windows"`)
    

در این مثال، ویندوز می‌فهمه این یک **URL** هست و مرورگر پیش‌فرض رو باز می‌کنه.

---

## 🔹 ۴. پارامتر چهارم → `0`

```c
LPCSTR lpParameters = 0;
```

🔸 این برای **پارامترهای اضافه‌ی خط فرمان** هست (در صورت نیاز).  
مثلاً اگه برنامه‌ای مثل `notepad.exe` رو باز می‌کردی،  
می‌تونستی بنویسی:

```c
ShellExecute(0, "open", "notepad.exe", "myfile.txt", 0, SW_SHOWNORMAL);
```

که در واقع Notepad رو با فایل خاصی باز می‌کرد.  
چون ما داریم URL باز می‌کنیم، چیزی لازم نیست — پس `0`.

---

## 🔹 ۵. پارامتر پنجم → `0`

```c
LPCSTR lpDirectory = 0;
```

🔸 این یعنی "دایرکتوری کاری فعلی" (Working Directory).  
می‌تونی مشخص کنی برنامه‌ای که باز میشه از کجا اجرا بشه.  
ما نیازی نداریم، پس `0`.

---

## 🔹 ۶. پارامتر آخر → `SW_SHOWNORMAL`

```c
INT nShowCmd = SW_SHOWNORMAL;
```

🔸 این مشخص می‌کنه **چطور پنجره نمایش داده بشه**.  
از ماکروهای زیر می‌تونه استفاده کنه:

|مقدار|معنی|
|---|---|
|`SW_SHOWNORMAL`|پنجره به شکل معمولی باز بشه|
|`SW_SHOWMAXIMIZED`|پنجره تمام‌صفحه باز بشه|
|`SW_SHOWMINIMIZED`|پنجره مینیمایز بشه|
|`SW_HIDE`|مخفی باز بشه (نشون داده نشه)|

ما معمولاً از `SW_SHOWNORMAL` استفاده می‌کنیم چون طبیعی‌ترین حالته.

بیاین قدم‌به‌قدم با مثال واقعی ببینیم چطور میشه فهمید دستور با موفقیت اجرا شده یا نه 👇

## 🔹 تابع ShellExecute چه چیزی برمی‌گردونه؟
تابع `ShellExecute()` یه **مقدار از نوع `HINSTANCE`** برمی‌گردونه.  
اما نکته اینجاست:  
اگه عملیات موفق باشه، **یه مقدار بزرگ‌تر از 32** برمی‌گردونه.  
اگه خطا رخ بده، **یه مقدار عددی بین 0 تا 32** (یا مساوی 32) برمی‌گردونه که نشون‌دهنده نوع خطاست.

---

## 🔹 مثال کاربردی

```c
#include <windows.h>
#include <stdio.h>

int main() {
    HINSTANCE result = ShellExecute(0, "open", "https://www.openai.com", 0, 0, SW_SHOWNORMAL);

    if ((int)result > 32) {
        printf("✅ عملیات با موفقیت انجام شد!\n");
    } else {
        printf("❌ خطا در اجرای دستور! کد خطا: %d\n", (int)result);
    }

    return 0;
}
```

---

## 🔹 جدول خطاهای ShellExecute

در صورتی که مقدار برگشتی **≤ 32** باشه، یعنی خطا رخ داده.  
برخی از کدهای مهم خطا 👇

| مقدار | معنی |
|--------|------|
| `0` | حافظه کافی برای اجرای عملیات وجود ندارد |
| `2` | فایل یا URL پیدا نشد |
| `3` | مسیر فایل اشتباه است |
| `5` | دسترسی رد شد (Access Denied) |
| `8` | حافظه کافی نیست |
| `31` | برنامه‌ی مرتبط برای اجرای فایل پیدا نشد |
| `32` | اشتباه ناشناخته (unknown error) |

---

## 🔹 مثال حرفه‌ای‌تر: اجرای دو کار پشت سر هم

فرض کن می‌خوای:
1. URL باز بشه  
2. فقط اگه موفق شد، پیغام یا برنامه‌ی دیگه‌ای هم اجرا بشه

```c
#include <windows.h>
#include <stdio.h>

int main() {
    HINSTANCE result = ShellExecute(0, "open", "https://www.openai.com", 0, 0, SW_SHOWNORMAL);

    if ((int)result > 32) {
        printf("✅ مرورگر با موفقیت باز شد!\n");
        // حالا یه کار دیگه هم انجام بده:
        ShellExecute(0, "open", "notepad.exe", 0, 0, SW_SHOWNORMAL);
    } else {
        printf("❌ خطا در اجرای دستور! کد خطا: %d\n", (int)result);
    }

    return 0;
}
```

اینجوری دقیقاً مثل همون کاری که با `status_code == 200` در پایتون انجام میدی،  
در C هم چک می‌کنی که نتیجه موفق بوده یا نه 😎
