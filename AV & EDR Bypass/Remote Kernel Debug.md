



# راه‌اندازی Remote Kernel Debugging ویندوز با WinDbg و KDNET

---

# مقدمه

Remote Kernel Debugging یعنی:

> دیباگ کردن Kernel ویندوز از روی یک سیستم دیگر.

معماری:

```text id="ly0rf5"
[ Target Machine ]
    Windows Kernel
        ↓
      KDNET
        ↓ Network
[ Host Machine ]
      WinDbg
```

---

# اصطلاحات مهم

| اصطلاح | توضیح |
|---|---|
| Host | سیستمی که WinDbg روی آن اجرا می‌شود |
| Target | سیستمی که Kernel آن را دیباگ می‌کنیم |
| KDNET | مکانیزم Kernel Debugging روی شبکه |
| WinDbg | دیباگر مایکروسافت |
| bcdedit | ابزار تنظیم Boot Configuration |
| Test Signing | اجازه لود Driverهای بدون Signature |

# مرحله 6 — تنظیم KDNET

---

# پیدا کردن kdnet.exe

معمولا:

```text id="j18o6l"
C:\Program Files (x86)\Windows Kits\10\Debuggers\x64
```

---

# اجرای KDNET

مثال:

```cmd id="4m6odl"
kdnet.exe 192.168.1.10 50000
```

---

# پارامترها

| پارامتر | توضیح |
|---|---|
| 192.168.1.10 | IP سیستم Host |
| 50000 | Port |

---

# خروجی نمونه

```text id="3bsl12"
Enabling network debugging on Intel(R) Ethernet...

Key=1.2.3.4

To debug this machine, run:
windbg -k net:port=50000,key=1.2.3.4
```

---

# نکته مهم

این Key برای Authentication بین Host و Target است.

---
