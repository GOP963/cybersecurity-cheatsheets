# 📌 مقدمه: کتابخانه time.h چیست؟

در زبان C کار با تاریخ و زمان _خیلی_ مهم است:  
مثل گرفتن زمان فعلی، اندازه‌گیری زمان اجرای برنامه، تبدیل تاریخ‌ها، چاپ زمان با فرمت دلخواه و…  
تمام این کارها با **time.h** انجام می‌شود.

در این کتابخانه ۳ نوع داده‌ی اصلی داریم:

---

# 🧩 1) `time_t`

یک عدد هست (integer-like)  
نمایش می‌دهد: **چند ثانیه از 1 Jan 1970 گذشته؟**

به این می‌گن **Unix Epoch Time**

مثلاً:

```
1732345678
```

---

# 🧩 2) `clock_t`

زمان CPU را برمی‌گرداند  
برای اندازه‌گیری این که _پردازنده_ چقدر وقت صرف اجرای برنامه کرده.

با `CLOCKS_PER_SEC` تبدیلش می‌کنیم به ثانیه.

---

# 🧩 3) `struct tm`

این مهم‌ترین است:

```c
struct tm {
    int tm_sec;   // 0-59
    int tm_min;   // 0-59
    int tm_hour;  // 0-23
    int tm_mday;  // 1-31
    int tm_mon;   // 0-11 (دقت کن: ژانویه = 0)
    int tm_year;  // از 1900
    int tm_wday;  // 0-6
    int tm_yday;  // 0-365
    int tm_isdst; // daylight saving time
};
```

---

# 🔥 الان بریم سراغ توابع مهم time.h

من کامل‌ترین و ساده‌ترین توضیح ممکن رو می‌دم.

---

# ⭐ 1) تابع `time()`

### گرفتن زمان فعلی به صورت time_t

```c
time_t t = time(NULL);
```

اگر خواستی داخل یک متغیر ذخیره کنی:

```c
time_t now;
time(&now);
```

---

# ⭐ 2) تابع `localtime()`

### تبدیل time_t به زمان محلی (ساختار struct tm)

```c
struct tm* info = localtime(&t);
```

---

# ⭐ 3) تابع `asctime()`

### تبدیل struct tm به رشته‌ی خوانا برای انسان

```c
printf("%s", asctime(info));
```

خروجی:

```
Tue Apr 15 07:22:42 2025
```

---

# 📌 مثال کامل: گرفتن زمان فعلی

```c
#include <stdio.h>
#include <time.h>

int main() {
    time_t t = time(NULL);
    struct tm* ptr = localtime(&t);
    printf("%s", asctime(ptr));
    return 0;
}
```

---

# ⭐ 4) `gmtime()`

زمان UTC → نه محلی

```c
struct tm* utc = gmtime(&t);
printf("%s", asctime(utc));
```

---

# ⭐ 5) `difftime()`

### اختلاف بین دو زمان (برحسب ثانیه)

مثال:

```c
time_t start = time(NULL);
...
time_t end = time(NULL);
printf("Diff = %.2f seconds", difftime(end, start));
```

---

# ⭐ 6) `clock()`

### اندازه‌گیری زمان CPU

```c
clock_t start = clock();
/* code */
clock_t end = clock();
printf("CPU time = %f seconds", (double)(end - start) / CLOCKS_PER_SEC);
```

---

# ⭐ 7) `strftime()`

### چاپ تاریخ و زمان با فرمت دلخواه

این بهترین تابع فرمت‌دهی است.

```c
char buffer[80];
strftime(buffer, 80, "Time is %I:%M %p", timeinfo);
puts(buffer);
```

خروجی:

```
Time is 09:00 AM
```

---

# 🧨 فرمت‌های مهم strftime

|کد|معنی|
|---|---|
|%H|ساعت 00-23|
|%I|ساعت 01-12|
|%M|دقیقه|
|%S|ثانیه|
|%p|AM / PM|
|%d|روز|
|%m|ماه|
|%Y|سال کامل (2025)|
|%a|نام کوتاه روز|
|%A|نام کامل روز|
|%b|نام کوتاه ماه|
|%B|نام کامل ماه|

---

# 🎯 حالا یک مثال خیلی حرفه‌ای

چاپ زمان فعلی کامل:

```c
time_t raw;
struct tm* info;
char buffer[100];

time(&raw);
info = localtime(&raw);

strftime(buffer, sizeof(buffer),
         "Today is %A, %B %d, %Y - Time: %H:%M:%S",
         info);

printf("%s\n", buffer);
```
