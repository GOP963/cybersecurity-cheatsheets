
ما با استفاده از ابزار mimikatz میتونیم با پروسه ها تعامل برقرار کنیم لیست کنیم یا استارت کنیم و موارد این چنینی


```
process::run 
```

```
process::start
```

ما با استفاده از این دو دستور میتونیم یک پروسس استارت کنیم با این تفاوت که ما وقتی میزنیم run با این معنی است که میخوام یک پروسسی رو همراه با یک دستور اجرا کنیم مثلا بزنیم 

```
	process::run "cmd wmic process call create calc"
```

اگه ما پروسسی رو ران کنیم اما دستوری بهش ندیم شل cmd رو میگیریم اما دستوری رو نمیتونیم بزنیم و یه جورایی اون سشن هنگ میکنه

اما وقتی میزنیم یک پروسسی رو استارت کن یعنی بیا این پروسس اجراش کن مثلا وقتی میزنی 

```
process::start cmd 
```

این دستور میاد یک cmd باز میکنه
