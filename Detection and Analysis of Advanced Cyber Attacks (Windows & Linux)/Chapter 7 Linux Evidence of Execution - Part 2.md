## `make menuconfig`

ابزار **تعاملی پیکربندی کرنل لینوکس** — یک رابط TUI (Text User Interface) برای انتخاب اینکه کرنل چه چیزی را **compile** کند.

---

### چرا اهمیت دارد؟

کرنل لینوکس ماژولار است — صدها feature اختیاری دارد. `menuconfig` تعیین می‌کند:
- چه چیزی **داخل کرنل** باشد (built-in)
- چه چیزی به صورت **ماژول جداگانه** (`*.ko`) کامپایل شود
- چه چیزی **اصلاً نباشد**

---

### اجرا
```bash
cd /usr/src/linux   # یا هر دایرکتوری سورس کرنل
make menuconfig
```

نتیجه: یک فایل `.config` در همان دایرکتوری ساخته/آپدیت می‌شود.

---

### رابط کاربری

Arrow Keys  → حرکت
Enter       → وارد شدن به زیرمنو
Space       → تغییر حالت (built-in / module / off)
/           → جستجو
?           → راهنمای آیتم انتخابی
ESC ESC     → برگشت / خروج


**سه حالت برای هر گزینه:**
| نماد | معنا |
|------|------|
| `[*]` | built-in — مستقیم داخل کرنل |
| `[M]` | module — فایل `.ko` جداگانه |
| `[ ]` | غیرفعال |

---

### ارتباط با فورنزیک

در امنیت/فورنزیک لینوکس مهم است چون:

- **rootkit‌ها** اغلب kernel module هستند → بررسی اینکه کدام ماژول‌ها در `.config` فعال شده‌اند
- **auditing** کرنل (مثل `CONFIG_AUDIT`) باید فعال باشد تا لاگ‌ها ثبت شوند
- سیستم‌هایی با کرنل سفارشی‌سازی‌شده ممکن است عمداً feature‌های امنیتی را disable کرده باشند

---

### مثال جستجو در منوconfig

با `/` و تایپ `AUDIT`:
CONFIG_AUDIT=y       ← فعال به صورت built-in
CONFIG_AUDITSYSCALL=y

اگر این‌ها `n` باشند، لاگ‌های syscall وجود ندارند → تحلیل سخت‌تر می‌شود.
