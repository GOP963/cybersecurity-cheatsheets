بریم باهم دیگه یکی دیگر از ابزار هایی که وجود دارد در زمینه Memory Forensic رو هم باهم ببینیم 

### MemProcFS

https://github.com/ufrisk/MemProcFS/


برای اینکه ما بتوینم از این ابزار استفاده کنیم احتیاج داریم به یک نرم افزار دیگر تحت عنوان dokan که به این امکان رو میده بدون نوشتن درایور یک file system ماننده FAT یا NTFS سیستم فایل خودتان را به راحتی و بدون نوشتن درایور دستگاه ایجاد کنید. Dokan شبیه FUSE (سیستم فایل لینوکس در فضای کاربر) است اما در ویندوز کار می‌کند. علاوه بر این، dokany شامل یک بسته‌بندی FUSE است که به شما کمک می‌کند سیستم فایل FUSE خود را بدون تغییر منتقل کنید

![[Pasted image 20260612034458.png]]


پس در اصل کاری که انجام میده اینه که میاد برای ما اون فایل dump شده رو mount میکنه و به یه file system در میاره به همین خاطره که با به ابزار dokan هم نیاز داشتیم چون ابزار در اصل اون فایل رو به یه device mount  شده در میاورد
