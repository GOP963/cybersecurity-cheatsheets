## Windows Prefetch

**مکانیزم:** سرویس `SysMain` (قبلاً Superfetch) هنگام اولین اجرای یک برنامه، منابع مورد نیاز آن را مانیتور کرده و در یک فایل `.pf` ذخیره می‌کند تا اجراهای بعدی سریع‌تر باشند.

**مسیر:**
C:\Windows\Prefetch\


**نام‌گذاری فایل‌ها:**
NOTEPAD.EXE-{HASH}.pf

هش از روی **مسیر کامل** برنامه محاسبه می‌شه — یعنی اگه همون باینری از دو مسیر مختلف اجرا بشه، دو فایل `.pf` جداگانه ساخته می‌شه.

## اطلاعات فورنزیک قابل استخراج

| فیلد | توضیح |
|---|---|
| Run Count | تعداد دفعات اجرا |
| Last Run Time | آخرین زمان اجرا |
| Up to 8 timestamps | ویندوز ۸ به بالا — ۸ تایم‌استمپ آخر نگه می‌داره |
| Full Path | مسیر کامل فایل اجرایی |
| Volume Info | درایو و Serial Number |
| Dependencies | تمام DLL‌ها و فایل‌های لود شده |

## نکات کلیدی فورنزیک

- حتی اگه **فایل اصلی حذف شده باشه**، فایل `.pf` باقی می‌مونه → دلیل محکم بر اجرا
- **ابزار تحلیل:** `PECmd.exe` (Eric Zimmerman)
- روی **Windows Server** به صورت پیش‌فرض **غیرفعال** است
- روی **SSD**ها بعضی OEMها Prefetch رو disable می‌کنن → absence of evidence ≠ evidence of absence


فایل **`UsrClass.dat`** هست (نه `csrclass.dat`) — احتمالاً تایپو بود.

## MUICache

**مکانیزم:** هر بار که کاربر یه برنامه اجرا می‌کنه، ویندوز نام نمایشی (Friendly Name) اون رو از منابع PE استخراج کرده و کش می‌کنه.

**مسیر رجیستری:**
HKCU\Software\Classes\Local Settings\Software\Microsoft\Windows\Shell\MuiCache


**Value ها:**
- **Name:** مسیر کامل فایل اجرایی (key)
- **Data:** نام نمایشی برنامه

**ارزش فورنزیک:** حتی پس از حذف برنامه، entry باقی می‌مونه → اثبات اجرا + مسیر اصلی

## ShellBags

**مکانیزم:** ویندوز تنظیمات ظاهری (اندازه پنجره، نوع نمایش، مرتب‌سازی) هر پوشه رو ذخیره می‌کنه — اما این یعنی **کاربر حتماً اون پوشه رو باز کرده**.

**مسیر رجیستری — تصحیح:**

HKCU\Software\Classes\Local Settings\Software\Microsoft\Windows\Shell\Bags
HKCU\Software\Classes\Local Settings\Software\Microsoft\Windows\Shell\BagMRU


> مسیری که گفتی (`HKCU\Software\Microsoft\Windows\Shell\Bags`) مربوط به **NTUser.dat** هست و Desktop/فایل‌دیالوگ‌هاست.  
> مسیر **UsrClass.dat** زیر `Local Settings` قرار داره و جامع‌تره.

**ارزش فورنزیک:**
- پوشه‌های باز شده (حتی حذف شده)
- درایوهای USB (با Volume Label و Serial)
- Network Shares (`\\server\share`)
- ZIP/ISO به عنوان پوشه

**ابزار تحلیل:** `ShellBagsExplorer` (Eric Zimmerman)
